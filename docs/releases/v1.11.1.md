# Stable v1.11.1

本版本包含当前开发主线与 2026-10-27 已确认纳入的全部客户端功能和修复。

- 使用 Claude Agent SDK 执行任务，保留主线已有的设计、编辑及升级兼容功能。
- 云账号可使用已上线的网页搜索、正文抓取和生图服务，服务端管理供应商凭据，并按现有计费规则结算。
- 改进生图任务恢复，复用已生成结果，避免因下载重试重复生成。
- 统一内置工具写入审批，保护目录与链接路径；修复连续上传附件覆盖和草稿、队列恢复问题。
- 改进自动会话标题，保留手动命名；复杂任务首次完成后最多增加一次有上限的标题请求，失败保留原标题。
- 为 Python、Edit 和浏览器引用失效提供针对性恢复指引；Trace 区分工具中间失败与任务最终状态，并展示调用输入和结果。
- 更新检查与安装文件下载使用 Stable Cloud；安装仍由用户确认，不强制重启应用。

这是桌面客户端发布，不重复迁移云端数据库或修改既有账号、价格与历史记录。网络搜索、抓取、生图及复杂任务标题生成可能按现有规则产生费用。

GitHub 构建、测试、安装升级和回滚检查通过后才创建正式发布。具体校验与实际验收记录见本次发布工作流。
