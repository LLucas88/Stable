# Stable 1.11.5

- 改进长报告对话的响应速度。工具运行期间按需读取对话，展开记录时加载详情。
- 改进流式回答、任务中断后的记录恢复和后台任务状态显示。澄清问题支持点击选项直接提交。
- Design 可直接提交图片生成请求。质量、尺寸和数量可按次绑定，提示词可以指定参数。生成结果支持标注、评论、移除背景和尺寸调整。
- 模板库新增 46 套中文命名的演示模板，其中 34 套提供原版样片。
- 改进应用内更新进度提示及编辑器退出时的未保存内容检查。
- 升级 Claude Agent SDK 至 0.3.318。

## 问题修复说明

长报告任务曾在处理单条对话时同步读取其他对话的历史记录。现在按对话标识查询，执行记录的写入也独立于历史摘要。长工具输入在展开详情时显示。

图片生成失败时，客户端区分参数错误、供应商拒绝和网络中断。上游结果未知时保留请求记录，防止重复提交。网页工具、任务取消和异常退出也保留相应的执行状态，便于返回对话后检查。
