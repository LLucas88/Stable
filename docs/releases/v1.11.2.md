# Stable v1.11.2

本版本汇总 v1.11.1 以来的客户端功能和修复。

## Design 图片创作

- 支持通过 Stable Cloud 使用 GPT Image 2.5 Sunburst / Flare，并保留 GLM-image；可选择模型支持的质量选项。
- 新增店铺头像、店招、海报、弹窗、常规橱窗、菜品图六种交付规格；交付前校验精确像素尺寸与文件大小，保留自定义尺寸和生成清晰度。
- Design 图片产物直接展示，支持多图排列、放大查看和右键文件操作；普通聊天及其他类型文件保留原有展示方式。
- 多图任务最多两张并发；保存生成结果供断线后恢复，避免下载失败引起重复生图。异步查询需要网关支持，兼容原有同步接口。
- 图片参数与文字数量冲突时先确认；修复等待输入标记直接显示在回复中的问题。

## 模型、文件与技能

- 新增 GPT-6.1 Sol / Terra 的云端 Responses 协议、模型适配的思考深度及工具结果续聊支持。
- 交付产物右键菜单支持打开方式、外部浏览器、另存为、复制路径或内容，以及在资源管理器中定位。
- 修复 WorkBuddy 导入会话的交付路径解析和 Excel 等文件展示；兼容既有导入记录。
- 输入 `/` 可搜索并选择技能；附件菜单的技能列表增加搜索。市场技能需用户主动使用后加入“我的技能”，保留已使用、修改或手动添加的技能。
- 普通公共网页资源自动加载，额外站点权限集中展示，私网和敏感操作仍保留权限边界。

## 界面与升级

- 安装版自动更新优先使用 Stable Cloud 的更新清单与下载地址；GitHub 保留正式版安装包与源码归档。

- 优化 Design 菜单、尺寸输入对齐、活动入口、新聊天按钮和窗口圆角；左侧图标栏与顶部窗口栏共享主题背景。
- 保留既有账号、聊天记录、升级备份与失败回退机制；不会强制重启应用。

桌面安装包与源码一起发布。仓库内网关补丁的提交不等同于自动部署网关或迁移数据库；模型可用性以现有 Stable Cloud 配置为准。本次发布验证使用隔离数据和模拟供应商，不产生真实模型费用。
