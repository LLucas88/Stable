## 自动更新路径

v1.11.2 完整安装包和轻量更新包都使用 Stable Cloud 的 generic provider。GitHub 保留版本、源码和安装包归档；本版安装程序的更新检查和下载直接访问云端。用户确认后才执行安装，不自动重启当前应用。

源码开发启动方式不会自动替换本地代码或开发程序。以上配置也不意味着已经改写其他电脑上尚未升级的旧版程序。
