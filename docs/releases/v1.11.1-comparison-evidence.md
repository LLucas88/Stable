## 本轮实际验证

执行已有的五组针对性离线测试：

```powershell
node --test --test-concurrency=1 tests/answer-tools.test.cjs tests/design-request.test.cjs tests/conversation-titles.test.cjs tests/default-model-upgrade.test.cjs tests/presentation-reader.test.cjs
```

首轮结果：**31 项中 30 项通过，1 项失败**。失败项是默认模型经桥接发送到本地模拟服务，错误为 `connect EACCES 127.0.0.1`，发生在受限环境连接回环地址时。

在主机环境仅重跑该项：

```powershell
node --test --test-name-pattern="a new conversation sends the official Flash alias" tests/default-model-upgrade.test.cjs
```

结果：**1 项通过、0 失败**。因此本轮所选的 31 个用例均取得通过结果，其中 1 项来自单项重跑；没有声称首轮全通过或全仓库测试通过。

这些测试验证数据复制/章节持久化、设计参数、标题写回限制、模型默认迁移和 PPTX 提取等具体行为，使用临时数据及本地模拟服务。它们不是本轮真实模型质量、付费生图、GUI、正式安装包或跨设备升级的验收。
