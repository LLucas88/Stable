# Stable v1.0.01

## 更新内容

- 接入 Codex Harness 执行架构，支持内置浏览器、Excel 工具及任务恢复。
- 浏览器增加标签页、地址导航、HTML/Markdown/Excel 文档预览、下载和页面注释；注释先加入输入框草稿。
- 输入框附件入口合并为「+」菜单，未发送的新对话不占用列表；精简模型、浏览器及问鼎按钮。
- 思考强度按模型实际支持的 API 参数传递，不再注入提示词。
- 优化 Skill 分类、专家市场及两个插件；正式安装后自动登记随包提供的 617 个 Skill，并保留已有对话与自定义修改。
- 修复发送后立即停止、队列取消、停止任务后删除对话等问题，增加关闭窗口选择。
- 修复升级过程中的运行时保留及目录链接清理问题。

## 下载与安装

- **完整安装包：Stable-Setup-1.0.01-x64.exe**，适用于首次安装、正常覆盖安装或运行时修复。
- **轻量更新包：Stable-Update-1.0.01-x64.exe**，适用于已有完整运行环境的安装。
- `latest.yml` 和 `.blockmap` 用于应用内更新。

支持 Windows x64。安装器保留现有用户数据目录；公开安装包不包含个人数据库、账号凭据、浏览器登录状态或对话记录。

发行标签及文件名使用 `v1.0.01`；构建和更新比较使用合法语义版本 `1.0.1`，以兼容不允许补零版本段的构建系统。
