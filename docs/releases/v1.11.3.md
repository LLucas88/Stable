# Stable v1.11.3

本版本汇总 v1.11.2 以来的客户端功能和修复。

## Design 图片创作

- 参考图片随生成请求传入图片编辑接口，并在排队、澄清和重试期间保持一致。
- 业务规格不再默认增加留白；无法同时保留内容、比例并铺满目标尺寸时，先让用户选择裁切、留边或扩图。交付前检查实际尺寸、图片数量及文件大小。
- 面板参数及时保存，修复最近一次修改丢失的问题；图片生成模式在发送和澄清后保持用户手动选择。
- 需求理解与执行使用 GPT-6.1 Sol，思考程度设为高。
- 交付图片右键菜单增加“复制图像”，保留原始尺寸和透明度；参考图按钮增加适配主题的圆角描边。

## 技能与联网

- 技能市场资源改为登录后按需下载，安装包不再附带市场技能及插件资源压缩包。保留已有用户技能，并校验下载资源完整性。
- 改进浏览器禁网和网络权限处理；公开网页优先使用原生 WebFetch，支持长文分段续读，保留受审批约束的备用抓取方式。

## 启动、更新与界面

- 更新应用图标、启动 Logo、加载页和云端登录 Logo。
- 改进云端账号启动恢复与超时处理，增加诊断和修复入口。
- 更新前检查任务状态及未保存内容，改进安装准备、失败回滚和明确请求后的重启处理。

完整安装包和轻量更新包均通过 Stable Cloud 下载渠道提供，GitHub 保留源码和发布文件。发布验证使用隔离数据和模拟模型服务，不调用付费模型；真实生图质量不属于这些自动化检查的证明范围。
