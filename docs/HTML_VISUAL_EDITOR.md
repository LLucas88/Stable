# 本地 HTML 可视化编辑

上传附件后即可点击文件卡片在内置浏览器打开，无需先发送消息。工作区内的 HTML / HTM 文件也可直接打开，点击地址栏旁的铅笔图标。Agent 打开的本地报告也可以通过相同入口转到原文件编辑。

## 操作

- 悬停高亮，点击选择，Shift 点击多选，拖动框选。方向键选择父级、子级或相邻元素。
- 点击地址栏旁的「区域 AI 编辑」图标后拖出矩形，支持空白位置；松开后输入要新增的内容，Enter 或勾选加入聊天草稿。原 HTML、区域截图和要求随草稿一起提交，区域文档坐标、容器及周边元素在内部提示词中提供。普通拖动仍为元素多选；Esc 取消区域模式。区域截图只含当前可见部分。
- 单击选中元素；双击时光标落在鼠标点击的位置，进入文字编辑（包括带加粗、链接等嵌套内容的整段文字和脚本生成的文字）；Esc 取消本次文字编辑。支持字号、字体、颜色、粗斜体、下划线、删除线、对齐、行高、透明度、背景、边框及链接。
- 选中图片后可以替换、裁剪，或拖动右下角等比例缩放。工具栏紧贴选区，优先放在上方，空间不足时放在下方并约束在视口内；文字、图片、块元素和多选展示各自的操作。
- Ctrl+Z 撤销，Ctrl+Shift+Z / Ctrl+Y 重做，Ctrl+S 保存。文字输入状态下保留原生文本撤销行为。
- 点击「AI 编辑」展开输入框。输入修改要求，Enter 或右侧勾选按钮仅加入聊天草稿，由聊天输入框发送。附件为原 HTML 文件和所选元素可见区域的截图，修改要求写入草稿；选区详情由主进程关联并放入内部提示词，不再生成或展示「HTML 选区.md」；普通 Markdown 文件仍可手动上传。加入草稿会保留已有文字和附件，并收起浏览器全屏展开状态。

## 保存和图片

停止修改约 500ms 后自动保存。底部提示显示「已自动保存」；保存失败同样在底部显示错误。已移除蓝色状态栏及添加注释功能。Ctrl+S 可重试保存，地址栏的下载图标可另存副本，刷新图标可重新载入。切换预览或关闭应用前收集正在输入的文字。保存失败时不销毁编辑内容；草稿位于工作区 `.stable/html-editor/`。再次进入同版本文件时可恢复草稿；已有外部冲突的草稿保留在目录内，当前会话可另存副本。

以 `report.html` 为例，替换图片和裁剪结果写入 `report.assets/images/`，HTML 使用相对路径。原图保留，`report.assets/images.json` 记录裁剪结果对应的原图，重启后仍可重新裁剪。另存副本同步复制编辑器管理的资源，并更新 HTML 和原图索引中的引用。它不是通用网站打包器，不会收集报告已有的所有外部 CSS、脚本等资源。

支持 PNG、JPEG、WebP、GIF、SVG 替换，单图最多 10MB、4000 万像素。裁剪完全在本地执行并输出 PNG；GIF / SVG 裁剪后为静态图片。图片解码处理 EXIF 方向，缩放后的页面坐标不作为原图像素直接使用。

## 源码和权限

静态元素通过 HTML 解析器定位源码片段；包含脚本的报告同时保存修改记录，避免脚本重绘覆盖已经保存的文字和样式。脚本生成的元素和富文本使用受限的可视化修改记录，在页面渲染后恢复用户修改；不把图表运行后的 DOM 重复序列化进源码。生成元素删除时隐藏该元素，以保留其他记录的同级位置。未修改的脚本、换行和 BOM 保持不变。写入前检查文件哈希和可写目录，使用同目录临时文件替换原文件。检测到外部冲突时保留草稿；干净且没有正在操作的会话会重新载入 AI / 外部更新，并重置历史。

支持工作区可写目录及当前对话主动上传的 UTF-8 HTML / HTM（最多 20MB）。上传授权只允许所选文件及报告的相对静态资源，不开放相邻 HTML 文件，也不跨对话共享。只读项目文件不获得额外写权限。页面只接触隔离世界中的 DOM 编辑脚本，不获得 Node 或 IPC 桥。

静态和动态 HTML 文字都可直接编辑，富文本保留内联结构，并支持选中文字的一部分修改格式。Canvas 绘图的数据仍通过 AI 修改；`picture` 响应式图片通过 AI 修改。远程图片需先替换为本地图片再裁剪。

## 实现位置

- `src/BrowserPanel.tsx`：编辑入口、状态、会话恢复与 AI 交付确认。
- `src/App.tsx`：草稿与现有聊天队列接入。
- `desktop/services/html-edit-runtime.cjs`：隔离页面工具栏、选区、文字、历史与裁剪交互。
- `desktop/services/html-editor-toolbar.cjs`：紧凑选区工具栏及弹出菜单。
- `desktop/services/html-editor-overrides.cjs`：富文本校验和动态修改的本地持久化。
- `desktop/services/attachment-previews.cjs`：当前对话上传文件的精确预览授权。
- `desktop/services/html-source-patch.cjs`：源码定位、受限修改、版本冲突与原子写入。
- `desktop/services/html-editor-images.cjs`：本地图片导入、原图索引、隐藏 Chromium 解码和裁剪。
- `desktop/services/html-visual-editor.cjs`：会话、自动保存、恢复、截图附件、另存副本。
- `desktop/main.cjs`：认证 IPC、原生视图保留和退出保护。

## WorkBuddy 设计依据

核对本机已安装版本的解包代码（只读）后独立实现：`index.esm-DM6e0-UB.js` 的浮动工具栏为 32px 高、4px 间距、10px 圆角，位置按选区中心计算，距选区 8px，按 text / block / image / 多选分组；`injected-dom-runtime-1.js` 使用渲染后的 DOM 和富文本 contenteditable。Stable 使用相同的交互分组与紧凑样式，保留自身本地图片保存和源文件冲突检查。

可选实文件回归：`STABLE_EDITOR_REPORT` 对应打杂陈经营复盘报告，`STABLE_EDITOR_HASH_REPORT` 对应齐品达经营分析报告；设置为各自 HTML 的绝对路径后运行测试。后者验证 `#s2` 锚点跳转后仍能保存并加入聊天。测试只复制该文件到测试目录，并校验原文件哈希未变。
