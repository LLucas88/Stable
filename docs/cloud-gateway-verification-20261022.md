# Stable Cloud 对接修复与验证（2026-10-22）

## 原因与改动

- 浏览器截图经 Claude Messages 转成 Chat Completions 后位于 `role: tool` 的 `image_url` 内容块中。当前网关只接受用户消息中的图片，因此返回 HTTP 400。Cloud 本地代理现在保留完整工具响应批次和调用 ID，把图片无损附在紧随其后的用户消息里，并注明它来自工具证据。直连模型路径不变。
- SDK 错误结果的 `errors` 可能为空，真实 API 错误位于 `result`；原代码因此显示笼统的 SDK 执行失败。现在保留最近的脱敏提供商错误，并回退读取 SDK 的 `errors`、`result` 和 subtype。成功请求清除旧错误。
- 提供商明确拒绝的 400/401/403/404/413/422 立即通过现有失败链路结束，避免 SDK 原样重试。429/服务暂不可用仍保留恢复机会。本机未授权请求不能终止运行中的任务。
- Cloud 代理现在将本机请求断开和代理关闭传递为上游 AbortSignal。该验证只证明取消信号已传递，不代表远端服务已停止计费。

## 验证

- 114 项相关回归通过：Cloud 账号恢复、登录失效、模型路由、额度错误、Chromium 传输、流式响应、思考参数、启动恢复、Claude 错误及重试机制。
- 真实 Claude SDK 本机集成：截图经过 SDK → Messages 桥 → Cloud 代理 → 严格校验的本机模拟服务，图片字节和调用关联保留；完成截图检查记录后正常结束。另验证真实 SDK 遇 HTTP 400 只发送 1 次请求并保留具体错误。模拟服务不代表真实模型推理。
- 原账号真实在线验证：`/api/account`、`/v1/models`、`/api/usage/summary` 均 HTTP 200。凭据仅在内存中解密使用，原账号和会话历史未修改。
- 将原报告用隐藏 Electron 窗口截图，经生产 Messages 桥和 Cloud 代理发送至 `deepseek-flash`。仅 1 次生成、输出上限 1024 token，返回 HTTP 200；实际返回用量 input_tokens=1356、output_tokens=99。没有取得货币费用，不能据此声称免费。
- 模型读出了图片中的月度净G 378.3万（-5.1%）、日均订单 6,216（-8.8%）、日均净G 12.61万（-2.0%），与截图一致。品牌文字“打杂陈”被识别成“打杂阵”，因此仅确认截图传输和视觉读取成功，不代表 OCR 全部准确或报告已验收。
- 本地 `npm run build` 成功。验证结果和截图位于 `.local/cloud-screenshot-verification/`，不纳入 Git。
