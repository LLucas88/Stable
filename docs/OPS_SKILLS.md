## 使用

用本分支启动 Stable，进入“技能市场 → Skill技能”。分类按钮可筛选，卡片显示当前状态；点击名称查看原文和依赖原因，启用技能可在对话中试用，也会进入每次至多 4 项的自动检索。

中文别名用于展示和检索，原始 ID 不变。已验证“会员复购电商活动策划”“订阅 MRR CAC LTV”“用户访谈研究综合”“会员权益文案”分别优先命中对应技能。用户明确引用优先于自动检索。

飞书停用和缺依赖限制同时在市场接口与旧技能接口执行，不只是界面按钮置灰。要开放某个等待适配的技能，应先提供其真实依赖、完成运行验证，再更新 ops-skill-bundle.cjs 中的兼容策略并重新运行安装命令。不得只因工具名称相似就宣称已兼容。

## 重现安装

在 Stable 仓库目录运行以下命令，两个路径改为目标机器的真实路径：

    node scripts/install-ops-skills.cjs --source "E:\merged-ops-skills-20260906\delivery" --user-data "C:\Users\25702\AppData\Roaming\stable-desktop"

安装器通过 Stable 自带 Electron 运行时执行，并获取目标数据目录的单实例锁；客户端运行时会拒绝安装。它先核验 2,245 个原件文件，完整复制到 .local/ops-skills/20260906，再在只读校验和 SQLite 一致性备份后初始化数据库，事务登记技能。已有目录与输入版本不一致时停止，不覆盖原件。重复运行不会增加重复条目，但会将仍在库的技能重新应用本次启用策略；不会自动恢复已删除条目。

开发启动读取仓库根配置；正式打包实例只读取其 userData 下的同名配置。迁移到新机器时按目标位置重新安装，不直接复制含旧绝对路径的数据库。原目录有资源引用关系，不能平铺 SKILL.md，也不能将同名飞书套件覆盖合并。

Stable 使用自己的技能登记及按需检索，将原文和绝对资源目录送入 Harness。本次没有往用户全局 .codex/skills 安装，也没有让 Codex 自动扫描所有 178 项；不同会话的 Codex HOME 继续保持现有隔离机制。

## 停用与恢复

日常停用兼容技能直接在市场详情中关闭；移除登记用“删除”，原文件保留。当前飞书停用策略在启动时仍会强制执行。

若要整体停止此包，先在市场逐项停用或通过 StableStore 批量对带有 bundle=ops-20260906 的条目调用 setSkillEnabled(id,false)，再移走本地配置以停止启动同步。只移走配置不会自动关闭已登记技能。不要删除其他用户技能或覆盖整个 settings 表。

安装前数据库快照用于最后手段恢复。整库恢复会丢失快照之后的对话和设置；应先关闭 Stable、备份当前数据库及 WAL/SHM 文件，再在确认需要时恢复。优先采用技能级停用或移除。
