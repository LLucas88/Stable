# Design 输入模式与 FlashX 路由验收

2026-10-26，`D:\stable` 当前源码。仅本地修改、构建和离线验证；没有真实模型或生图费用，没有推送、部署或打包安装包。

## 本次行为

- Design 删除对话模型选择器。“图片生成”和“对话”两种模式均使用 GLM-5.3-FlashX；新会话创建时选定，旧 Design 在下一次正常发送时选定。不会更改普通会话或全局默认模型，不中断正在运行的任务。若 FlashX 不可用，明确提示配置/启用，不默默退回 DeepSeek。
- 左下角增加“图片生成／对话”下拉菜单。新建 Design 默认图片生成；发送生图消息或加入队列后切回对话，保留草稿中的生图设置供下次主动切换使用。已存在且有历史的 Design 重新打开默认对话。
- 对话模式使用普通输入框及附件/权限工具，不显示尺寸、分辨率、张数，也不提交这些参数。后端不再用会话保存的生图设置填补本条消息缺失的参数。
- 生图消息下方显示该条消息的尺寸（px）、分辨率档位和张数。自定义尺寸标记“自定义”，避免把任意尺寸错误标为标准/2K。排队消息也显示自己的参数快照。
- 参数作为用户消息的结构化 trace 保存，不拼入用户原始文字。沿用现有 JSON 字段，无需迁移数据库；修改下一条生图参数不影响旧消息，关闭并重新打开数据库后快照仍保留。旧历史没有保存参数的消息不猜测补填。
- 生图请求如果需要澄清，回复继续同一请求时保留原参数；已完成后的普通对话不继承参数。取消尚未发送的生图并恢复草稿时，恢复对应输入模式和参数。
