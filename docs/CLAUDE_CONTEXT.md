# Claude 工具上下文去重

Messages 适配层在发送模型请求前，通过 `desktop/services/claude-context.cjs` 对工具证据去重。原始 SDK 历史、工具执行、审批、对话展示和用户附件保持原样。

- 工具图片在数据 URL 内容完全相同时引用当前请求中第一份图片；不同图片和远程 URL 不合并，不降采样。
- Claude 浏览器截图在可写任务中保存到工作区 `.stable/browser-evidence/run-*/`，返回 `screenshotPath`、SHA256 和重复截图计数。相同字节复用文件，但每次截图仍真实执行，不能把页面动态变化当成缓存命中。文件在本轮结束后保留；只读任务不落盘，保存失败也继续返回内联图片，且不宣称存在文件。
- 对具有已验证文件路径、类型和内容哈希的浏览器截图，当前模型请求保留最近三个不同画面；更早画面以真实路径和哈希索引代替内联像素，需要时用原生 Read 读取。文件丢失或被修改则保留内联图片。用户图片、未落盘图片、错误、原始 SDK 历史不受此窗口限制。此策略只减少本次发给模型的图片，不删除证据文件。
- 同一浏览器标签页和 URL 的 `text`、`tables` 字段完全相同且达到 512 字符时，保留第一份，重复字段改为 `contextReferences`。每个结果的控件、ref、视口、截断标记、限制说明、操作状态仍完整发送。
- 原生 Read、Grep、Glob 的工具名、参数和长文本回包完全相同时，重复文本引用前一份；实际调用仍执行。命令回包和错误不压缩。
- 引用表与最近画面集合仅存在于一次请求内。SDK 压缩、会话恢复或切换会话后，根据该次保留的消息重新建立；精确去重引用不会指向已被移出的内容。历史截图文件索引依赖回包中实际保存的证据文件，每次生成索引前核实文件内容。
- 保留工具调用 ID、调用与回包顺序、模型推理续接和用户消息。引用文本不是新的网页内容，网页原有 `untrustedContent` 标记保留。
- 真实 SDK 会给工具回包附加独立提示块；适配层先保留块边界完成去重，再合并纯文本回包，避免 JSON 与提示拼接后无法解析。附加提示不丢弃。

HTML 检查提示要求维护有限验收清单，先定位目标，再按尚未确认的视觉问题拍摄；相同状态复用已有截图，修改后仅复查受影响项目，检查通过及时交付。截图及每八次成功浏览器操作的回包附带检查进度提示，不以次数断定完成、不跳过工具调用，也不强制提前结束。提示不能保证模型每轮都选择最少调用，因此真实对照需要同时检查产物质量。

Claude 的 `stable_browser` 额外接受可选 `purpose` 和 `reviewUpdates`。它们只用于本轮模型检查记录，不传给共享浏览器、审批参数或界面事件，不改变原有浏览器操作。每次成功回包附带 `reviewNotebook`：最多 24 项模型自述结论，以及最近 12 条截图/布局测量证据（证据 ID、视口、历史页面版本和可读路径）。记录可随必要操作提交，也可在看完最后一张图后用 Claude 专用 `action=review` 更新；该操作不重新操作页面或截图。超过清单上限会提示更新已有项，不静默丢弃未解决项。被检查项引用的证据不会因无关截图被淘汰。

出站上下文只保留同一 scope 的最后一份完整检查记录；旧回包的记录用稳定提示代替，保留其自身截图路径、控件和观测。原 SDK 历史不改写。稳定提示不随末尾调用 ID 变化，避免重复破坏前缀缓存；压缩后只有一份记录时完整保留。

SDK Stop 钩子在视觉检查没有记录、或有 open/needs-recheck 时，把未完成项交回模型修复、复查和更新，不新增用户轮次。最多三次收尾反馈，同一未完成状态最多两次反馈；仍未解决以未完成错误结束，不伪装为成功。主动停止、待接收用户输入和澄清卡片不触发该保护。真正受权限/数据限制的项可记为 blocked，并在交付末尾明确列出，不能把可修复缺陷直接当作素材限制。该记录不独立证明视觉质量，仍需产物验收。

`passed` 必须引用同标签页、同打开/导航版本的证据；已保存截图文件需仍存在且哈希一致。只读/保存失败时可引用本轮实际返回的内联截图。页面重开、导航或文件失效会使相关通过项变为 `needs-recheck`。其他标签页、缺少证据的结论不能标为通过。外部文件编辑、异步网页变化和检查范围是否完整不能由此记录自动判断；模型需显式将受影响项标为待复查。记录是当前运行内的有界状态，新运行不会自动恢复此前的通过结论；原 SDK 工具历史仍保留。

共享浏览器 audit 增加最多 40 张当前显示图片的固有/显示尺寸及三层容器几何；容器下方空间只作为观察，不自动判定留白错误，不包含图片 base64 或页面脚本执行能力。

验证入口：`tests/claude-context.test.cjs`、`tests/claude-tools.test.cjs`、`tests/claude-messages-bridge.test.cjs` 与 `tests/claude-sdk-integration.cjs` 的 browser evidence 专项。覆盖路径可读、真实 SDK 原生 Read、文件缺失/变更回退、只读模式、链接目录边界，以及压缩后原始图片恢复。

Claude 专用 `stable_browser action=batch` 可将同一标签页中已明确的 read/resize/scroll/click/screenshot/audit 合为一次模型调用，最多 12 步和 4 张截图。每步仍走原处理器、逐次审批、取消和界面事件；拒绝、错误或导航时停止后续步骤并保留已有回包，不自动重试。没有脚本执行、自动发现新目标或跳过验证能力。唯一完整 `label` 只能来自此前观察的控件，并按最新快照解析为 ref；重名、不可见或未知名称返回错误。

批量结果标注 `batchStep`，保留全部截图和 audit 测量、最后一份控件快照及检查记录，省略中间已失效控件和重复正文。每张图继续落盘并验证哈希，出站最近三图策略按单张证据处理，不因一次回包有多图而失效。批量成功仅表示操作完成；模型仍须逐图判断、修复并提交 review。该能力不改变 main 的共享工具 schema 或界面。

audit 的隐藏元素、图片几何、图表、浮层和溢出数组采用与正文相同的请求内精确去重：只有同页同字段完全相同且超过 512 字符才引用早前结果，变化后的测量和当前视口完整保留，压缩后重新建立引用。

原生 Read 返回的图片也参与最近三个不同画面的证据窗口。适配层将 SDK 实际返回的像素（可能已经缩放，不能拿源文件冒充）按 SHA256 保存到会话内部 `tool-images/`；该目录仅加入原生工具的可读范围，不增加可写范围。旧图用确实可读且内容一致的文件索引代替，原图被删除后仍可回看。归档失败、文件被修改、目录链接或非法数据时保留内联像素，不覆盖可疑文件。用户上传图片与错误回包不归档。会话清理规则和原始 SDK 历史不变。

截图附带 `viewport` 及 `captureLayout`：当前视口内最多 12 张图片的固有尺寸、显示尺寸、三层容器空间和文档宽度，复用已有只读 audit 测量。截图与 DOM 测量紧邻执行，动态页面仍可能变化；测量失败保留截图和错误说明。只提供观察，不自动判定留白错误或替代视觉验收，也不发送整页隐藏元素清单。

SDK 还可能缩放或重编码浏览器 MCP 截图，而原始 `screenshotArtifact` 元数据保持不变。此时核实原始文件后，另将 SDK 实际返回的图片字节归档到 `tool-images/`，使用自己的格式与哈希参与三图窗口；不拿原始文件冒充已变换画面，不改变像素或删除原件。归档失败则仍保留内联图片。

`open` 的可选宽高与 `resize` 一样持续设置视口，避免参数被静默忽略；省略宽高时保留原行为。共享工具 schema 明确 scroll 的正负相对像素、locate/wait 的文本含义及 key 的可用按键，不扩展原生按键权限。

audit 与截图附带 `typography` 的中文短标题/控件行测量：最多80项、4096字符、20条末行单字候选，跳过隐藏、竖排和长段落。它是只读测量，显式换行或品牌设计也可能产生候选，不能直接当作错误或文字可读性验收通过。像素截图和原始文字保持不变。

Claude 检查记录按标签页、视口宽度和文字身份保留每条换行候选，自动加入 open 待复核项；切换区域出现其他标题不能覆盖早先未处理的标题，重复观察同一条也不会新增检查。确认其他检查不能消除它；标 passed 需要引用候选出现之后、同页面版本及同宽度的证据。测量已无候选时也仍需模型明确复核；有意排版需结合当前证据说明理由。达到24项记录容量仍有新候选时会显式报告超限并阻止静默成功，收尾次数保护保持原规则。该机制防遗漏，不代替独立质量验收。

batch 顶层可携带 purpose 和 reviewUpdates：检查记录在批量步骤之前更新，只能引用已有证据，不能提前通过尚未看到的新截图；purpose 仅补充未指定用途的步骤。失败、取消和逐步审批仍沿用原逻辑，可减少单独更新记录的一次模型往返。

完整 read/open 与 audit 提供最多80张图片的 imageInventory：浏览器已解码固有尺寸、加载状态和布局显示状态，包含隐藏画廊图片；不读取像素或数据URL，也不证明隐藏画面的布局正确。完全相同的长清单参与请求内精确去重，尺寸或加载状态变化时保留新清单，减少模型自行解析内嵌图片的准备工作。

audit 与截图的 imageSpacing 提供有界留白候选：检查已显示图片三层内的单图裁切/滚动容器，跳过透明祖先、图注文字、生成内容和底部内边距；只报告明显空余高度，并说明扫描上限。候选不是缺陷判决。Claude 按页面、宽度及图片容器身份加入待复核记录，切换画廊不清除未解决项，标为通过仍需同宽度的新证据和模型判断。多图容器、图片像素内部留白和截断扫描仍需视觉检查。

截图的 captureLayout.images 保留当前视口图片和三层容器的必要几何，去掉重复祖先正文及非必要样式；完整 audit 仍可查询原始测量。截图附带的文字/留白候选覆盖当前显示区域的 DOM，可能位于视口下方；不得把当前截图误当作已经查看候选所在位置。执行提示优先复用尺寸清单、批量明确步骤和同根因修复，要求覆盖短图、长图及交互状态，不以裁图、缩字或强制提前结束换取速度。

留白候选标为 passed 时，引用测量必须实际覆盖相同图片容器，且不再报告该容器空余高度；其他画廊、缺少测量或仍有候选不能通过。模糊背景和装饰填充不算修复容器高度。受真实外部约束的情况可明确标 blocked，原收尾保护与不完整交付提示保留。
