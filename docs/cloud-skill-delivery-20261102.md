## 实现

- 617 个技能按 44 个完整来源包分发，另有 2 个业务插件包、10 个插件技能入口。保留共享文件和相对引用，仅启用用户选择的技能。
- 46 个资源包共 67,138,962 字节（约 64.03 MiB）；随客户端锁定的目录约 1.14 MiB。
- 客户端沿用已登录账号和现有网络传输，拒绝跨域重定向，校验大小、包和逐文件 SHA-256，再原子安装。
- 下载失败或超时不会登记技能；已安装资源可复用；缓存被修改时不自动覆盖。
- 旧资源完整时由后台 worker 复制到用户缓存，保留技能 ID、启停状态、用户文本及会话引用。写回前重新检查并发修改。资源缺失且托管文本未改动时，可在选择技能时重新下载；存在用户改动的缺失资源需要先解决冲突。
- 私有服务监听回环端口 18882；每次下载通过现有账号接口验证设备会话，支持 GET/HEAD/单段 Range。文件目录不得映射到公开更新下载路径。
- 提供 `build/cloud-skills.config.cjs` 和 `build/cloud-skills-update.config.cjs`，均排除两个插件 ZIP 和筛选技能副本，保留专家与运行时依赖。未运行正式打包，默认配置和更新通道未切换。
- 本地源码验证需同时设置 `STABLE_CLOUD_ENABLED=1`、`STABLE_SKILL_DELIVERY=cloud`；开发模式的云端账号开关默认关闭。云端包配置会写入下载模式元数据。
