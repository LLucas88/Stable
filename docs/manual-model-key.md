# Stable：用户自行配置 API Key

1. 点击左下角账号菜单 → **模型连接**。
2. 选择预设模型或已保存的连接，粘贴供应商 API Key。
3. 点击 **加密保存并使用**。下次启动无需再次输入。
4. 其他供应商可选择 **自定义连接**，填写服务 ID、显示名称、API 基础地址、实际模型 ID 和 Key。

当前提供 DeepSeek Flash 预设（`https://api.deepseek.com` / `deepseek-flash`），参数按 [DeepSeek 官方文档](https://api-docs.deepseek.com/zh-cn/) 核对。已有连接也会继续显示，不会删除原配置。

保存后输入框清空，页面只显示“已加密保存”；在原连接留空保存会保留原 Key，填写新 Key 会更新。更改 API 地址时需重新输入 Key。
Key 使用 Electron safeStorage 保存到当前 Windows 用户的应用数据目录，不作为明文写入模型目录、数据库或公开状态，也不会回填到界面。

默认模型用于新对话；已有对话可在输入框切换模型。保存成功代表本机加密存储成功，供应商连通性和模型权限需发起实际任务验证。

本版不再展示设备申请、签发、导入配置包入口，也不再自动处理旧配置 EXE 写入的待导入文件。请直接在应用中填写。
更换 Windows 用户或迁移到其他电脑后，需重新填写 Key。
