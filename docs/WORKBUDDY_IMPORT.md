# AI 应用数据导入

实际运行目录：`D:\stable\.local\cluade-sdk-bash`，版本 1.1.0。修改源码和本地构建，不制作安装包。完全退出旧进程（含托盘）后，`npm start` 加载新代码。

## 界面与操作

设置 → 数据导入 → WorkBuddy / Codex → 导入。
一级页为应用列表和导入历史，二级页为两组卡片、五类选择：技能、连接器、记忆、项目、聊天会话。点击分类进入条目列表，点击名称预览；会话内可展开附件与产物。默认不选任何内容，选择会话会一并选择可用关联文件，仍可取消单个文件。项目独立选择。只显示标题、数量、操作及必要的失败/缺失提示。

## 会话与旧数据转换

- 新导入的会话直接创建为本地 Stable 对话，标题无应用前缀，直接使用正常输入框；采用新的运行上下文与请求审批模式，不迁移源端权限、运行会话或工具调用。
- 仅当前分支的用户输入和最终回答进入消息列表及历史上下文。排除 reasoning/thinking、分析通道和工具执行过程。WorkBuddy 的工具前普通助手文字按执行顺序排除，不按英文或关键词猜测；外层消息带有 `message.usage` 时仍读取外层最终回答。
- 新导入记录不保存原始思考日志，仅保存筛选后的问答。扫描时私有临时快照用于校验，下一次成功扫描会清理旧快照。
- 启动时处理旧 `source_type=workbuddy` 的存档。先验证原始快照并备份原会话、消息、原始 JSONL、导入元数据，再在同一对话 ID 下转换；保留原项目绑定与文件副本。备份位于 Stable 用户数据目录的 `migration-backups/<conversationId>-<uuid>/`。
- 每条旧记录独立事务；读取、校验或写入失败时保留旧记录，并在导入页显示错误。已转换会话不会重写，用户后续新增消息不受影响。旧快照及备份不作为新对话上下文。
- 长历史另存为可检索的问答文件，续聊时按需读取。记忆/偏好导入知识库，初始不启用；技能手动调用。

## 来源与边界

WorkBuddy：扫描当前用户 `.workbuddy` 或手选备份目录；数据库与 WAL 使用一致私有副本；JSONL、明确引用的附件/产物、记忆、技能和已使用连接器配置可识别。原项目目录不递归复制，不获得额外授权。

Codex：默认读取 CODEX_HOME 或当前用户 `.codex`，也可选择数据目录或 sessions 日期子目录。读取 sessions / archived_sessions 的 JSONL，使用 session_index 标题和本地项目映射；导入用户问答，过滤子代理、系统上下文、思考、commentary 和工具记录。旧格式回答仅在 task_complete 明确确认后导入。技能读取 skills 下可用 SKILL.md；记忆读取 AGENTS.md 与 memories 中 Markdown；连接器仅识别 config.toml 的静态 HTTP URL，凭据不迁移。扫描不读取 auth.json、不修改 Codex 数据库，不访问云端历史。ChatGPT 导入入口已移除，历史记录与已导入对话保留。

附件仅复制本地可读文件。ZIP 路径穿越/链接拒绝；重复文件名不能唯一匹配时标为不可用。云端链接或导出包未包含的文件不会自动下载。单个文件 50 MB、单会话/JSON 100 MB、Codex 会话扫描总量 512 MB（按最近更新时间排序，超限明确提示，可分目录扫描）；其他导入总量 256 MB、最多 5000 条目，预览最多 6000 字符。

连接器：只迁移可识别 HTTP/SSE 声明，去除 headers、环境凭据、URL 用户信息/查询参数及原工具授权；保存为未启用模板。导入历史 → 配置 → 补填 Authorization 和准确的允许工具名称 → 保存并启用。未授权的其他扩展不会连带开启，stdio 或未知格式需手动重新配置。启用保存配置不代表服务已连通。

相同来源与内容再次导入会跳过；来源改变创建新副本。仅手动导入，无自动同步。

## 本轮验证

- 单元/集成样本覆盖当前分支、最终回答、附件复制、原位转换与备份、回滚、幂等、连接器凭据隔离、ChatGPT JSON/ZIP/本机缓存样本和路径穿越。
- 隐藏 Electron 独立窗口走真实设置组件与导入 IPC：应用入口、五类卡片、预览、选择、导入、打开同一原生对话；检查深浅主题和窄窗口。
- 本机 WorkBuddy 的 5 个真实 JSONL 只读解析；没有改写源数据或运行中的 Stable 业务数据库。
- 本机 Codex 目录已只读扫描：23 条可导入会话、6 个项目、26 个技能、63 份记忆、86 个可读文件；超 100 MB 的单条会话和缺失文件未导入。未修改源数据或调用付费模型，真实模型续聊质量尚未实测。

## 本版默认模型

启动完成旧数据恢复、本地配置导入后，执行一次 `flashHighDefaultV1` 迁移：所有已有对话和默认模型改为官方 DeepSeek-Flash，思考程度设为 high。模型选择旧值留存在设置备份中；不改变历史、权限和凭据。新对话继承默认模型及 high；迁移标记防止重启覆盖后续手动选择。缺少 Key 提示补填，Cloud 未提供 Flash 时明确报错，不自动切到 GLM。
