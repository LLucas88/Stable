# Design 输入框调整验收

- 上传图片复用普通聊天的布局与缩略图样式，移除固定窄外框、旋转和两列网格覆盖。横图、竖图并排，图片不溢出外框或遮挡底部工具栏。
- 尺寸面板增加比例图标、分辨率分段选择、W/H 数字输入和比例锁定。宽高编辑失焦或按回车后自动调整到 512–2048 范围内最近的 32 倍数，显示实际结果。锁定时联动另一边并受两边范围约束；取整可能造成小幅比例偏差，以显示的实际像素为准。
- 自定义宽高随会话设置、发送和队列快照传递；后端重新校验，生图工具强制使用该尺寸。旧会话只有预设比例时仍兼容。
- 删除输入框“按次计费”说明及张数弹层的计费文案。删除“生成背景 + 原图合成”入口，当前 UI 统一为图片生成；历史记录不重写。

验证：TypeScript 与 Vite 构建通过，36 项相关回归通过，最终样式调整另复跑隐藏完整 App 用例。覆盖尺寸自动取整、比例锁定、边界限制、后端拒绝非法参数、模拟生图请求实际尺寸、横竖参考图几何布局、参数发送与队列隔离。

隐藏离屏窗口不产生原生失焦事件，因此用相同的冒泡 focusout 事件验证 React 失焦处理；输入、渲染和参数传递均使用真实组件。

本轮无付费模型调用，无账号或原历史数据写入，无远程推送或安装包发布。当前源码及本地 dist 已更新，运行中的客户端需重新加载前端并重启主进程。
