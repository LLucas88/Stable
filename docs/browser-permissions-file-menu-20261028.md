# 浏览器资源提示与产物右键菜单修复

日期：2026-10-28。修改当前 D:\stable 源码；未打包、部署或推送。

## 浏览器问题

原实现要求每个跨域子资源的 origin 都先获得站点授权，同时在正文上方逐条展开全部被拦截请求。因此图片、字体、样式和脚本 CDN 会产生大量提示并挤占预览区域。

修复：

- 已授权页面的公共图片、字体、样式、脚本和媒体 GET/HEAD 请求可以自动加载。
- 自动加载只适用于静态子资源，不会把这些域名写入会话站点授权，不会顺带授予导航、iframe、XHR、WebSocket、下载或设备权限。
- 地址及 DNS 校验拒绝未授权的本机、私网、保留地址、混合公网/私网解析、凭据 URL、非标准端口和解析失败。DNS 查询有超时、并发共享和短期有界缓存；这不是独立网络沙箱或 DNS 绑定机制。
- 剩余请求按 origin 去重，默认折叠为一条提示；展开列表限制高度并可滚动。新页面导航清理旧请求，文件标签不显示网页请求。
- 手动允许站点后，提示说明需要重新加载页面；避免自动刷新丢失网页上正在填写的内容。

## 产物菜单

Markdown 文件链接与文件卡片共用菜单：打开文件、打开方式、外部浏览器打开、另存为、复制路径、复制文件内容、资源管理器定位。

- 打开文件保持 Stable 内部预览。
- Windows 打开方式通过 SHOpenWithDialog 选择应用；默认浏览器通过 https 协议关联取得可执行程序，不再依赖 HTML 文件关联。
- 本机只读核实默认浏览器为 chrome.exe；未启动外部应用或弹出系统选择窗口进行交互验收。
- IPC 限于主界面发起，所有文件操作校验工作区/已登记附件路径。复制内容限支持的文本格式、2 MB 以内，拒绝二进制与无法识别的编码。
- 支持取消另存为、原文件/硬链接覆盖保护、失败提示、键盘菜单、Escape 返回焦点与窗口边缘防溢出。
