# 一键更新本地验证（2026-11-02）

范围：D:\stable 本地 main。未发布、未推送、未制作正式安装包、未更新现有设备。

## 行为

- 设置页和侧栏的“一键更新”共用入口：检查 → 下载（显示进度）→ 安装 → 成功后启动客户端。
- 后台定时检查仍可提前下载；只有用户点击一键更新才会安装，普通退出不会自动安装。
- 点击时及下载完成后各检查一次任务和草稿。有运行中的 Agent、自动化、协作、脚本或工作流，或打开的 HTML 编辑会话时，先提示处理。
- 渲染进程在安装前保存输入草稿、附件引用和发送队列；未提交的设置、消息编辑或上传、保存失败、界面无响应时阻止安装。主进程验证回应来源并再次检查任务状态。
- 下载已完成但安装条件不满足时保留下载结果；处理后再点击即可继续。重复点击不会重复下载或安装。
- 安装器在原有运行时健康检查、原目录备份与失败回退之后，成功路径根据 `--force-run` 启动客户端；失败路径不会启动新版本。

## 验证边界

Electron 场景将安装器启动替换为参数断言，不操作真实安装目录；NSIS 场景使用隔离的模拟运行时与启动标记。因此已验证界面、IPC、更新控制和安装器分支，没有声称完成新正式包的真实覆盖安装、UAC 或完整客户端重启验收。发布前仍需对正式候选包做一次真实升级与启动验收。

第一次运行隐藏 Electron 登录场景时，“错误密码提示可见”断言曾超时；单独复跑和最终五场景全量回归均通过，原因未被确定，不能将其归结为已修复的登录故障。

现有安装在其他设备上的旧客户端不会因本地源码修改自动获得该功能。旧客户端启动安装器时没有传递强制启动标记的场景，也不属于此次新入口的自动启动保证。
