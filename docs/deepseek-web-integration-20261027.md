模拟测试确认：选择 GLM 对话时可以执行 DeepSeek 搜索与抓取，两次工具调用只产生两次对应工具接口请求，不额外调用 DeepSeek 聊天模型。成功请求按各自价格结算，空结果不计费，重复键不重复请求，402、Stable 额度不足、限流、抓取安全拒绝及无正文有明确区分。

回归过程中修正了旧测试前提：简单问答已跳过额外前置调用；联网工具测试必须明确允许联网；数据库约束测试应逐名核验既有约束，允许新增业务触发器。没有放宽产品权限或账务约束。

本轮真实模型、搜索和抓取费用为 0，未访问原账号历史，未改生产数据。离线测试不能证明供应商实时连通、余额充足或真实网页抓取质量。
