## 本轮变更

- 原生工具失败钩子根据上述错误类型向模型提供固定、针对性的恢复指引，保留原始失败记录；不自动执行重试、不扩大权限、不把外部错误文本升级为指令。中断和取消不追加恢复建议。
- Python 指引补充版本兼容、文件依赖顺序、真实表头和字段契约、缺失值与校验口径；不允许用补零、删除断言等方式掩盖问题。
- Edit 保持唯一匹配保护，明确要求重新读取并使用唯一上下文。
- 浏览器明确说明旧引用失效原因，要求使用最新 controls，保持引用校验及敏感操作限制。
- Trace 分别显示工具失败数与任务最终状态，展开后展示调用输入、执行结果，避免把历史中间失败误读为任务最终失败。
