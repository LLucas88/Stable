## 已实现的行为

| 项目 | 实施结果 |
| --- | --- |
| 参考图直传 | 点击发送时读取已授权附件，按真实文件内容识别 PNG/JPEG/WebP，固定原始字节及 SHA-256，保存在会话私有目录并生成工作区预览。排队执行及澄清续接使用同一版本；原文件随后变化不会改变本次输入。预览副本被改写会报错。理解模型读取该副本，GPT Image 编辑请求上传对应的真实图片字节。默认使用本次全部参考图，也允许使用工具参数中的已授权资源 ID 子集；不能指定任意文件路径。 |
| 默认留白 | 默认采用严格适配：同比例缩放，比例不符则保留 `.source.png` 原图并停止交付；不自动补边、裁切或拉伸。尺寸面板可明确选择“允许留边”或“允许居中裁切”。裁切目前为明确标注的居中方式，不提供自由拖动裁切框。扩图/重新构图需要用户明确提出新操作，不自动重试付费生成。 |
| 最终一致性 | 自定义尺寸与六种业务规格共用成品规格。生成阶段校验实际尺寸及文件上限；透明背景要求实际存在透明像素。助手最终回复前重新读取本地交付文件，检查 PNG 格式、实际宽高、大小、透明要求、数量和 SHA-256，覆盖本轮最后一次脚本改写。原图预览不能当合格成品；重复引用同一文件不能凑数量。失败同时影响历史任务状态和后续队列调度，不显示成功。纯讨论不会触发缺图错误。 |
| 面板参数入库 | 每次调整都独立保存，不再等待发送。按会话串行合并，SQLite revision 比较避免旧窗口覆盖新值；失败保留本地草稿并显示重试。未确认写入保存在本地恢复日志中。切换会话分别恢复；旧排队任务不回写最新偏好，取消恢复也不恢复旧参数。 |
| 理解与执行模型 | 保留此前已实现的固定 `gpt-6.1-sol` / `high`，覆盖 Design 理解、澄清与执行。 |
| 输入框模式 | 保留此前已实现的手动模式持久化；发送、澄清回答、任务完成和重新挂载不强制切回“对话”。 |

参考图限制：最多 4 张，单张不超过 10 MiB、合计不超过 20 MiB，最大边 8192 px、总像素不超过 3200 万。GLM 暂不支持该直传流程，带参考图调用时会明确报错，不能静默转成纯文字生成。希望保留 Logo/文字原像素时，仍应使用原图合成，图片编辑模型不保证逐像素保真。

文件校验是任务交付时的检查，并在生成结果复用时核对哈希；目前不提供交付结束后对外部编辑的持续文件监控。旧历史图片不批量重写。

## 云端实现及上线边界

新增登录保护的 `/v1/images/edits`，先鉴权再读取受大小限制的 JSON 请求；验证图片类型、大小和内容哈希，转换为供应商要求的 multipart `image[]`。请求指纹包含有序参考图数据，同一任务成功重放不再调用供应商；结果未知时拒绝再次提交。

计费分别核算文字输入、图片输入、各自缓存和图片输出。未配置图片输入费率时，在供应商调用前返回错误；预留按已配置输入上下文上限计算，结算使用供应商实际用量。该保守预留可能使低余额账号暂时无法发起图片编辑，不能把预留额说成实际消费。用量不一致、费用超过预留或持久化结果不确定时保留待核对状态，不静默重复生成。

价格依据为本轮查看的官方 [Sunburst 模型页](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst)、[Flare 模型页](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare) 及 [编辑接口](https://developers.openai.com/api/reference/resources/images/methods/edit)。迁移脚本从现有文字输入价格推导图片输入及缓存费率，保留现有币种换算；新增不可变价格版本，不修改历史价格、账单、账号或额度。

已批准的部署步骤：

1. 核实服务器当前版本和是否有进行中的请求；保留回退版本，再把当前 overlay 应用到独立发布目录并构建，不能直接覆盖正在服务的源码。
2. 用 `node tools/cloud-openai/enable-image-input-pricing.mjs <现有网关数据库>` 只读预览两种模型的新价格。核对无误后使用 `--apply` 建立版本；重复执行相同配置不会反复创建价格。该脚本先在合成数据库验证，再于本次上线中针对生产数据库建立两个新版本。
3. 切换发布目录并重启服务，验证登录保护、缺失参数、模型目录及接口可达性；这些检查不需要调用供应商。
4. 真实参考图效果、供应商用量和线上账单需另设预算进行端到端验收，本次模拟联调不能替代该验收。

步骤 1–3 已完成，云端接口和计费配置已生效；步骤 4 的真实付费生图验收未执行。客户端本地修复需运行本次源码/构建产物才能生效。
