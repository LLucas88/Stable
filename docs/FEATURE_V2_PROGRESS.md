### 历史与文件的行为

首次加载最新消息；“加载更早的消息”通过稳定序号向前翻页。滚动位置保存消息ID、偏移与序号，重新打开时按需补读旧页，等待布局稳定后恢复。搜索的长词使用SQLite trigram索引，少于3个字符的查询使用有界SQL结果回退；不将全库消息加载到JS后拼接。

项目重命名、切换查看和置顶不会移动工作目录。项目失联或目录身份变化时可继续查看历史，发送被阻止并要求重新定位。移除项目仅解除组织关系，保留原cwd和文件。

启动对账只读取运行时记录；只把已知thread/turn对应的最终回复补入一次，不重新执行工具。无法确认是否送达的消息明确保留为待核实，重复发送被阻止。清空后的记录不会被对账重新恢复。索引损坏或无法续接时，可在对话菜单选择“从本地历史重建上下文”，保留旧映射来源，下一次用户发送才建立新上下文。

删除先保存待删除状态，运行时确认成功后再移出本地活动记录及搜索索引，清理运行投影、发送日志、授权和指针，解除浏览器标签归属。运行中需先停止任务。同步失败保留可重试状态；“运行时已删除但本地未确认”会额外read核实不存在，再完成删除。

**删除不删除用户交付文件、全局登录profile和已有迁移备份。** 备份留在本机，不自动过期；不能将此操作描述为清除了所有磁盘副本。下载文件由原生完成事件、大小和目录身份校验确认；导入任务前再次检查文件是否变化。

### 审批能力矩阵

| 动作 | 运行时接口 | Stable处理 |
| --- | --- | --- |
| 命令执行 | item/commandExecution/requestApproval | 静态分类＋人工或显式兼容审核；批准前重算脚本/目录摘要 |
| 文件变更 | item/fileChange/requestApproval | 精确参数与目标进入请求；高风险转人工 |
| 网络与扩大权限 | item/permissions/requestApproval、sandboxPolicy.networkAccess | 联网边界独立保存，切换审核者不扩大联网权限 |
| 动态工具 | item/tool/call | Stable内置工具桥接；网页副作用动作单独申请 |
| 浏览器站点 | Stable共享profile请求拦截 | 用户导航或获批open允许目标站点；新增来源需明确许可 |
| 网页副作用 | Stable browser动作 | open/click/fill/select/key/drag审批；ref/导航版本与控制权校验 |
| 浏览历史/诊断 | Stable独立许可 | 默认不向模型提供；接管期间停止读取和截图 |

第三方模型上的**原生Auto-review尚未实测**，没有把schema字段存在等同于可用。当前明确使用`stable_compatibility`审核来源；输出须包含准确actionDigest、approvedScope、policyVersion、reasonCode、rationale和authorizationBasis。审核失败、超时、取消均不会默认批准。

## 数据迁移与回退

- 正常启动先对SQLite执行一致备份（含WAL），复制已知会话指针，比较迁移前后消息摘要；保留原ID、消息正文与文件路径。
- 增量加入项目、视图状态、运行映射、同步日志、审批账本和搜索索引；不从后台工具把另一环境的数据库覆盖到用户客户端。
- 手工演练只写入全新副本目录：

```powershell
node scripts/verify-conversation-migration.cjs "<Stable数据目录>" "<全新演练目录>"
```

脚本比较原库前后与副本的对话/消息字段摘要，执行integrity_check，输出migration-report.json。不会启动业务任务，也不会将演练副本替换原库。

紧急关闭新增执行路径可在启动前设置以下环境变量为`0`：

| 变量 | 效果 |
| --- | --- |
| STABLE_COMPATIBILITY_REVIEWER | 自动审核转人工；不放宽权限 |
| STABLE_SHARED_BROWSER | 停用共享浏览器工具/界面命令；保留profile |
| STABLE_HISTORY_RECOVERY | 停止启动自动对账；保留本地历史和手工核实入口 |

这些是执行路径开关，不是删除新表或自动恢复旧数据库。恢复旧数据库必须在退出客户端后，由明确选定的备份执行；本次没有替用户做覆盖式回滚。
