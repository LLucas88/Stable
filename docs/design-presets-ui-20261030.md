# Design 交付规格与界面调整验收

日期：2026-10-30。范围：本地源码、隔离数据、后台 Electron 界面及图片处理验证；未调用付费模型，未修改原账号和历史，未打包、部署或推送。

## 界面

- Design 菜单删除模型实现说明和逐张生成说明，弹层与选中项使用浮层/选中阴影，覆盖浅色和深色主题。
- 侧栏顶部删除搜索按钮，活动按钮靠右，新聊天按钮填满剩余区域；保留窗口标题栏搜索。
- 桌面布局侧栏和聊天区域顶端、标题行高度对齐，外侧圆角，右侧和底部留 1px 灰色间隙。
- 交付规格提供六种业务尺寸，同时保留自定义宽高和标准/2K 生成清晰度。

## 交付约束

| 规格 | 最终像素 | 文件大小 |
| --- | --- | --- |
| 店铺头像 | 260 × 260 | 小于 5 MB |
| 店招 | 750 × 422 | 小于 20 MB |
| 海报 | 1138 × 292 | 小于 20 MB |
| 弹窗 | 600 × 750 | 小于 2 MB |
| 常规橱窗 | 702 × 532 | 小于 2 MB |
| 菜品图 | 260 × 260 | 小于 2 MB |

业务规格与供应商生成尺寸分别保存。切换模型和生成清晰度保留业务规格。生成结果下载后，客户端进行等比缩放、居中补齐，保存精确尺寸 PNG，并按保守的十进制 MB 校验实际字节数。透明背景保留透明补齐。图片不裁切，不改写供应商原始输入图片。

规格参与生成任务缓存标识，避免不同交付规格错误复用旧产物；普通非规格请求继续沿用原流程。后续由 agent 脚本编辑的成品在任务规则中要求再次保持这些约束，其真实模型执行尚未在本轮验证。
