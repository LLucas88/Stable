# 报告图表脚本修复副本

这里保留 2026-11-06「奉天玖福记经营诊断报告」图表模块的修复版本及其原有 `svgkit.py` 依赖，用于可复现的几何回归。它不是 Stable 内所有模型生成脚本的自动替换器。

修复涵盖恒定坐标范围、空数据、零值、负数柱形的零基线和实际比例；相邻图形覆盖单点趋势、全零瀑布/漏斗/环图及恒定哑铃图。对无效数值、类别长度不匹配和不适用的对数/漏斗输入明确报错，不默认为零或伪造数据。

```powershell
& vendor/wending-cli/python/python.exe -I -B -X utf8 tests/report-charts.test.py
```

测试也可指定实际模块目录作为第一个参数；仅导入图表函数并生成内存中的合成 SVG，不执行 `gen.py`，不写入报告。

用户已授权将修复后的 `charts.py` 应用到现有报告工作目录，同时明确保留 HTML。备份及受保护文件哈希记录位于 `qa-artifacts/report-chart-repair-20261106/`。后续重新生成报告仍需用户明确要求。
