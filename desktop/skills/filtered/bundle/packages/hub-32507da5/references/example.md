# 微信群活动运营示例

## 示例任务

请根据我提供的群画像、活动目标、奖品和时间，完成微信群活动运营，输出群内节奏表、主持话术和转化动作；同时标注缺失信息和发布前必须人工确认的风险。

## 调用前

只有原始群画像、活动目标、奖品和时间，信息分散、判断口径不统一，社群运营与私域团队无法直接进入下一步执行。

## 调用后

得到结构化的群内节奏表、主持话术和转化动作，关键结论附依据，缺口和风险单独列出，可直接分配负责人并验收。

## 对比

| 维度 | 调用前 | 调用后 |
|---|---|---|
| 信息结构 | 原始资料混杂 | 按任务目标分层 |
| 决策依据 | 依赖个人经验 | 结论绑定输入证据 |
| 执行状态 | 不清楚下一步 | 负责人、动作和门槛明确 |
| 风险控制 | 容易遗漏 | 缺失、合规和人工确认项显式标记 |

## 验收项

- 设计预热、参与、结果和承接四阶段。
- 控制刷屏频率并准备冷场分支。
- 输出未虚构资料中不存在的事实、数据或用户反馈。
