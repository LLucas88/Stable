## Input
Are there any privacy issues with our product?

## Expected output
Privacy and regulatory risk assessment requires knowing what data is collected, how it's used, and which markets are involved.

What is known:
- There is a product with potential privacy concerns

What must be confirmed before assessment:
- What data does the product collect? (personal, financial, health, behavioral, biometric)
- How is the data used and stored?
- Which markets or geographies does the product serve? (determines which regulations apply)
- Are there any third-party data sharing arrangements?
- Are there any particularly sensitive data types or user groups (minors, health data, financial data)?

Without these, no meaningful risk assessment can be done. "Are there any privacy issues" applied to an unknown product can only produce a generic checklist of possible risks, not an actionable assessment.

Suggested next inputs:
- Feature or product description
- Data types collected and their use
- Target market/geography

Confidence level:
Provisional
