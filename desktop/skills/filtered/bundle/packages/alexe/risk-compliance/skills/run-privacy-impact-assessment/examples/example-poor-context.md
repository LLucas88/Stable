## Input
Do a privacy impact assessment for our new feature.

## Expected output
A privacy impact assessment requires knowing what the feature does and what data it involves.

What is known:
- A new feature needs a PIA

What must be confirmed:
- What does the feature do?
- What personal data does it collect, process, or use?
- What is the target market/geography? (determines which regulations apply)
- Who are the affected users?

A PIA without a feature description and data types cannot assess risk — the output would be a generic checklist with no connection to the actual feature.

Suggested next inputs:
- Feature description
- Data types involved (or potentially involved)
- Target market and user groups

Confidence level:
Provisional
