## Input
We need to audit our AI.

## Expected output
An AI audit requires knowing which AI system is being audited and what standards it should be audited against.

What is known:
- There is an AI system that needs an audit

What must be confirmed:
- Which AI feature or system is being audited?
- What standards should it be audited against? (company standards, regulatory requirements, industry framework)
- What is the audit scope? (which time period, which aspects of the system)
- Has the AI governance framework been defined? (if not, audit against what?)

Without a specific system and standards, the audit is not auditing anything in particular.

If governance standards don't exist yet, use govern-responsible-ai to define them first — then audit against those standards.

Suggested next inputs:
- AI feature or system to audit
- Governance standards or framework to audit against
- Time period

Confidence level:
Provisional
