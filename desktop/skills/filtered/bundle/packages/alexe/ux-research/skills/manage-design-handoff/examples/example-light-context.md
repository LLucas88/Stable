## Input
We're redesigning the thread messaging feature in our communications app. Design is mostly done in Figma. We need to hand it off to the engineering team. Last time we did this it was messy — engineers kept finding things that weren't designed for.

## Expected output
Handoff readiness criteria (general — adapt to your team):
1. All screens annotated with interaction behavior (what happens on click, hover, swipe)
2. Edge cases covered: empty states, error states, loading states
3. Responsive behavior defined (if applicable)
4. Design system components identified (existing vs. new)
5. Copy finalized

Required artifacts:
- Annotated Figma file
- Interaction specs (can be Figma annotations or a separate doc)
- Component mapping
- Link to requirements doc (if one exists)

Review and sign-off process (recommended):
1. Design walkthrough with engineering (screen-by-screen, engineers ask questions)
2. Engineering gap review period (1–2 days to identify missing states and constraints)
3. Resolution session to address gaps before build starts
4. Sign-off from engineering lead

Iteration protocol:
- Route all design feedback through a single channel (Notion page, Linear project — not ad-hoc Slack)
- Track each item with a status (open → resolved)
- Designers update the source Figma file, not separate exports

Missing information:
- How many screens are in the Figma file
- Whether interaction specs or annotations exist yet
- Team structure (who reviews, who signs off)
- Whether a design system is in place
- What specifically went wrong in the last handoff (beyond "engineers found undesigned cases")
- Timeline for engineering build

Suggested next steps:
1. List the specific problems from the last handoff — this will tell you which checklist items to prioritize
2. Check Figma for missing states (empty, error, loading) before scheduling the walkthrough
3. Set up a single feedback channel before handoff begins

Confidence level:
Directional — the process structure is sound, but the checklist should be customized once team structure and past failure modes are clearer.
