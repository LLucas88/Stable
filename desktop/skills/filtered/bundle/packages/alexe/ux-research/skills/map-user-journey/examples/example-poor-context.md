## Input
Map our user journey.

## Expected output
To map a user journey, I need to know whose journey, through what product, and what data exists to ground it.

What is known:
- The team wants a user journey map

What must be confirmed:
- Which product or service to map
- Which user segment or persona the journey is for
- What scope: end-to-end experience, or a specific flow (e.g., onboarding, purchase, support)?
- What research or data exists: interviews, analytics, support logs, survey data

A journey map without user data is a hypothesis map. It can be useful as a starting point, but it reflects internal assumptions, not actual user experience.

Suggested next inputs:
- Product area to map
- User segment or persona
- Journey scope (start and end points)
- Any available data (analytics funnels, user feedback, interview transcripts)

Confidence level:
Cannot map — no product, segment, or data specified
