Usability testing basics:
- Participants attempt realistic tasks while a moderator observes
- Tasks should be goal-based ("book an appointment") not instruction-based ("click the blue button")
- 5–6 participants typically surface 80–85% of usability issues
- Sessions run 30–45 minutes each
- Can be moderated or unmoderated, remote or in-person

Suggested next inputs:
- The flow or feature to test
- Whether a prototype or testable version exists
- The user tasks participants should attempt
- Target participant profile
- Timeline and format preference (remote/in-person, moderated/unmoderated)
