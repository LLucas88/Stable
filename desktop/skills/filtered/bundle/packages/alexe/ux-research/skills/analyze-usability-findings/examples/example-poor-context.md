## Input
We did some usability testing and got feedback. Can you help us analyze the results?

## Expected output
To analyze usability findings, I need the raw material from the sessions. Here's what I need and why:

What is known:
- Usability testing was conducted
- Feedback was collected

What must be provided:
- Session observations or notes (what participants did, said, struggled with)
- Tasks or scenarios that were tested
- Number of sessions and participant profiles

What would strengthen the analysis:
- Direct quotes or observed behaviors
- Task completion rates and timing
- Severity of issues observed (did they block the task or just slow it down?)
- Whether sessions were moderated or unmoderated

Suggested next steps:
1. Gather all session notes, recordings, or observation logs
2. List the tasks participants were asked to complete
3. For each session, note: what went well, where participants struggled, any direct quotes
4. Share this material for analysis

Without session data, analysis would be speculative. The value of usability findings analysis comes from grounding recommendations in observed behavior, not assumptions.

Cannot assess — no session data provided
