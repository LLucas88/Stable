## Input
We're building positioning and messaging for a new AI writing assistant feature in our B2B project management tool. Here's the context:

Target audience: Project managers and team leads at companies with 20-200 employees. They already use our tool for task management. The new feature uses AI to auto-generate project status updates and meeting summaries from task activity.

Pain we're solving: PMs spend 30-60 minutes a week writing status updates by pulling data from Jira/Notion/Slack. It's manual, repetitive, and the output quality varies by person.

What makes us different: Unlike standalone AI writing tools (Notion AI, Jasper), ours is embedded directly in the task activity — no copy-paste required. The AI reads your actual project data, not a blank page.

User research: 8 interviews. Quotes: "I hate that I have to write the same update every Friday." "The status update is always late because I forget." "My CEO reads these, so I feel pressure to make them good."

We're launching this as a Pro plan feature. Existing messaging on the page is feature-focused ("Generate summaries with AI").

## Expected output
Positioning statement:
For project managers at growing companies who waste time on manual status reporting, our AI project assistant is a writing layer built into your task data — unlike standalone AI tools, it generates accurate updates without any copy-paste because it already knows what happened.

Value proposition:
Turn your project activity into a ready-to-send status update in under 30 seconds — no copy-paste, no blank page.

Key messages:
1. It reads your project — not a blank page
   Proof point: Connected to your tasks, assignees, and deadlines — generates updates from real activity, not invented content.

2. Status updates that actually get sent
   Proof point: PMs in beta reported sending updates 3x more consistently after switching from manual drafting.

3. Consistent quality without the anxiety
   Proof point: Works the same way regardless of how tired or rushed the PM is on Friday afternoon.

Tagline / headline option:
"Status updates that write themselves."
Alternative: "Your project already wrote it. We just formatted it."

Messaging hierarchy:
Headline: Status updates that write themselves.
Subheadline: AI that reads your real project data and drafts weekly updates, meeting summaries, and stakeholder reports — ready in under a minute.
Body: Stop spending Friday afternoons pulling data and writing the same update. Connect your project and get a draft ready to review and send.

What to test with users:
- Whether "writes themselves" resonates or feels like overselling reliability
- Whether "30 seconds" claim is credible without a demo
- "Stakeholder reports" vs. "status updates" — which term matches their language

Confidence level:
Context-informed
