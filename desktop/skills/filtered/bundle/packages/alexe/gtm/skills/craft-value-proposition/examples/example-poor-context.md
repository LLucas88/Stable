Provisional template:

What is known:
- An app needs a value proposition

What must be confirmed before a value proposition can be drafted:

- Who the target user is
- What job or problem the app addresses for that user
- What makes it different from what users do today or use instead

Suggested next inputs:
- app name and brief description
- target user or customer
- primary problem the app solves
- how it differs from alternatives (or what alternatives users currently use)
