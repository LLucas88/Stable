## Input
We have a meditation app for busy professionals. The main feature is short 5-minute sessions. We want a value proposition.

## Expected output
Value proposition statement (provisional):
[App name] helps busy professionals build a meditation habit by fitting sessions into their schedule — even when they only have 5 minutes.

Target user:
Busy professionals (exact segment not specified — "professional" is broad)

Core job or problem addressed:
Finding time for mindfulness practice despite a demanding schedule. Assumed — not confirmed from user research.

Outcome delivered:
A meditation habit that doesn't require 20-30 minute sessions. Specific outcome (stress reduction, focus improvement, sleep quality) not defined — which one to lead with depends on user research.

Differentiation from alternatives:
"Short sessions" is a feature, not a differentiator by itself — Calm and Headspace both offer short sessions. The value proposition needs a sharper angle: is it the structure of the 5-minute format, the content type, something about the user experience?

Specificity test:
The current framing is too broad — it could describe several existing apps. "Short sessions for busy people" is a category, not a position.

Alternative formulations (provisional):
1. "Meditation for people who keep meaning to start but never do."
2. "Build a habit in 5 minutes. No retreat required."
3. [Needs more product specifics to produce a third meaningful variant]

Language to avoid:
- "Transform your life" (oversell)
- "Mindfulness journey" (cliche)

Missing information:
- What specific outcome do users care about most (stress, sleep, focus)?
- What does user research say about the primary reason people start or quit?
- What makes this app's 5-minute format different from competitors?

Confidence level:
Provisional
