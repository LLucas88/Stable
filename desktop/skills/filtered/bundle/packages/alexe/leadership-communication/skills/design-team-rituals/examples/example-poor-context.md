## Input
What team rituals should we have?

## Expected output
Team ritual design requires knowing the team context before recommending which rituals to use.

What is needed:
- Team type and composition: who is on this team? (Roles, size)
- Current state: what rituals already exist, even if informal?
- Key challenges: what specific team goals or friction points are the rituals meant to address?

Without knowing the team's needs, any ritual set recommended would be generic and may add process overhead without solving the actual problem.

Suggested next inputs:
- "Our team is [size and roles]"
- "Currently we have [existing rituals or none]"
- "Our main challenge is [alignment / psychological safety / delivery discipline / communication / etc.]"
- "We're [remote / hybrid / in-person]"
