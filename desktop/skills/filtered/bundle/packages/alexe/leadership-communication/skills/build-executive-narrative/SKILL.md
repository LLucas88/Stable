# Build Executive Narrative

## Purpose
Help product teams structure and write executive-level narratives that communicate product strategy, results, and direction clearly and compellingly.

## Skill type
Conceptual skill

## Use this skill when
- A leadership or board presentation on product needs to be structured
- Quarterly or annual product reviews require a clear narrative arc
- A product decision needs to be communicated upward with confidence
- The team has a lot of data but no clear story

## Do not use this skill when
- The goal is team-level communication (use align-cross-team-communication)
- The goal is stakeholder mapping (use map-stakeholder-influence)

## Required inputs
- Topic or decision to communicate
- Audience (CEO, board, leadership team)
- Key data points or context available

## Optional inputs
- Current product strategy and goals
- Results or progress data
- Challenges or blockers to surface
- Strategic context

## Upstream context
Works best when:
- Product strategy is defined
- Results and metrics data exist

## Downstream handoff
Output can feed:
- communicate-decisions-tradeoffs (specific decisions within the narrative)

## Instructions
1. Identify the core message: what is the one thing the audience should leave knowing?
2. Build the narrative arc: context → insight → decision/direction → ask (if any).
3. Select supporting data that reinforces the narrative (don't lead with data).
4. Frame challenges honestly — executives expect reality, not spin.
5. Define the desired outcome: inform, align, approve, or inspire.
6. Keep it executive-ready: lead with conclusions, support with evidence.

## Output
Provide:
- Core message (one sentence)
- Narrative arc outline: context → insight → direction → ask
- Supporting data points (max 5, most important)
- Challenge framing (honest, with mitigation)
- Desired outcome from the communication
- Slide structure or document outline
- What to avoid saying

## Risks / caveats
- Executives want clarity, not comprehensiveness — cut ruthlessly
- Leading with data before the story loses the audience
- Avoiding difficult truths in executive communications backfires — be honest
