## Input
Help me with an executive presentation.

## Expected output
An executive narrative requires knowing the topic, the audience, and the key message before it can be structured.

What is needed:
- Topic or decision to communicate: what is the presentation about?
- Audience: who is this for? (CEO, board, leadership team, investors — each requires different framing)
- Key data points or context available: what do you know that shapes the message?

Without these inputs, any presentation structure produced would be a generic template.

Suggested next inputs:
- "The presentation is about [topic]"
- "The audience is [CEO / board / leadership team]"
- "The key data I have is [results / metrics / strategic context]"
- "The desired outcome is [inform / align / get approval / inspire]"
