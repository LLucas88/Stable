## Input
We run a freelance marketplace — buyers post projects, freelancers apply, work happens on-platform. Revenue is 15% take rate on completed projects. Current growth: mostly paid acquisition for buyers, organic SEO for freelancers. We have 8,000 active buyers and 45,000 registered freelancers. About 20% of our buyers return for a second project within 90 days. New buyer CAC is $85. We don't have a formal referral program. Our best freelancers tend to have LinkedIn profiles that mention our platform.

## Expected output
Identified growth loops with cycle descriptions:

Loop 1: SEO content loop (active, moderate strength)
Cycle: Freelancers create profiles → profiles rank for "[skill] freelancer" searches → new freelancers and buyers find the platform → freelancer supply increases → more project completions → more freelancer reviews/portfolios → more indexed content. This is the main organic acquisition mechanism currently.
Loop type: Content / acquisition
Current strength: Moderate. SEO brings organic freelancer traffic. But buyer acquisition relies on paid, meaning the loop is half-functional — it fills supply without compounding buyer demand.
Weakest link: No buyer-side organic acquisition. The content loop drives supply but not demand.

Loop 2: Reputation and re-engagement loop (weak / underbuilt)
Cycle: Buyer completes a project → rates the freelancer → high-rated freelancers appear higher in search → more buyers find and hire them → freelancer earns more → stays on platform → creates more reviews. This loop exists but only compounds for top freelancers.
Loop type: Engagement / quality
Current strength: Weak. 20% second-project rate for buyers means 80% of buyers are one-shot. The loop isn't driving buyer retention — either the experience doesn't encourage return or there's no trigger to re-engage.
Weakest link: Buyer re-engagement after first project completion. There's no loop mechanism pulling buyers back.

Loop 3: Social proof / referral loop (missing / weak)
Cycle: Buyer completes successful project → shares result (or mentions freelancer source) → referred buyer signs up → hires → shares result. This loop is implied by the LinkedIn mentions of top freelancers, but there's no product mechanism to capture or amplify it.
Loop type: Acquisition (word-of-mouth)
Current strength: Broken / missing. The signal exists (LinkedIn mentions) but the loop has no intentional product step to close it.
Weakest link: No prompt, incentive, or framing for buyers to refer others. The sharing happens organically but outside the product.

Missing loops that should exist:
- Buyer-side content loop: successful project completions could generate indexed case studies ("we built X with a freelancer from [platform]"). This doesn't exist.
- Network expansion loop: buyers bring projects → freelancers invite colleagues to join → supply grows without paid acquisition. Also missing.

Priority order for strengthening:
1. Buyer re-engagement loop: fix the 20% second-project rate before investing in new acquisition. Each buyer retained for a second project generates $85 of incremental value (equivalent to acquiring a new buyer at $0 CAC). A triggered email/notification at 30 days post-project completion is the minimum viable mechanism.
2. Referral loop: formalize what the LinkedIn behavior suggests is already happening. A simple post-project prompt ("Know someone who needs a freelancer? Get $20 credit") converts passive word of mouth into a tracked loop.
3. SEO loop: continue feeding the content loop by improving freelancer profile quality and review volume. This is already working — invest to accelerate, not redesign.

Investment required per loop improvement:
- Buyer re-engagement: low — triggered email sequence, no product change required
- Referral loop: medium — referral tracking, reward fulfillment, landing page for referred buyers
- SEO improvement: ongoing — profile quality scoring, automated profile completion prompts for freelancers
