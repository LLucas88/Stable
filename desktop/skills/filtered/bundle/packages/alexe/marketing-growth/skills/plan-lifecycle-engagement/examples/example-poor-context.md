## Input
We need to set up lifecycle messaging. Where should we start?

## Expected output
Lifecycle engagement planning requires knowing the product, the user journey, and some data on where users drop off.

What is known:
- Lifecycle messaging needs to be set up

What must be confirmed before starting:
- What is the product and user lifecycle? (what does a new user → retained user journey look like?)
- What is the activation event? (when has a user gotten value?)
- What is the current retention or churn rate?
- What messaging channels are available? (email, push, in-app, SMS)
- Are behavioral triggers available? (can the messaging tool receive product events?)

Starting lifecycle messaging without knowing where users drop off produces untargeted time-based blasts, not effective engagement.

Suggested next inputs:
- Product type and lifecycle description
- Activation event definition
- Current activation and retention/churn metrics
- Channels and tooling available

Confidence level:
Provisional
