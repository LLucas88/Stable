## Input
Design an onboarding flow for my app.

## Expected output
An onboarding flow design requires knowing what the product does and what activation means.

What is known:
- An app needs an onboarding flow

What must be confirmed before designing:
- What is the product and what does it help users do?
- What is the activation event? (what specific action signals the user has experienced core value?)
- What are the current onboarding steps, if any?
- Where are users dropping off in the current flow?

Without an activation event definition, any onboarding flow designed will have no measurable success criterion.

Suggested next inputs:
- Product description and target user
- Activation event definition
- Current onboarding steps (if any)
- Drop-off data or user research insights

Confidence level:
Provisional
