## Input

"I think we have a product problem."

## Expected output

Cannot frame a product problem without a signal to work from.

Questions that must be answered before any framing is possible:
1. What specific behaviour, metric, or complaint triggered this concern?
2. Which users are affected — new users, existing users, a specific segment?
3. What is the business consequence if this is left unresolved?
4. Is there any data — even rough — pointing to the problem area?
5. What product area is this in — onboarding, core feature, retention, monetisation?

Provisional problem template (to be completed once signal is available):
[Affected segment] struggle to [accomplish goal or task] because [friction, gap, or missing capability], which leads to [business or user consequence].

Confidence level: Provisional — no framing is possible until at least one concrete signal is provided.
