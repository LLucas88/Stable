## Input
Build me a product dashboard.

## Expected output
A dashboard design requires knowing what decisions it should support and who will use it.

What is known:
- A product dashboard is needed

What must be confirmed:
- Who is the audience? (team-level, leadership, cross-functional)
- How often will it be reviewed? (daily, weekly, monthly)
- What decisions should this dashboard drive?
- What product area is it covering?
- What metrics exist already?

Without this, the result is a list of generic metrics that no one will use.

Suggested next inputs:
- Dashboard audience and review cadence
- Key decisions it should support
- Product area in scope

Confidence level:
Provisional
