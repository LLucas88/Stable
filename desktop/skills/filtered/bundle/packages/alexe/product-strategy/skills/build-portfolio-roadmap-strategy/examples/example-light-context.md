# Example: Light Context

## Input

**Product areas:** We have our main product and we're working on some AI features and a new dashboard.
**Business goal:** Grow revenue.
**Constraints:** Small team.

## Output

### Status
Context is thin. A provisional structure is provided, but strategic clarity is missing.

### Provisional portfolio structure

| Area | Assumed class | What's unknown |
|------|--------------|----------------|
| Main product | Core — likely | What does "main product" do? What's its health? |
| AI features | Growth — possible | What problem do they solve? Any traction? |
| New dashboard | Unclear | Is this for existing users or new segment? |

### What's missing before real prioritization
1. What are the specific revenue growth goals? (ARR target, timeline)
2. What is the current state of each area? (usage, retention, feedback)
3. What does "small team" mean? (1 team, 2 teams?)
4. Who are the primary customers and what do they value most?

### Recommended next step
Answer the four questions above. This skill will then produce a proper portfolio map and roadmap structure.

### Confidence level
Provisional — cannot produce a real roadmap recommendation without strategic goals and area health data.
