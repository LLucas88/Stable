## Input
Help me plan delivery for a new feature.

## Expected output
Delivery planning requires a feature to plan. Without context, no plan can be produced.

What is needed:
- What is the feature? (Even a rough description)
- What is the team structure? (How many engineers, designers)
- What is the timeline or deadline?
- Are requirements or user stories defined?

Optional but useful:
- Known technical dependencies
- Cross-functional teams involved (design, QA, data, marketing)
- Known risks

Without these inputs, any plan produced would be fictional milestones for an unknown feature with an unknown team.

Suggested next inputs:
- Feature description
- Team size and composition
- Timeline or deadline
- Whether requirements exist (PRD or user stories)
