## Input
Write user stories for our new feature.

## Expected output
User stories cannot be written without knowing the feature, the user, and the goal.

What is needed:
- What is the feature? (Even a rough description)
- Who is the user? (What role or segment is this for?)
- What outcome should the feature deliver? (What problem does it solve?)

Without these inputs, any stories produced would be fictional and likely wrong.

What must be confirmed before writing:
- Feature description: what should users be able to do?
- Target user type: who uses this feature?
- Goal: why does this feature exist? What changes after it ships?
- Scope: are there related features or existing functionality this connects to?

Suggested next inputs:
- "The feature is [description]"
- "The users are [role or segment]"
- "The goal is [outcome or problem being solved]"
