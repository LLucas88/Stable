## Input
We finished our Q1 sprint cycle and want to do a retro. The quarter was okay but we didn't hit all our goals. The team is 5 people.

## Expected output
Scope and context summary:
Q1 sprint cycle. Team of 5. Goals partially met — specifics needed to make the retro substantive.

Format selected: What went well / What didn't / What to change
Rationale: Simple, widely understood format suitable for a quarterly cycle review. Works with limited prior context.

---

Facilitation plan (since specifics are limited, here is a structure to run the session):

**Before the session (30 minutes prep):**
- Pull the metrics: what were the Q1 goals? Which were hit, which weren't?
- Pull a list of key events: launches, incidents, process changes, team changes
- Ask team members to write 3–5 observations each before the meeting (silent writing reduces groupthink)

**During the session (60–90 minutes):**

1. Review prior retro actions (5 min): what was committed to last quarter? What was completed?
2. Review the data (10 min): goals, metrics, key events — shared context, not debate
3. Individual observations (15 min): each person shares 2–3 items across the three categories
4. Cluster themes (10 min): group similar observations
5. Vote on top themes (5 min): each person votes for top 3 most important
6. Discuss top themes (30 min): focus on causes, not symptoms
7. Define actions (15 min): at most 3 actions; each needs an owner and a deadline

**Key questions to surface:**
- Which goal that wasn't hit matters most — and why wasn't it hit?
- What's the one thing that would have made Q1 easier if it had been in place from the start?
- Is there anything we keep saying we'll fix but never do?

---

- Which goals were hit and which weren't?
- Were there specific incidents or blockers worth examining?
- What were the action items from the last retro?
