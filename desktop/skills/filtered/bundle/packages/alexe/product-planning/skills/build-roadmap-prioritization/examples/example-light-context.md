## Input
We have a list of things we want to build: better search, notifications, user profiles, analytics dashboard, mobile improvements, onboarding tutorial, and referral program. We want to build a roadmap for the next few months. The main goal is growing users.

## Expected output
Roadmap cannot be fully structured without goals and goal-initiative mapping, but here's what can be done with the information provided.

Preliminary assessment of initiatives vs. "grow users" goal:

| Initiative | Connection to User Growth | Confidence |
|-----------|--------------------------|-----------|
| Referral program | Direct — increases acquisition | Medium (depends on current referral baseline) |
| Onboarding tutorial | Direct — improves activation of acquired users | Medium (only if activation is the growth bottleneck) |
| Better search | Indirect — helps existing users; unclear acquisition impact | Low without data |
| Notifications | Indirect — can improve retention/re-engagement | Low without specifics |
| Mobile improvements | Could affect acquisition and activation if mobile is a key channel | Low without data |
| User profiles | Unclear connection to growth | Low |
| Analytics dashboard | No direct user growth connection | None identified |

Provisional now/next/later structure (directional only):

Now candidates: referral program, onboarding tutorial (if activation is bottleneck)
Next candidates: better search, notifications
Later: user profiles, analytics dashboard, mobile improvements (too vague to prioritize)

Missing information before this becomes a real roadmap:
- What does "growing users" mean — new signups, MAU, paid conversions?
- What is currently blocking growth? Acquisition, activation, or retention?
- What are your metrics today (signups, activation rate, churn)?
- Team size and capacity?
- Is there a specific deadline or milestone driving the timeline?

Recommendation: define the growth bottleneck first, then prioritize only initiatives that address it.
