## Input
Synthesize our customer feedback.

## Expected output
Feedback synthesis requires feedback sources to synthesize.

What is needed:
- Feedback sources and rough volume: what data exists? (Support tickets, reviews, NPS, surveys, interviews)
- Synthesis goal: what decisions should this synthesis inform?

Without feedback sources, there is nothing to synthesize. Without a synthesis goal, there is no way to know which themes matter most.

What must be confirmed:
- "We have [sources]: [support tickets / App Store reviews / NPS verbatims / survey responses / interview notes]"
- "The synthesis should help us [roadmap planning / identify top user pain points / prepare for a board presentation / etc.]"

Optional but useful:
- Rough volume per source (100 tickets? 20 reviews?)
- Time period covered
- Whether some sources are already tagged or organized

Suggested next inputs:
- List of feedback sources and their approximate volume
- The decision or planning cycle this synthesis is feeding
