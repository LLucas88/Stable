## Input
We need success metrics for an experiment.

## Expected output
Possible primary metric options depending on the goal:
- Activation rate if the change affects onboarding or first value
- Conversion rate if the change affects checkout or purchase flow
- Retention if the change affects ongoing habit or repeat usage
- Revenue per user if the change primarily affects monetization

What is known:
- The user needs experiment metrics

What is assumed:
- Nothing reliable about product stage or business goal

What must be confirmed:
- What user outcome is meant to improve
- Which funnel stage is affected
- Which risks need guardrails
- What level of improvement would matter

Which parts are provisional due to missing context:
All metric choices are provisional
