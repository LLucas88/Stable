## Input
Hypothesis:
If we reduce onboarding from 5 steps to 3 for new iOS users,
we expect more users to start their first lesson.

Business goal:
Increase new-user activation without hurting Day 1 retention.

## Expected output
Primary metric:
First-session lesson start rate

Why it is primary:
It is the closest measurable outcome to the hypothesis and reflects first value realization.

Secondary metrics:
- Onboarding completion rate
- Time to first lesson
- Drop-off by onboarding step

Guardrail metrics:
- Day 1 retention
- Onboarding error rate
- Support contacts related to sign-up

Minimum meaningful effect:
To be agreed by the team based on expected value and implementation cost

Success threshold:
Primary metric improves by at least the agreed minimum meaningful effect with no material guardrail degradation

Neutral zone:
Small movement below the minimum meaningful effect

Failure threshold:
No meaningful uplift or negative guardrail impact

Interpretation notes:
The primary metric is strong because the hypothesis is explicitly about faster activation.

Which parts are provisional due to missing context:
Minimum meaningful effect
