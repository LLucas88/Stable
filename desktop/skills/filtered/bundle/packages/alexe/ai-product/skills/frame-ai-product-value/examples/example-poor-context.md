## Input
We want to add AI features to our product. What's the value?

## Expected output
AI product value cannot be framed without knowing what the AI feature does and what user problem it solves.

"Adding AI" is not a value proposition. The value comes from the specific user problem the AI capability addresses.

What is needed:
- The specific AI capability or feature idea: what would the AI do?
- The target user segment: who has the problem this AI would solve?

Without these inputs, any value framing would be speculative and likely generic.

Suggested next inputs:
- "The AI feature would [do this specific thing] for [user type]"
- "The user problem it addresses is [description]"
- "Currently users [current behavior without AI]"
