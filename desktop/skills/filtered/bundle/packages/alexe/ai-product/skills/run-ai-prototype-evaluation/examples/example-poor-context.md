## Input
Evaluate my AI prototype.

## Expected output
Prototype evaluation requires knowing what the prototype is and what decision the evaluation should inform.

What is needed:
- AI prototype or proof-of-concept description: what does it do? What input does it take and what does it produce?
- Evaluation goal: what specific decision will this evaluation inform? (Build vs. don't build? Choose between two approaches? Identify issues before launch?)
- Success criteria: what would a "good" prototype look like? What quality bar needs to be met?

Without these inputs, any evaluation would be a generic checklist rather than a meaningful assessment.

Suggested next inputs:
- "The prototype [does this]. It takes [input type] and produces [output type]."
- "The evaluation should help us decide [specific decision]"
- "We think success looks like [quality bar, user reaction, performance metric]"
