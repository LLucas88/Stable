## Input
What AI model should I use?

## Expected output
Model capability assessment requires a task to assess.

"Which model should I use" is unanswerable without knowing what the model needs to do.

What is needed:
- The specific task the model needs to perform (what input goes in, what output comes out?)
- The quality bar required (what does "good" look like? What does "bad" look like to users?)
- Key constraints: latency, cost, data privacy, language support

Without a defined task, any model recommendation would be arbitrary.

Suggested next inputs:
- "The task is: [description — input, desired output, context]"
- "The model needs to [action] given [input type]"
- "The main risk if the model is wrong is [consequence]"
