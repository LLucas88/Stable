## Input
We need to run a sensitivity analysis on our plan.

## Expected output
Status:
Sensitivity analysis cannot be run without a plan with explicit assumptions.

What is needed:
- A forecast or business case with specific numerical assumptions
- The outcome metric to evaluate (e.g., ARR, revenue, ROI, payback period)
- For each assumption: a base case value and a plausible range (pessimistic to optimistic)

A sensitivity analysis works by varying one assumption at a time and measuring how the outcome changes. Without documented assumptions and a base case model, there is nothing to vary.

What "no documented assumptions" means in practice:
If the plan exists but assumptions are implicit or unstated, the first step is to surface them:
- What would have to be true for the plan to succeed?
- Which of those conditions are uncertain?
- What is the realistic range for each uncertain condition?

Common assumptions worth analyzing in a product business plan:
- Conversion or upgrade rate from free → paid
- Churn rate
- Average revenue per customer
- Market size or addressable user base
- CAC and channel performance
- Time-to-value or sales cycle length

Recommended next steps:
1. Share the business case or forecast (even a rough one)
2. List the key assumptions it depends on
3. For each assumption, provide: current estimate and a plausible low / high range

Once these are available, the sensitivity analysis can identify which assumptions drive the most variance and which need validation before the team commits.
