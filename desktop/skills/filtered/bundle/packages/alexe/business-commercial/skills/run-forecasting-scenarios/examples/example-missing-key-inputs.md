## Input
We need a revenue forecast for next year. We're growing and want to plan for different scenarios.

## Expected output
Status:
Cannot produce a forecast without baseline data and key assumption inputs.

What is needed before forecasting:
1. Metric to forecast: revenue, MRR, ARR, user count, GMV — specify which
2. Current baseline: what is the current value of that metric?
3. Time horizon: 6 months, 12 months, 24 months?
4. Key growth drivers: what drives the metric? (new customers, ARPU, churn, channel mix)
5. Current trajectory: recent trend (is the business accelerating, stable, or decelerating?)

Without these, a "scenario forecast" is fabricated numbers attached to made-up assumptions — not useful for planning.

What can be provided now (framework):
A forecasting structure for revenue-based metrics typically models:

End-period MRR = (Starting MRR) + (New MRR from acquisitions) − (Churned MRR)

The three inputs that drive variance are:
- New customer volume (or new MRR per period)
- Average revenue per customer (ARPU)
- Churn rate (monthly or annual)

To build three scenarios (base / upside / downside), each of these inputs needs a realistic range:
- What is the base case for each driver? (current trajectory)
- What would need to go right to hit the upside? (specific assumption)
- What would cause the downside? (specific risk)

Recommended next inputs:
- Current MRR or ARR
- Monthly new customer additions (or new MRR per month)
- Monthly or annual churn rate
- Time horizon
- Any strategic initiatives that might change the trajectory (new channel investment, pricing change, product launch)

Confidence level:
Provisional
