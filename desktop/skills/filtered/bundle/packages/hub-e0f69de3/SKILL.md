# 抖音爆款脚本

## 这个 skill 解决什么

抖音脚本写不好的 3 个根本原因：
1. **不懂"前 3 秒定生死"**：开头 3 秒没钩住人 → 完播率 < 10% → 算法直接降权
2. **不懂"完播率 > 点赞率"**：抖音算法首要指标是完播率，不是点赞
3. **不懂"信息流 / 直播 / 带货脚本逻辑完全不同"**：信息流要"种草"、直播要"控场"、带货要"逼单"

这个 skill 给 3 件事：
1. **结构化模板**：4 段式（钩子 / 痛点 / 解决 / 召唤），按时长分配秒数
2. **场景适配**：信息流 / 直播间 / 带货脚本逻辑差异
3. **平台合规**：违禁词清单、容易被限流的元素警告

---

## 抖音 3 大脚本类型

### 类型 1：信息流广告脚本（DOU+ 投流用）
- 时长：**15-30 秒**（30 秒内完播率最稳）
- 目标：跳到主页 → 点关注 / 跳转链接
- 节奏：钩子 3s + 痛点 5s + 解决 7s + CTA 5s
- 测试逻辑：DOU+ 投 100 元起，看完播率和 CTR

### 类型 2：直播间话术脚本
- 时长：直播间循环话术（每段 30 秒-2 分钟）
- 目标：留人、互动、点赞、关注、加粉丝团、最终下单
- 节奏：欢迎新进 → 介绍当前讲解 → 痛点共鸣 → 福利节奏 → 逼单
- 关键：**控场节奏**，每 5 分钟一波小高潮

### 类型 3：带货短视频脚本
- 时长：**30-60 秒**（带货长一点更利于讲清产品）
- 目标：点小黄车直接下单
- 节奏：钩子 5s + 痛点 10s + 产品 20s + 价格福利 15s + 召唤 10s
- 关键：**信任感**，前 5 秒就要建立"这人懂"

## 4 段式核心模板

```
┌─────────────────────────────────────────────────┐
│ 段 1：钩子（3-5 秒）                            │
│   作用：让人停下不刷走                          │
│   类型：① 反差 / 颠覆认知                       │
│         ② 利益型（"教你 XX 省 XX 块"）          │
│         ③ 提问型（"你知道吗"）                  │
│         ④ 悬念型（"我差点亏了 X 万"）           │
│         ⑤ 视觉冲击（夸张表情 / 动作 / 场景）    │
├─────────────────────────────────────────────────┤
│ 段 2：痛点共鸣（5-15 秒）                       │
│   作用：让观众感觉"这就是我"                    │
│   方法：①  描述具体场景，越细节越好             │
│         ② 用观众的话说话（口语化、有 emoji）   │
│         ③ 加情绪（焦虑 / 愤怒 / 委屈）          │
├─────────────────────────────────────────────────┤
│ 段 3：解决方案（10-30 秒）                      │
│   作用：给方法 / 卖产品 / 立人设                │
│   方法：① 1-3 步法（步数越少越好）              │
│         ② 对比演示（before / after）            │
│         ③ 案例佐证（"我有个粉丝 ……"）           │
├─────────────────────────────────────────────────┤
│ 段 4：行动召唤（CTA，3-10 秒）                  │
│   作用：把流量转化为关注 / 评论 / 下单          │
│   类型：① 关注（"关注我，下期继续讲"）          │
│         ② 评论（"评论 1，我私你完整版"）        │
│         ③ 下单（"点小黄车，今晚 8 点价"）       │
│         ④ 收藏（"收藏起来，慢慢看"）            │
└─────────────────────────────────────────────────┘
```

## 5 大类钩子（前 3 秒）实战

| 钩子类型 | 模板 | 适用 |
|---|---|---|
| **反差颠覆** | "你以为 XX，其实 XX" / "99% 的人都做错了" | 知识科普类 |
| **利益直给** | "教你 3 招，月省 1000" / "1 个动作，瘦腿 5cm" | 干货类、带货类 |
| **悬念追问** | "差点亏 50 万，就因为 XX" / "再不知道这个就晚了" | 故事类、避坑类 |
| **场景代入** | "刚加入新公司怎么破？" / "今年要结婚的姐妹注意" | 垂直场景 |
| **数据冲击** | "98% 的人不知道" / "1000 个客户做完都说……" | 权威背书类 |

**钩子 5 大禁忌**：
- ❌ 自我介绍（"大家好我是……"）—— 直接划走
- ❌ 慢节奏的环境镜头（拍天空 / 走路）—— 完播率 < 5%
- ❌ "今天给大家分享…… " —— 太老套
- ❌ "废话开场"（说了和没说一样）
- ❌ 字幕和口播不一致（视觉错乱）

## 信息流广告脚本（30 秒）模板

```
【0-3s 钩子】
画面：女主睁大眼睛，举着两瓶面霜
口播："99% 的人都用错了乳液，难怪皮肤越来越差！"

【3-10s 痛点】
画面：失败 case 演示（皮肤干、起皮、爆痘）

       问题不是面霜，是你少了一步！"

【10-25s 解决方案】
画面：演示正确步骤

       关键是这瓶 XX 精华，含 5% XX 成分，
       (上字幕：XXX 成分检测报告)
       28 天连续用，毛孔可见缩小 32%"

【25-30s CTA】
画面：产品展示 + 二维码
口播："关注我，主页置顶有今日福利价，先到先得"
```

## 直播带货脚本（5 分钟段落）模板


## 抖音违禁词与限流元素

### 绝对违禁词（出现就限流 / 下架）
- 极限词：最、第一、最佳、首屈一指、独家、绝对
- 引战词：揭秘、内幕、惊呆了、太可怕了
- 医疗词（普通账号不能用）：治愈、根治、立竿见影
- 金融词：投资必赚、保本、年化 X% 收益
- 虚假词：100% 有效、零风险

### 限流元素
- 镜头中出现品牌 logo（除非有蓝 V）
- 二维码（除非橱窗 / 小风车）
- 微信号 / 公众号名（直接 ban）
- 抖音其他平台名（小红书、B 站）

### 视频元素的正向加分
- 字幕清晰且和口播完全一致
- BGM 用抖音热门音乐
- 视频有节奏切换（每 3-5 秒一个镜头）
- 出镜真人 > 纯字幕
- 有手部动作 / 表情变化

## AI 执行流程

### 第一步：摸需求

1. 你的视频是 信息流广告 / 直播话术 / 带货短视频？
2. 时长大概多久？（15s / 30s / 60s / 直播段）
3. 产品 / 主题是什么？目标受众是谁？
4. 你账号当前粉丝量？（< 1 万 走"立人设"路线，> 10 万 走"带货"路线）
5. 有没有钩子素材 / 痛点 / 卖点的草稿？

### 第二步：选模板

按场景选 4 段式 / 5 分钟直播段 / 60 秒带货段。

### 第三步：填内容

每段都给 2-3 个备选版本，用户挑：
- 钩子：5 类钩子各给 1 个备选
- 痛点：3 个不同切入点
- 解决方案：步骤 / 案例 / 演示 三种风格
- CTA：关注 / 评论 / 下单 / 收藏 四种召唤

### 第四步：合规检查

- 扫违禁词
- 检查限流元素
- 提示视频拍摄注意事项

### 第五步：自检 checklist

- [ ] 前 3 秒有强钩子？
- [ ] 段间过渡顺畅？（没有"接下来我们" 这种废话）
- [ ] 总时长在用户要的范围内？
- [ ] 没有违禁词 / 限流元素？
- [ ] CTA 明确可执行？
