# 情节结构与章节模板

## 一、整体结构骨架（按题材选用）

- **三幕式**：建置（前 1/4，立人设+抛冲突）→ 对抗（中 1/2，爽点递进+反派升级）→ 解决（后 1/4，卷终决战+阶段质变）。
- **英雄之旅**：平凡世界 → 召唤 → 跨越 → 试炼 → 收获 → 归来。适合成长逆袭。
- **反转结构**：表面真相 → 第一次反转 → 加深谜题 → 大反转。适合悬疑/规则怪谈。
- **多线并行**：主线 + 1–2 条副线（感情线/事业线），定期交汇。适合群像/长篇。

## 二、单章情节模板（对齐情绪拐点）

```
开头 10%   —— 即时冲突 / 承接上章钩子 / 抛新悬念
发展 60%   —— 推进核心任务，3–5 个场景，至少 1 个爽感元素
高潮 20%   —— 打脸 / 突破 / 反转，情绪顶点
收尾 10%   —— 章末钩子，卡在冲突/悬念/反转
```

## 三、卷级节奏（全局统一）

```
每 1–2 章：小打脸（碾压小角色、得小收获）
每 3–5 章：中打脸（击败阶段对手、突破等级）
每 8–12 章：大高潮（翻转局势、揭示真相、大规模碾压）
每 15–20 章：卷终决战（解决卷级矛盾、主角阶段性质变）
```

> 连续 3 章无爽点即预警；卷与卷之间用 1 章"状态回收"衔接，不假定读者记得前卷细节。
