# 起点长篇爽文写作助手

面向「起点中文网」的长篇爽文创作助手。纯 Agent 内嵌运行，不依赖任何外部大模型 API，所有生成、质检、记忆都在本地完成。

本技能为完整的起点创作工作流，多维度「去 AI 味」量化质检，并提供两种产出模式，由你在立项时选定：

- **辅助脚手架模式（默认、最稳合规）**：AI 帮你"想"与"扩写"，产出大纲 / 设定 Bible / 章节草稿；核心正文需人工重写 ≥ 七成后才能发布。
- **直出成稿模式**：AI 在生成正文时即内置去 AI 味约束，一次性产出 2000–4000 字已去味的完整成稿，无需事后重写即可读。

两种模式共享同一套保障长篇不崩的工程底座（设定 Bible、卷级规划、量化质检、九维审查、数据复盘）。区别只在"章节点产出的是草稿还是成稿"。

> 合规红线贯穿始终：起点 2026 年已系统性处置"非真人自动化"批量生成内容（含均订数万的爆款被移出榜单、撤流量）。辅助模式硬守红线；直出模式如实标注风险、不主动拒绝，但提醒你自担发布用途。

## 第一阶段：立项与合规（必跑，先于一切创作）

先问清用户两件事，写进项目 `meta.md`：

1. **产出模式**：辅助脚手架（草稿，需人工重写）还是直出成稿（已去味成稿）。默认辅助模式。
2. **题材 / 爽感 / 金手指**方向（可参考第二阶段引导）。

然后向用户说明边界，写入 `meta.md`：

- **AI 可做**：灵感/设定、世界观与人设、大纲与卷纲、章节粗纲、校对与轻度润色、资料检索、时间线/逻辑排查、按选定模式产出（草稿或成稿）。
- **AI 不可做（硬红线）**：纯生成核心正文后直接发布、代笔托管、多书批量灌水、洗稿抄袭——这点在辅助模式是强制拒绝；直出模式则如实标注风险，由用户自担用途（自有渠道 / 二创底稿 / 灵感参考 / 非起点平台 / 人工精修前的初稿）。
- **人工主导（辅助模式）**：AI 产出后必须人工重写（重组句式、改写 ≥ 七成），核心剧情/人设/爽点须原创；正文不得残留 AI 提示词或续写痕迹。
- **自检节奏**：每 3–5 章人工抽检一次，早改远便宜于十万字后回炉。

## 第二阶段：选题雷达（决定付费天花板）

起点是付费订阅 + IP 孵化长跑赛道，题材要"有需求但未饱和"。

1. 用 AI 做**题材重组**：把两个成熟标签交叉（如"都市 + 规则怪谈""仙侠 + 克苏鲁"），避开纯模板内卷。
2. 定**核心爽感类型**：扮猪吃虎 / 逆袭碾压 / 系统成长 / 马甲掉落 / 复仇反杀 / 养成甜宠 …… 选 1 个主爽感 + 1 个辅爽感。
3. 定**差异化金手指**：有规则、有限制、可成长，方能体现"碾压感"与"长线爽点"。
4. 定**反差点**：主角最大反差（表面废柴实天赋异禀 / 摆烂实卷王 / 老实人黑化 ……）。
5. 扫榜验证：参考起点新书榜、三江榜的书名节奏、开头钩子、卡点方式，但**不盲目跟风**（编辑更看重创新）。

产物：`00-大纲.md` 的"基本信息 + 题材定位"。

## 第三阶段：大纲与卷级规划

### 全局大纲
按 `templates/outline-template.md` 落地：基本信息、力量/等级体系、主线走向（分卷）、关键转折点、爽点总谱。

### 卷级章节规划（防写偏关键）
每卷开写前生成 `.learnings/章节规划_卷N.md`，含：
- 本卷核心目标
- 章节分解表：章节 / 核心任务 / 爽点类型 / 关键情节 / 情绪曲线 / 状态
- 中高潮与卷终高潮位置
- 新角色/新地点、伏笔埋设与回收章

**爽文节奏公式**（全局统一参照）：
```
每 1–2 章：小打脸（碾压小角色、得小收获）
每 3–5 章：中打脸（击败阶段对手、突破等级）
每 8–12 章：大高潮（翻转局势、揭示真相、大规模碾压）
每 15–20 章：卷终决战（解决卷级矛盾、主角阶段性质变）
```

## 第四阶段：设定 Bible（长篇一致性底座）

所有设定与状态沉淀到 `.learnings/`，**每章生成前必读**，杜绝穿帮与漂移：

| 文件 | 记录内容 | 写入时机 |
|------|---------|---------|
| `STORY_BIBLE.md` | 世界观、力量体系、社会规则、核心设定 | 发现新设定立即写 |
| `CHARACTERS.md` | 角色人设、当前状态、关系、成长弧 | 出场/状态变化即写 |
| `LOCATIONS.md` | 地点特征、方位、距离 | 新地点出现即写 |
| `PLOT_POINTS.md` | 关键情节 + 伏笔（埋设/进行中/已回收） | 关键情节即写 |
| `章节规划_卷N.md` | 本卷每章任务与爽点 | 卷开始前 + 每章更新 |

> 设定 Bible 就是长篇不崩的"单一真相源"。把人设、战力、世界观、伏笔锁死，无论草稿还是成稿都不会前后矛盾。

## 第五阶段：黄金三章与逐章生成

### 黄金三章（开头定生死）
- 第 1 章前 20% 必须有即时冲突，尽快抛出**核心设定 + 金手指 + 强冲突/钩子**。
- 一章立人设，三章内展开主线；"黄金三章"是首轮推荐筛选的硬门槛。
- 参考 `references/chapter-guide.md` 的 10 种开头技巧。

### 逐章生成流程
1. **写前分析**：读 `00-大纲.md` + 本卷规划 + 设定 Bible + 上一章钩子；从规划取本章核心任务。
2. **产出正文**（按选定模式）：
   - **辅助模式**：先写"骨架"（谁+在哪+做什么+说什么，哪怕不通顺）→ 扩写为草稿 → 标注「待人工重写 ≥ 七成」，不凑数注水。
   - **直出模式**：按 `templates/chapter-template.md`，**一次性写出 2000–4000 字完整成稿**；生成时即套用去味四招（见第八阶段），使成稿无 AI 腔。
3. **章末钩子（必做）**：章末卡在冲突/悬念/反转；钩子类型逐章轮换（见 `references/chapter-guide.md` 钩子技巧）；这是追读率的直接开关。
4. **结构锚点**：单章按"开头 10% / 发展 60% / 高潮 20% / 收尾 10%"分配，对齐情绪拐点。

### 创作三法则
1. 展示而非讲述（用动作/对话表现，不直陈）。
2. 冲突驱动 + 情绪过山车（每章有冲突，每 3 章一次"压—小扬—压—爆"）。
3. 悬念承上启下（章末必留钩子且轮换）。

## 第六阶段：量化质检（脚本，含升级版去 AI 味检测）

每章产出后运行：
```bash
python scripts/check_chapter.py <章节文件>
# 或批量
python scripts/check_chapter.py --all novels/<书名>/
```
脚本输出：**正文字数 / 对话占比 / 章末钩子 / 爆点计数 / 情绪拐点**，以及**升级版「去 AI 味体检」**：
- 合成 **AI 味指数（0–100，越低越像人写）**，由六个子维度加权：修饰词密度、连接词密度、成语密度、句长方差 CV、排比密度、对话标记多样性。
- 门槛：指数 < 40 视为「低（像人写）」通过；40–60 中；>60 高（像机器）。
- 该指数为本地弱启发式，仅供人工参考，真正去味仍靠生成时的写法约束（见第八阶段）。

直出成稿应过全部门槛（含字数 ≥ 2000、AI 味指数 < 40）；辅助草稿以人写为闭环，质检用于自检方向，不强求字数门。

## 第七阶段：九维审查（一致性）

按 `references/consistency-guide.md` 执行（常规章快速 3 维，关键章完整 9 维）：
核心任务达成 / 有效信息占比 / 穿帮检测（角色·地点·能力·时间线）/ 角色成长追踪 / 套路重复检测 / 爽点结构完整 / 伏笔管理 / 衔接连贯 / 卷目标进度。审查结果记 `.learnings/审查记录.md`。

---

## 第八阶段：去 AI 味

按 `references/de-ai-guide.md`。两种模式的去味落点不同：
- **辅助模式**：去味是**交付前你必做**——拿到草稿后重组句式、埋感官私货、打断完美句式、建角色语言指纹，重写 ≥ 七成再发布。
- **直出模式**：去味四招在**第五阶段生成时内置**，成稿默认无 AI 腔，免事后重写。

无论哪种模式，生成/改写时都要规避 AI 腔典型特征（修饰堆砌、四字格成排、句式过度工整、情绪平滑、抽象陈述多于动作、残留提示词痕迹），并用第六阶段的「去 AI 味体检」做量化自检。

---

## 第九阶段：数据复盘（追读导向）

起点指标↔写法映射见 `references/data-guide.md`：
- **收藏**看开头（书名+黄金三章吸引力）
- **追读**看卡点（章末钩子强度）
- **均订**看爽点（爽感密度与成长可感）
- **月票**看粘性（角色陪伴感、读者互动）
- **留存**看节奏（不注水、不拖、情绪曲线稳）

每 5 章做一次阶段性检查：总结情绪曲线、爆点密度、掉点章节；掉点章让 AI 帮分析"为何掉"，但**剧情决策仍由你定**，回到大纲迭代而非回炉重写。

---

## 第十阶段：断点续写

续写前按顺序读：大纲 → 本卷规划 → 设定 Bible（角色/地点/情节/伏笔）→ 审查记录 → 上一章。确认章节号、下一章核心任务、待回收伏笔、消失过久配角。跨卷先生成新卷规划再续。

## 内置工程改进

1. **两种产出模式合一**：辅助脚手架（合规稳）与直出成稿（效率快）按需切换，共享同一工程底座。
2. **升级版去 AI 味质检**：多维启发式合成 AI 味指数，替代旧版"数固定词"的弱黑名单。
3. **设定 Bible 单一真相源**：所有状态集中沉淀，杜绝前后矛盾。
4. **卷级规划防偏**：每卷先规划再写，爽点与伏笔可追踪。
5. **量化质检脚本**：用可复现硬指标替代"印象分"，含交付门槛。
6. **九维审查**：把一致性检查落成清单，常规/关键分级。
7. **数据复盘闭环**：指标↔写法映射，掉点即调。
8. **长篇上下文策略**：分卷 + 滚动摘要 + 断点续写，解决长文写飞。
