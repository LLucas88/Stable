# 客户开发与触达助手

销售的第一步是找到客户。没有客户源，再好的话术也白搭。

## 什么时候用

- 不知道去哪找客户
- 加了客户微信不知道怎么开口
- 电话陌拜被秒挂，不知道怎么破
- 想建立稳定的获客渠道

---

## 二、微信获客技巧

### 2.1 微信加人话术

```
❌ 错误加人方式：
"你好，我是做XX的，加我了解一下"
→ 通过率 < 5%

✅ 正确加人方式：给对方一个理由

方案A（利益型）：
"你好，看到您在[领域]很专业，我这里有一份[行业报告/资料]，想分享给您"
→ 通过率 30-50%

方案B（共同圈子）：
"你好，我也是[XX群]的，看到您分享了[内容]，很认同，想交流一下"
→ 通过率 40-60%

方案C（解决问题）：
"你好，看到您在问[问题]，我刚好懂这个，可以帮您看看"
→ 通过率 50-70%

方案D（朋友推荐）：
"你好，[朋友名]推荐的，说您在[领域]很厉害，想认识一下"
→ 通过率 60-80%
```

### 2.2 加人后的第一条消息

```
❌ 错误开场：
"您好，我是做XX的，请问您有需要吗？"
→ 被删概率 90%

✅ 正确开场（3步走）：

步骤1：自我介绍（一句话，别说太多）
"你好，我是[名字]，[一句话说明你是做什么的]"

步骤2：找共同点/给价值
"看到您[朋友圈/群里]分享了[内容]，很有共鸣"
或
"我刚好有一份[资料/信息]，觉得可能对您有用"

步骤3：轻量互动（不推销）
"先不打扰您，以后有[领域相关]的问题可以随时问我~"

💡 核心：先建立联系，不要急着卖！
```

### 2.3 社群获客方法

```
步骤1：加入目标客户聚集的社群
→ 不要加同行群，要加客户群
→ 比如卖企业管理软件 → 加创业者群/老板群

步骤2：先贡献价值，再加人
→ 回答问题、分享干货、帮别人解决问题
→ 让群里的人先认识你、认可你

步骤3：私聊跟进
→ 对你内容点赞/评论的人，主动加微信
→ 加的时候备注："XX群的，之前聊过XX话题"

步骤4：持续经营
→ 朋友圈定期发有价值的内容
→ 别人需要的时候自然会找你
```

## 三、电话陌拜技巧

### 3.1 电话开场白（前10秒决定生死）

```
❌ 错误开场：
"您好，我是XX公司的，我们公司是做XX的..."
→ 3秒挂电话

✅ 正确开场模板：

模板A（痛点切入）：
"王总您好，我了解到很多[行业]公司都在头疼[痛点]，
我们刚好帮[同行公司]解决了这个问题，
想跟您交流一下我们的做法，您看方便吗？"

模板B（熟人引荐）：
"王总您好，是[朋友名]建议我联系您的，
说您这边可能有[需求]的需求，
耽误您1分钟简单介绍一下？"

模板C（信息差）：
"王总您好，我们最近帮[同行]做了一个[方案]，
效果很好，[具体数据]，
不知道您这边有没有类似的需求？"

模板D（活动/福利）：
"王总您好，我们下周有个[行业活动/免费体验]，
专门针对[行业]企业的，
想邀请您参加，我简单介绍一下？"
```

### 3.2 电话陌拜全流程

```
准备阶段（打电话前）：
├─ 查好对方公司/个人信息
├─ 准备好1分钟核心话术
├─ 手边放好纸笔记录
└─ 选对打电话时间

最佳电话时间：
├─ B2B企业客户：上午 10:00-11:30 / 下午 14:00-16:00
├─ 个体老板：上午 9:00-10:00 / 下午 16:00-17:00
├─ 上班族：午休 12:00-13:00 / 下班后 18:00-19:00
└─ 避开：周一上午 / 周五下午 / 饭点时间

通话流程：
1️⃣ 开场白（10秒）→ 引起兴趣
2️⃣ 确认需求（20秒）→ "您这边有XX方面的需求吗？"
3️⃣ 简单介绍（30秒）→ 核心卖点 + 案例
4️⃣ 争取面谈/加微信 → "方便加个微信发些资料给您看看？"
5️⃣ 记录信息 → 哪怕没成交也要记录，下次跟进

⚠️ 电话目标不是成交！是加上微信/约到面谈！
```

## 四、老客转介绍

```
转介绍是转化率最高的获客方式（转化率 60-80%）

什么时候开口求转介绍：
├─ 客户刚刚体验完服务/产品，很满意的时候
├─ 客户主动夸你的时候
├─ 帮客户解决了一个大问题的时候
└─ 节日/客户生日问候的时候

话术模板：
"王总，感谢您一直以来的信任~
有个事想请您帮个忙，
如果您身边有朋友也需要[服务]，
能不能帮我介绍一下？
当然我会给您/您朋友[优惠/回报]，
您看方便吗？"

激励机制：
├─ 给介绍人返利/折扣
├─ 给新客户专属优惠
├─ 送礼物/请吃饭
└─ 优先服务/VIP待遇
```

## 五、快速生成获客方案

当用户说"帮我找客户"或"怎么获客"时：

1. 问：你卖什么？目标客户是谁？客单价多少？
2. 推荐2-3个最适合的获客渠道
3. 生成对应的触达话术
4. 制定一周获客计划
5. 给出预期效果和注意事项
