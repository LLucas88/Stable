### 1.2 客户说"价格再谈谈" → 让步回复

```
📧 场景：王总回复"AI模块不错，但128,000有点贵，之前才86,000"
📧 目标：用条件交换的方式让步

─────────── 复制以下内容 ───────────

王总，理解您的感受。

确实从86,000到128,000涨幅不小，
但这次多了AI客服模块（单独买要60,000）。

这样吧，我能给到的是：

方案A：¥128,000/年，送2个月（相当于10个月价格）
  → 但需要签2年合约

方案B：¥118,000/年，1年一签
  → 标准价，没有赠品

方案C：先续基础版¥86,000/年，AI模块3个月后再加
  → 适合想先观望的情况

我个人建议方案A，因为AI客服你们越早上越省人力。
您看看哪个合适？

─────────── 结束 ───────────

💡 话术分析：
- 让步原则1：✅ 没有免费让步（方案A要签2年约）
- 让步原则2：✅ 幅度递减（A降8%、B降0%、C不降）
- 三选一：不要给"要/不要"的选择，给"选哪个"
- 引导方向：推荐方案A（对你最优），但给B/C做备选
```

## 场景2：异议处理（C-003 张伟）

### 2.1 客户说"有点贵，再谈谈"

```
📧 发送对象：张总（C-003）
📧 场景：报价¥350,000后，张总回复"有点贵"
📧 目标：不打价格战，打价值战

─────────── 复制以下内容 ───────────

张总，理解，350,000确实不是小数目。

不过咱们换个角度算笔账：

📊 您当前的数字：
   - 次品率：8%
   - 年产量：约500万件
   - 次品量：约40万件/年
   - 每件次品损失：约2.5元（材料+人工+返工）
   - 年损失：约¥100万

📊 上系统之后：
   - 次品率降到3%以内
   - 年次品损失降到¥37.5万
   - 年节约：¥62.5万

📊 投入产出：
   - 一次性投入：¥350,000
   - 年节约：¥62.5万
   - 回本周期：约5.6个月
   - 之后每年纯省¥62.5万

这还不算：
   - 客户投诉减少带来的订单留存
   - 质检人员可以从6人减到3人（年省¥18万）
   - MES系统帮你们提升排产效率15%

所以350,000看起来贵，但5个月就回来了。
后面每年帮您省80万+，这个账划算不？

─────────── 结束 ───────────

💡 话术分析：
- 张总是🔵分析型 → 全程用数据说话，零情怀
- 对比法：当前损失¥100万 vs 投入¥35万
- 回本周期：5.6个月（非常具体，不是"很快回本"）
- 隐性收益：追加质检人力节约+排产效率（增加说服力）
- 没有降价！只算账。如果客户还嫌贵，再出三档方案
```

## 场景4：电话陌拜冷启动（通用模板）

### 4.1 电话开场白（10秒版）

```
📞 场景：给新线索打第一个电话
📞 目标：不被挂电话 + 加上微信

─────────── 话术 ───────────

（前3秒）：
"王总您好，我是[公司名]的[名字]"

（3-10秒）：
"我了解到很多[行业]公司都在头疼[痛点]，
我们刚好帮[同行公司]解决了这个问题，[具体数据]，
想跟您交流一下我们的做法，您看方便吗？"

─────────── 结束 ───────────

❌ 千万不要说的开场：
"您好我是XX公司的，我们公司是做XX的..."
→ 客户3秒内挂电话（听起来就是推销）

✅ 如果客户说"没兴趣"：
"理解王总，那我不耽误您时间。
我加您个微信，把资料发您，
您有空的时候看看，有问题随时找我。"
→ 目标不是电话成交，是加上微信！
```

### 4.2 客户不回消息（3次跟进序列）

```
📧 场景：发了方案/消息，客户3天没回

第1次（Day 3）：
"王总，之前发的方案您看了吗？
有不明白的地方随时问我~"
→ 温和，不施压

第2次（Day 7）：
"王总，分享一个跟您行业相关的案例，
[同行公司]用了之后效果不错，有空看看~"
→ 不提业务，纯分享价值

第3次（Day 14）：
"王总好久不见，最近怎么样？有空一起喝茶~"
→ 轻松，像朋友问候

⚠️ 3次不回 → 降频到月度触达
⚠️ 绝对不要说"您考虑得怎么样了"
```

## 话术使用指南

```
怎么用这些话术模板：

1. 找到对应场景
   → 客户在哪个环节？→ 用哪个阶段的话术

2. 替换变量
   → [公司名]、[客户名]、[金额] → 替换成实际信息

3. 适配性格
   → 🔴支配型：简洁、数据、结论先行
   → 🟡表达型：故事、案例、社交认可
   → 🟢亲和型：温暖、不催、安全感
   → 🔵分析型：数据、图表、保障条款

4. 发送前自检
   □ 有没有叫对称呼？（王总/美琪姐/张总）
   □ 有没有个人化细节？（不是通用模板）
   □ 有没有明确CTA？（下一步是什么）
   □ 有没有给客户台阶？（不逼到死角）
```
