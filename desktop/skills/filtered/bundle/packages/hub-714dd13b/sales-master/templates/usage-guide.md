## 一、30秒快速上手

### 你只需要做3件事

```
第1步：告诉AI你在卖什么
       "我是卖[XX产品/服务]的，目标客户是[XX行业/人群]，客单价大概[XX元]"

第2步：告诉AI你现在遇到什么问题
       "我加了个客户微信不知道怎么聊"
       "客户说太贵了怎么回"
       "合同快到期了怎么续约"
       "不知道怎么找新客户"

第3步：AI会给你具体的话术、模板、建议
       → 直接复制粘贴使用
       → 或者让AI根据你的情况定制
```

**就这么简单。不需要学理论，不需要背流程。你说问题，AI给方案。**

## 三、实操示例（跟着做一遍）

### 示例1：从零开始找客户

```
你：我是做AI客服系统的，卖给中小企业，客单价5-8万/年，怎么找客户？

AI：根据你的产品（B2B、客单价5-8万），推荐3个渠道：

渠道1：老客转介绍（转化率最高，成本最低）
→ 话术："王总，上次的问题解决了，您身边有朋友也需要吗？"
→ 适合你现有客户不多时先积累几个成功案例

渠道2：行业社群（精准）
→ 加入中小企业老板群/创业者群
→ 先贡献价值（分享AI趋势），再私聊
→ 加微信话术："XX群的，看到您问了AI客服的问题，我刚好做这个"

渠道3：脉脉/领英（B2B精准）
→ 搜索目标行业的HR/客服负责人
→ 不是直接推销，先建立专业形象

你：那第一个渠道具体怎么做？我有一个客户挺满意的

AI：（给出转介绍具体话术，参考 templates/demo-scripts.md 场景6）
```

### 示例2：跟进一个犹豫的客户

```
你：我有个客户王总，聊了2周了，方案也发了，但他说"考虑一下"就再没回复，已经5天了，怎么跟进？

AI：先判断一下：
- 客户性格类型？（如果不知道，看Phase 1.2四种类型）
- 客户说"考虑一下"的真实原因？

考虑到他已经5天没回，建议这样跟进：

第6天（今天）发：
"王总，之前发的方案您看了吗？
有几个客户最近也问了类似的问题，我整理了个对比表，
发您看看，对您做决定可能有帮助~"
（不提"考虑得怎么样了"，给价值而不是施压）

如果还不回：
第10天发一个行业新闻/案例分享（完全不提业务）
第14天发一条轻松的问候"最近怎么样"

⚠️ 连续3次不回 → 降频到月度触达

你：那他到底是什么意思？是真不想要吗？

AI："考虑一下"通常有3种可能：
1. 真的在比较（有竞品在竞争）→ 需要你主动问"主要在比较哪方面"
2. 有顾虑但不好意思说 → 需要你主动引导
3. 不是优先级 → 需要制造紧迫感

下次如果联系上了，可以直接问：
"王总，方案您也看了，目前主要顾虑是什么？
价格、效果、还是时间安排？我帮您分析一下"
→ 把模糊的"考虑"变成具体的问题
```

### 示例3：准备续约

```
你：客户王总的合同3月1日到期，现在1月中旬了，怎么续约？

AI：现在是到期前45天，已经进入🟡黄灯阶段了。

立刻做3件事：

1. 回顾合作成果（你帮客户实现了什么？）
→ "这两年帮智链做了XX、XX、XX"

2. 准备升级方案（不只是续约，要有新东西）
→ 新功能/新服务/老客户优惠

3. 发续约沟通（参考 templates/demo-scripts.md 场景1.1）

你：他可能会嫌贵，续约价想涨一点

AI：那准备好让步方案（三档）：
- 方案A：原价+升级，送2个月（要求签2年约）
- 方案B：小幅涨价，1年一签
- 方案C：维持原价，不加新功能

让步原则：
- 每次让步都要换条件（签长约/预付/加模块）
- 让步幅度递减（10% → 5% → 2%）
- 让步要显得困难
```

## 七、常见问题

```
Q：我完全没做过销售，能学会吗？
A：能。这套系统的设计逻辑就是"你说问题，AI给方案"。
   不需要你学理论，不需要背话术。遇到问题直接问就行。

Q：我不懂怎么判断客户性格类型怎么办？
A：简单方法——
   说话直接、爱打断你的 → 🔴支配型
   爱聊天、爱讲故事的 → 🟡表达型
   温和、说话慢、怕做决定 → 🟢亲和型
   要数据、要对比、要细节 → 🔵分析型
   判断不了就用通用版话术，AI会自适应。

Q：话术可以直接复制发给客户吗？
A：可以，但建议先替换里面的[变量]（名字、金额、行业等）。
   更好的方式是告诉AI你的具体情况，让它定制版本。

Q：这套系统适合什么行业？
A：全行业通用。B2B/B2C、科技/保险/制造/零售/服务都能用。
   区别只是不同行业侧重不同环节。

Q：我不是用Hermes的，能用这套系统吗？
A：可以。所有文件都是Markdown格式，任何AI工具都能读。
   把SKILL.md和参考文件丢给ChatGPT/Claude/豆包都能用。

Q：怎么添加我自己的客户数据？
A：复制 demo-clients.md 里的客户档案模板，
   填入你的客户信息。建一个clients/目录存放。
```

## 八、邮件自动化快速上手

> 定时发邮件、生日提醒、合同到期提醒、产品营销群发——全自动。

### 8.1 3步开启邮件自动化

```
第1步：配置邮箱
  cd scripts/
  # 编辑 email_config.yaml，填入SMTP信息+公司信息+销售人员信息

第2步：初始化数据库
  python email_automation.py init
  # → 自动创建3个演示客户 + 关键日期提醒 + 定时任务

第3步：启动调度引擎
  python email_automation.py scheduler
  # → 每天8点自动检查生日/合同到期，自动发邮件
```

### 8.2 常用命令速查

```
# 查看所有客户
python email_automation.py list-customers

# 发一封邮件（用模板，自动带公司签名）
python email_automation.py send --to xxx@qq.com --template birthday_wish

# 群发产品推广给A级客户
python email_automation.py campaign --template product_promotion --level A

# 检查今天有没有需要触发的提醒
python email_automation.py check-dates

# 模拟测试（不真的发邮件）
python email_automation.py send --to xxx@qq.com --template birthday_wish --dry-run
```

### 8.3 邮件签名自动注入

每封邮件自动追加公司签名（从 email_config.yaml 读取）：

```
--
[你的姓名]
销售总监
深圳[你的公司简称]技术有限公司
tel: [你的手机号] | email: [你的邮箱]
web: [你的公司网站]
```

修改签名 → 编辑 `scripts/email_config.yaml` 中的 `agent` 部分。
