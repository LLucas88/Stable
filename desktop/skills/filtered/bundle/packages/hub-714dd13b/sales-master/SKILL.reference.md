# 销售一条龙全流程引擎

> 好销售不是天赋，是系统。这套引擎把销售拆成17个环节，每个环节都有工具、模板和话术，直接拿来用。

## 什么时候用

- 刚入行不知从哪开始 / 获客难不知去哪找客户 / 加了微信不知怎么推进 / 客户聊了半天不成交 / 不知怎么报价谈判逼单 / 签完单不知怎么维护 / 客户流失不知怎么挽回 / 想系统化管理客户（生日提醒、合同到期、续约）/ 想复盘提升转化率
- **核心一句话：只要涉及"卖东西给客户"的任何环节，先用这个skill。**

## ⚠️ 使用纪律

1. **不要跳环节**：销售有节奏。获客没做好就去逼单等于自杀。
2. **先诊断后开药**：用户问"怎么卖"，先问3个问题（卖什么/卖给谁/客单价），再给方案。
3. **每条话术都要场景化**：结合行业、产品、客户类型给定制版本，不给通用模板。
4. **重视记录**：不记录 = 不存在。
5. **邮件需配置**：首次使用需复制 `scripts/email_config.example.yaml` 为 `email_config.yaml` 并填入你的邮箱和公司信息。
6. **中文优先**：所有邮件模板、话术、报告必须用中文。
7. **测试从简**：测试邮件每种类型只发1条。QQ邮箱短时间发>10封会被限流。

## Phase 1：策略定位

> 没有定位，就没有方向。90%的销售失败，是因为找错了人。

**1.1 理想客户画像（ICP）**：3维度定义——行业（成交率+客单价双高的2-3个）、公司（规模/阶段/地域/决策链）、个人（职位/关注点/决策方式/沟通偏好/性格类型/异议）。

**1.2 四种性格类型**：🔴支配型(老虎)"直接说重点"→开门见山给结论 | 🟡表达型(孔雀)"讲故事"→多互动多赞美 | 🟢亲和型(考拉)"别催我"→建信任给安全感 | 🔵分析型(猫头鹰)"给数据"→给数据案例保障。

**1.3 差异化定位**：3路线——低价(⚠️易陷价格战)/差异(做竞品做不到的)/聚焦(细分做到极致)。
卖点公式：**"我们帮[目标客户]解决[核心痛点]，通过[差异化方法]，实现[具体效果]"**
✅ "帮跨境电商解决退货率高，通过AI质检，退货率从15%降到3%"  ❌ "行业领先的AI提供商"

## Phase 2：获客开发

> 销售第一步是找到客户。没有客户源，再好的话术也白搭。

**2.1 渠道矩阵**：线上(微信社群/抖音小红书/知乎百度/脉脉领英/投流SEM/电商) + 线下(行业展会/商会协会/地推陌拜/异业合作/老客转介绍转化最高/沙龙)。
选择：客单价>5000→人脉/转介绍/展会 | <500→投流/社媒/电商 | B2B→脉脉领英/活动/转介绍 | B2C→抖音/小红书/社群/投流。

**2.2 微信获客**：加人通过率排序——朋友推荐(60-80%)>解决问题(50-70%)>共同圈子(40-60%)>利益驱动(30-50%)。加人后3步走：①自我介绍 ②给价值/找共同点 ③轻量互动不推销。**核心：先建立联系，不要急着卖！**

**2.3 电话陌拜**：开场白前10秒决定生死——3模板：痛点切入/熟人引荐/信息差。最佳时间：B2B企业 10:00-11:30/14:00-16:00｜个体老板 9:00-10:00/16:00-17:00｜上班族 12:00-13:00/18:00-19:00。避开周一上午/周五下午/饭点。**电话目标不是成交，是加微信/约面谈！**

**2.4 线索资格判定**：BANT(B预算/A决策权/N需求/T时间线，全满足=A级重点/3项=B级培育/2项以下=C级/无预算需求=放弃)。MEDDIC深度判定(B2B大单)：M量化指标/E经济决策者/D决策标准/D决策流程/I痛点确认/C内部支持者。

**2.5 行业特定获客渠道**：不同行业有专属渠道，AI应根据客户行业主动推荐：

| 行业 | 高效获客渠道 | 触达方式 |
|------|------------|---------|
| 跨境电商 | 亚马逊卖家群/跨境峰会(慕尼黑/拉斯维加斯)/ERP服务商异业合作/鹰熊汇/雨果跨境 | 卖家社群+行业活动 |
| SaaS/企业服务 | 脉脉/领英/36氪/企服点评平台/SaaS大会 | 精准1对1+内容引流 |
| 制造业 | 行业展会(工博会/CME)/商会协会/1688/行业协会 | 展会+转介绍 |
| 教育/教培 | 家长社群/学校合作/教育展/小红书种草 | 社群+内容+体验课 |
| 餐饮/零售 | 美团/大众点评/餐饮加盟展/供应链展 | 地推+展会+异业 |
| 保险/金融 | 社群运营/转介绍/理财沙龙/内容引流(知乎/小红书) | 社群+内容+活动 |

💡 **AI行为指引**：用户说行业后，先查上表推荐2-3个该行业最高效的渠道，再给通用渠道作为补充。不知道行业时，先问「你的客户主要在哪个行业？」

## Phase 3：跟进培育

> 80%的成交需要5次以上跟进。大多数人跟进2-3次就放弃了。

**3.1 跟进节奏（14天5次）**：第1天总结消息→第3天有价值内容→第5天朋友圈轻互动(不私聊)→第7天方案反馈→第10天分享案例→第14天试探逼单或降门槛("先从小模块试试？")。

**3.2 跟进话术（4场景）**：
- **"把资料发我看看"** ⚠️（B2B最常见！90%是客气拒绝，不是真要看）：
  → 不要只发资料！发资料的同时锁定下次沟通："资料我整理好了，不过每个人的情况不一样，我给您定制一版。您看周三还是周四方便聊10分钟？"
  → 如果客户坚持"先发来看看"：发精简版（不要发全部），附一句"详细版我根据您的情况定制，聊完马上给您"
  → 发完后第2天跟进："资料看了吗？有没有什么问题？"（不要等客户主动找你）
  → 连续2次不回→降频月度触达
- 不回消息：逐次降压力，不提"考虑得怎么样"，连续3次不回→降频月度触达
- "考虑一下"→"主要考虑哪方面？价格/效果/时间安排？"
- "最近忙"→"理解，方案先备好，什么时候方便我联系您？"（锁定具体时间）

**3.3 培育内容**：朋友圈 3:1:1——3份价值内容(干货/洞察/案例)+1份生活+1份产品/活动。发圈：早8-9/午12-13/晚20-22；周末生活，工作日专业。

## Phase 4：需求挖掘

> 不要急着卖产品。先搞清楚客户到底要什么。

**4.1 SPIN提问法**：S现状("目前[流程]怎么做的？")→P痛点("哪个环节最头疼？")→I影响("不解决一年损失多少？")→N需求("如果有方案能解决，您感兴趣吗？")。💡 让客户自己说出需求，比你说更有说服力10倍。

**4.2 倾听技巧**：3F倾听(Fact事实/Feeling感受/Focus意图) + 复述确认("您的意思是___，对吗？") + 5Why挖深层需求(客户要CRM→真正需求是"防止客户流失")。

---

## Phase 5：方案报价

> 方案不是产品说明书，是帮客户算账。

**5.1 方案7部分**：①客户现状与痛点 ②解决方案概述 ③实施方案与时间线 ④预期效果与量化收益 ⑤成功案例 ⑥报价明细(分模块) ⑦下一步行动。

**5.2 FABE介绍法**：F特性→A优势→B利益→E证据("XX公司用了从___变成___")。

**5.3 报价策略**：报价前明确4个数字——报价/目标价/底线价/竞品价。3技巧：锚定法(先说市场区间)/拆分法(均摊到每天XX元)/对比法(人工成本vs方案费)。⚠️ **报价时机：价值塑造完再报价！没认识到价值就报价=嫌贵。**

---

## Phase 6：谈判成交

> 客户说不，才是销售的开始。

**6.1 十大异议处理**（详见 `references/objection-handling.md`）：

```
"太贵了"→共情+拆解+对比+案例+选项    "考虑一下"→"主要考虑哪方面？"
"不需要"→提问引导发现问题            "有供应商了"→找薄弱环节(不说竞品坏话)
"预算不够"→基础版起步 or 算拖延成本   "跟领导商量"→帮准备向上汇报材料
"别家更便宜"→打价值战不打价格战      "先试试免费"→给试用期+测试建议+配置支持
"竞品免费"→算时间成本+免费隐藏成本    "跟技术确认"→给技术材料+直接对话IT
```

**6.2 让步4原则**：①永远不免费让步(换[签2年约/预付/加模块]) ②幅度递减(10%→5%→2%) ③显得困难("请示领导""破例了") ④每次让步要有回报。

**6.3 逼单成交七法**：信号=客户问细节/讲价/问别人/算时间/对比竞品/问付款。①二选一("标准版还是旗舰版？") ②限时(活动价月底恢复) ③稀缺(剩3名额) ④假设成交("下周二还是周三实施？") ⑤风险逆转(不满意全额退款) ⑥从众(XX公司都选了我们) ⑦最后一步("就差签合同了")。

**6.4 成交后**：别急着走！①确认关键信息 ②告知下一步 ③设下次接触点 ④感谢 ⑤立即推进交付(当天发合同/48h启动实施)。

## Phase 7：签约交付

> 谈完不等于签了，签了不等于收钱了。

**7.1 合同检查清单（9项）**：合同主体/服务范围/金额和付款方式(推荐50%预付+30%中期+20%验收)/交付时间/验收标准/售后条款/违约责任/发票/续约条件。⚠️ 不口头承诺 / 标准量化 / 付款节奏卡住 / 留书面记录。

**7.2 报价单/合同模板**：详见 `references/contract-templates.md`

**7.3 应收款追踪**：到期前7天温和提醒→到期当天正式通知→逾期3天跟进原因→逾期7天升级→逾期30天发催款函(考虑暂停服务/法律手段)。⚠️ 催款天经地义，话术客气但坚定。

**7.4 Onboarding五步法**：①欢迎期望管理(Day0)→②快速启动(Day1-3，48h给第一个可见成果)→③阶段性交付(每周汇报)→④验收确认(签字)→⑤交付后关怀(Day7/30/90：使用回访→效果评估→续约引导)。

## Phase 8：客户维护与关键日期管理

> 开发新客户成本是维护老客户的5-10倍。会卖的人赚一次，会管的人赚一辈子。

**8.1 客户分级**：A级(VIP，每周互动/每月面谈/专属礼物/问题第一时间处理) | B级(潜力，每两周互动/节日问候/推荐升级) | C级(普通，每月朋友圈互动/节日群发带名字/大促通知) | D级(沉睡，每季度唤醒/专属回归优惠)。

**8.2 客户喜好档案**：VIP/A级记录——基本信息(称呼/公司/生日/籍贯)+沟通偏好(方式/时间段/信息偏好)+业务偏好(关注点/决策方式/风险偏好)+个人偏好(性格/爱好/家庭/饮食禁忌)。⚠️ 日常交往自然收集，记录下来！

**8.3 关键日期管理系统 ⭐**（客户维护核心，客户觉得你用心就在这些细节）

📧 **自动化邮件提醒**：

```bash

python email_automation.py init                  # 初始化数据库+演示数据
```

详见 `references/email-automation.md` 和 `references/key-dates-system.md`

```
关键日期：🎉个人(生日/纪念日/孩子生日/升职,提前3天) | 📅业务(合同到期,提前30/60/90天预警/续约窗口) | 📆行业(财年结束日/旺季前/展会/政策节点)
提醒按级别：A级手写贺卡+礼物(200-500元) | B级微信祝福+小礼物 | C/D级微信祝福(带名字不群发)
合同到期续约4封信(60/30/15/7天)→详见 references/key-dates-system.md
```

**8.4 日常维护**：朋友圈互动(每天10分钟，有意义点赞/走心评论/分享价值) + 微信私聊(不每次聊业务/主动分享有用信息/记住客户提过的事) + 节日问候(**不要群发！**单独发带名字，重要客户打电话/寄礼物)。

## Phase 9：复购扩展与转介绍

**9.1 复购6策略**：会员积分体系/定期补货提醒/搭配推荐(交叉销售)/专属优惠/升级引导(向上销售)/服务绑定。

**9.2 复购话术（3场景）**：快到期("提前续费有专属优惠") / 有新品("预留了体验名额") / 顺便提("上次您说[需求]，刚好出了方案")。

**9.3 转介绍系统**（转化率60-80%、成本最低的获客）：开口时机=客户很满意/主动夸你/帮解决大问题后/节日问候时。话术："如果身边朋友也需要[服务]，能帮我介绍吗？我会给您/朋友[优惠]"。激励：返利/折扣/新客户优惠/送礼物/优先服务。⚠️ 产品好+服务好+关系好=自然转介绍，不要硬要。

## Phase 10：流失预警与挽回

**10.1 流失预警信号**（出现2个以上）：回消息越来越慢/短→不再主动咨询→朋友圈不互动→投诉增多→提到竞品→取消续约/减少采购→推脱见面。

**10.2 流失挽回话术（4场景）**：很久没联系("好久不见！有空喝茶~"先重建联系) / 转向竞品("用着还好吗？关系在，有问题随时找我~"大度等机会) / 因不满离开(真诚道歉+具体改进+承诺) / 回归优惠("老客户回归专属优惠，想到您了")。

## Phase 11：销售复盘与漏斗管理

**11.1 销售漏斗**：线索→意向(30-50%)→方案(40-60%)→谈判(50-70%)→成交(60-80%)。整体5-15%。
诊断：线索→意向低=获客渠道不对 / 意向→方案低=需求挖掘不到位 / 方案→谈判低=方案没说服力 / 谈判→成交低=逼单能力不足。

**11.2 成交预测（加权预测法）**：客户价值=预计金额×成交概率。概率：谈判70-90%/方案40-60%/意向20-40%/初次接触5-20%/线索1-5%。

**11.3 周报模板**：本周数据(新增线索/拜访/方案/成交金额/回款金额+环比) + 本周成交 + 重点推进 + 下周计划 + 复盘改进点。

### ⚠️ 邮件发送注意

- **QQ邮箱限流**：连发>10封触发"Connection unexpectedly closed"，每封间隔≥60秒
- **中文优先** / **测试从简**(每种类型只发1条)
- **后台进程陷阱**：Hermes后台进程在WSL bash中执行，涉及Windows路径的Python脚本必须前台运行
- **签名自动注入**：每封邮件底部自动追加公司签名（从email_config.yaml读取）
