# Phase 15：销售管理与行业差异化

> 从"个人销售"到"团队管理"的升级，以及不同行业的销售打法差异。

## 15.1 销售团队目标与配额管理

```
目标设定原则：60-70%的人应该能完成配额。
→ 全员完成=目标太低 | 没人完成=目标太高

配额分配3种方法：

方法1：历史业绩法（最常用）
├─ 按去年实际业绩 × 增长率（通常20-30%）
├─ 新客户：按区域/行业潜力分配
└─ 缺点：去年运气好的人今年目标高

方法2：自下而上法（最公平）
├─ 让每个销售自己报Pipeline预测
├─ 汇总后乘以历史转化率
├─ 管理层审查是否合理
└─ 优点：销售自己报的更有认同感

方法3：市场容量法（最科学）
├─ 计算每个区域/行业的目标市场容量(TAM)
├─ 按市场份额目标倒推配额
├─ 参考竞品在该区域的份额
└─ 适合扩张期企业

配额分配注意事项：
├─ 老客户续约算不算配额？（建议算，鼓励维护）
├─ 新签和续约的配额权重不同（新签权重更高）
├─ 大客户和小客户的配额折算（1个大客户=10个小客户？）
├─ 新人配额打8折（前3个月Ramp-up期）
└─ 季度配额 vs 年度配额（建议季度，及时调整）

年度目标拆解到执行层：
年目标 → 季度目标 → 月目标 → 周行动 → 日待办
例：年目标1000万 → 季度250万 → 月83万 → 周21万
  → 本周要推进5个谈判阶段客户（加权预测21万）
```

## 15.2 SPIF专项激励设计

```
SPIF = Special Performance Incentive Fund（专项激励基金）
不是常规提成，是临时性的额外激励，用来推动特定行为。

SPIF使用场景：
├─ 新产品上市：卖新品额外奖励X元/单
├─ 库存清理：卖滞销品额外奖励
├─ 季度冲刺：最后2周成交额外+2%提成
├─ 多年合约：签2年约额外奖励
├─ 预付款：客户全款预付额外奖励
├─ 转介绍：推荐成交额外奖励
└─ 培训完成：新人通过认证奖励

SPIF设计原则：
├─ 时效性：有明确起止日期（"本月内"）
├─ 简单明了：销售不用算就知道能拿多少
├─ 足够诱人：金额/比例要让销售愿意为此改变行为
├─ 不要常态化：SPIF是临时刺激，不能变成固定提成
├─ 全员公平：所有人都有机会争取
└─ 即时兑现：达成后1周内发放（不要等到月底）

⚠️ SPIF的陷阱：
├─ 滥用SPIF → 销售只在有SPIF时才卖力（形成依赖）
├─ SPIF太频繁 → 变成"常规提成的一部分"，失去激励效果
├─ 目标偏移 → 销售为了SPIF去推不该推的产品
└─ 内部不公平 → 只有部分人能拿到的SPIF影响团队士气

好的SPIF举例：
"本季度最后2周，签2年合约额外+3%提成"
→ 时间限定+行为明确（签长约）+奖励清晰
```

## 15.3 反贿赂与送礼红线

```
在中国做销售，"请客送礼"是文化，但红线必须清楚。

什么能送/做什么：
├─ 正常商务餐（人均200元以内，合理）
├─ 节日小礼品（中秋月饼/端午粽子/年货，价值合理）
├─ 公司定制周边（笔记本/水杯/U盘，有品牌价值）
├─ 行业活动邀请（峰会/沙龙/考察）
├─ 知识/信息分享（行业报告/数据/洞察）
└─ 人脉引荐（帮客户对接资源，非物质价值最高）

什么不能送/做：
├─ 现金/购物卡/储值卡（=贿赂）
├─ 高价值礼品（奢侈品/名表/金条）
├─ 为客户私人消费买单（旅游/娱乐/家庭开支）
├─ 回扣/返点（私下给个人，不入公司账）
├─ 给公务员/国企人员任何形式的好处（法律风险极高）
└─ 以"咨询费"等名义变相行贿

判断标准：
├─ "如果这件事被公开，你会尴尬吗？" → 会就别做
├─ "这个礼物是给公司还是给个人的？" → 给个人的要格外小心
├─ "这个金额在正常商务往来范围内吗？" → 超出就是问题
└─ "对方是公务员/国企领导吗？" → 是就一分钱都不能送

⚠️ 法律红线（《刑法》/《反不正当竞争法》）：
├─ 给公司/企业人员送礼金额>3万 = 行贿罪
├─ 给公务员送礼金额>3万 = 行贿罪（从重处罚）
├─ 即使金额不到3万，也可能构成违法
└─ 外企员工还需遵守FCPA（美国海外反腐败法）

安全做法：
├─ 所有礼品走公司流程审批+留记录
├─ 礼品金额控制在合理范围内（单次<500元）
├─ 送公司不送个人（"给贵公司团队"而非"给您"）
├─ 客户公司的合规政策优先（有些公司禁止收任何礼物）
└─ 有疑问时问合规部门/法务，不要自己判断
```

## 15.4 制造业/工业品销售特点

```
制造业B2B销售和普通B2B有很大不同。

制造业销售特点：
├─ 决策周期长（3-12个月甚至更长）
├─ 决策链复杂（采购+技术+生产+财务+老板）
├─ 试错成本高（选错了影响整条产线）
├─ 技术门槛高（必须懂客户的技术/工艺）
├─ 客单价高（几十万到上千万）
├─ 需要现场考察/POC验证
└─ 售后/实施极重要（停线=巨大损失）

制造业销售流程：
1. 技术交流（先跟工程师聊技术匹配度）
2. 方案定制（针对具体产线/工艺定制）
3. 小批量试产/POC（用数据证明效果）
4. 正式报价（含实施/培训/售后）
5. 招投标（大单通常需要）
6. 合同审核（法务/采购/财务逐层审批）
7. 实施/安装/调试
8. 验收（按合同标准逐项验收）
9. 售后维护（响应速度是关键）

关键决策角色：
├─ 老板/总经理：看ROI和投资回报周期
├─ 生产总监：看效率提升和减少人工
├─ 技术总监/工程师：看技术参数/兼容性/稳定性
├─ 采购经理：看价格/交期/付款条件
├─ 财务：看预算/现金流/ROI
└─ 操作工/班组长：看好不好用（影响采用率）

话术差异（vs SaaS销售）：
├─ 不说"颠覆/创新"，说"效率/良品率/降本"
├─ 不讲PPT，讲数据/案例/现场试产结果
├─ 不说"月费/订阅"，说"投资回收期/年节约"
├─ 不做Demo，做现场POC
└─ 茶台是主战场（不是会议室）
```

## 15.5 保险/金融产品销售合规

```
保险和金融产品销售有严格的合规要求。

合规底线：
├─ 必须持证销售（保险从业资格/证券从业资格）
├─ 如实告知（不能隐瞒免责条款/除外责任）
├─ 不得夸大收益（"保证赚XX%"=违规）
├─ 不得误导销售（把保险说成存款/理财）
├─ 双录要求（部分产品需要录音录像）
├─ 冷静期/犹豫期（客户有权在X天内全额退保）
├─ 适当性管理（不能给风险承受能力低的客户卖高风险产品）
└─ 客户信息保密（《个人信息保护法》）

保险销售流程：
├─ 需求分析（家庭状况/收入/负债/保障缺口）
├─ 方案设计（重疾+医疗+意外+寿险+教育金组合）
├─ 健康告知（如实填写，不能代客户隐瞒）
├─ 产品讲解（保障范围+免责条款+犹豫期，全部讲清楚）
├─ 投保（双录+签名+缴费）
├─ 回访（保险公司客服电话确认）
├─ 保单递送（当面讲解条款+保单管理）
└─ 长期服务（续保提醒+理赔协助+年度保障回顾）

话术合规检查：
├─ ✅ "这个产品的预期收益率是X%，但投资有风险"
├─ ❌ "这个绝对赚，稳赚不赔"
├─ ✅ "这个保障范围是XX，免责条款是XX"
├─ ❌ "什么都保，出了事就赔"
├─ ✅ "您有10天犹豫期，期间退保全额退款"
└─ ❌ "签了就不能退了"
```

## 15.6 销售经理带团队与1对1辅导

```
好的销售经理不是自己卖得最好的，是能让团队都卖好的。

1对1辅导（每周或每两周1次，30-45分钟）：

1对1结构（4部分）：

① 数据review（5分钟）
├─ 本周Pipeline变化（新增/推进/流失）
├─ 目标完成进度（本周/本月/本季度）
├─ 关键指标（电话量/会面数/方案数/成交数）
└─ 找到最大的问题/机会

② 重点客户review（15分钟）
├─ 挑2-3个重点客户深入讨论
├─ 客户在哪个阶段？下一步是什么？
├─ 有什么障碍？需要什么帮助？
├─ 成交概率和预计时间
└─ 经理提供策略建议/资源支持

③ 技能辅导（10分钟）
├─ 本周遇到的最大挑战是什么？
├─ 一起分析一个具体case（录音/复盘）
├─ 角色扮演练习话术
├─ 分享最佳实践
└─ 设定下周改进目标（1-2个具体行动）

④ 行动计划（10分钟）
├─ 下周的Top 3优先事项
├─ 需要经理提供的支持/资源
├─ 需要协调其他部门的事项
└─ 下次1对1的重点话题

辅导原则：
├─ 问>说（让销售自己想答案，不是你给答案）
│   "你觉得这个客户为什么卡住了？"
│   "如果重来一次你会怎么做？"
├─ 具体>笼统（不说"你要更努力"，说"这周多打20个电话"）
├─ 正向>负向（先夸做得好的，再说需要改进的）
├─ 数据>感觉（用Pipeline数据说话，不靠主观判断）
└─ 行动>讨论（每次1对1必须产生2-3个具体行动项）

团队管理节奏：
├─ 每天：晨会5-10分钟（今日目标+互相激励）
├─ 每周：1对1辅导 + 团队周会（分享经验+复盘）
├─ 每月：月度总结 + 下月计划 + 表彰Top performer
├─ 每季：季度kickoff + Pipeline review + 培训
└─ 每年：年度规划 + 配额分配 + 团队建设
```

## 15.7 销售漏斗预测准确度提升

```
预测不准 = 公司没法做决策（招人/备货/预算）。

预测不准的5个原因：
① 销售过于乐观（把"有机会"当成"快成交"）
② 没有标准化的阶段定义（每个人对"意向"理解不同）
③ 不跟踪历史转化率（没有数据基准）
④ 忽略竞争因素（以为只有自己在跟客户谈）
⑤ 不更新Pipeline（Pipeline是3周前的旧数据）

提升预测准确度5步法：

Step 1：标准化阶段定义
├─ 定义每个阶段的具体标准（什么条件才能进入下一阶段）
│   例："方案阶段"= 客户确认了需求+你发了书面方案
│   不是"我觉得客户有兴趣"
├─ 所有销售统一理解（培训+打印贴在桌上）
└─ 不符合标准的不准进入下一阶段

Step 2：加权预测法
├─ 每个阶段对应一个成交概率（基于历史数据）
│   线索5% → 意向25% → 方案45% → 谈判70% → 成交90%
├─ 预测金额 = 客户金额 × 阶段概率
├─ 汇总所有客户的加权金额 = 总预测
└─ 加权预测比"销售说会成交"准确3-5倍

Step 3：三档预测
├─ 乐观预测（Best Case）：所有可能成交的（概率>50%）
├─ 基准预测（Commit）：几乎确定成交的（概率>70%）
├─ 保守预测（Pipeline）：全部在跟的（概率>5%）
└─ 向上汇报基准预测，内部看三档范围

Step 4：定期校准
├─ 每周更新Pipeline（过期的/变化的及时调整）
├─ 每月对比预测vs实际，计算偏差率
├─ 偏差>20% → 找原因（哪个阶段判断不准？）
├─ 3个月后建立你团队的历史转化率基准
└─ 用历史数据校准每个阶段的概率

Step 5：预测评审会
├─ 每周/每两周开Pipeline review会
├─ 逐个客户过：
│   "这个客户上次更新是什么时候？"
│   "下一步行动是什么？什么时候做？"
│   "有没有竞品在竞争？"
│   "这个deal你有多确定？（1-10分）"
├─ 剔除"僵尸deal"（3个月没推进的客户，不要骗自己）
└─ 经理的职责：挑战销售的乐观判断（"你说70%确定，凭什么？"）

⚠️ 预测管理的黄金法则：
├─ 永远不要100%相信销售自己说的概率
├─ 用证据说话（有预约吗？有方案吗？有报价吗？）
├─ 历史数据是最好的预言家
└─ 宁可保守也不要过度承诺
```
