# Phase 13：高阶销售战术

> 资深销售和普通销售的分水岭。以下场景是B2B大单、长周期、多决策者才会遇到的复杂局面。

## 13.1 多决策者接触策略（Multi-Threading）

```
只跟客户公司一个人 = 把鸡蛋放在一个篮子里。
那个人离职/调岗/改主意，你的deal就死了。

为什么要多线程接触：
├─ 韧性：一个人消失了deal还能活
├─ 速度：多条线并行推进比单线快
├─ 情报：不同角色给你不同的信息
└─ 影响力：在客户内部建立多方支持者

4类利益相关者及沟通策略：

① 高管/决策者（CEO/CFO/VP）
   关心：ROI、战略对齐、风险控制、竞争优势
   沟通：简洁、数据导向、讲业务成果不讲功能
   话术："王总，这个方案帮您每年节省XX万，
         X个月回本，XX公司（同行）也在用"
   ⚠️ 尊重他们的时间，15分钟以内说清楚

② 业务负责人（总监/经理）
   关心：团队效率、实施可行性、KPI达成
   沟通：战术+战略结合、展示理解他们的痛点
   话术："刘总，这个方案上线后帮您的团队
         每周节省XX小时，XX公司同岗位用了效果很好"

③ 技术评估者（IT/安全/架构）
   关心：集成兼容、数据安全、维护成本
   沟通：技术先行、提供文档/测试环境
   话术："陈工，这是我们的API文档和安全合规报告，
         可以安排技术团队对接看兼容性"

④ 使用者（基层员工）
   关心：好不好用、会不会增加工作量、培训
   沟通：简单直接、承诺培训和支持
   话术："不用担心，我们有专人培训，
         上手只需要2小时，有问题随时找我们"

多线程接触操作步骤：
├─ Step1：画客户组织架构图（谁拍板/谁评估/谁使用/谁反对）
├─ Step2：通过Champion引荐其他关键人
│   "王总，为了方案更贴合你们需求，
│   能不能介绍你们IT负责人和技术团队聊聊？"
├─ Step3：对不同角色用不同的沟通策略（见上）
├─ Step4：定期同步各方进展（信息对齐）
└─ Step5：组织多方会议（让支持者在会上帮你说话）

⚠️ 多线程的禁忌：
├─ 不要绕过你的Champion去找他老板（会被视为背叛）
├─ 不要对不同人说不一致的信息（会被发现）
└─ 先告诉Champion你要接触其他人，取得同意
```

## 13.2 竞品Battle Card（战斗卡）

```
遇到竞品不要慌，提前准备好战斗卡。

Battle Card标准模板：

┌──────────────────────────────────────┐
│  竞品XX 战斗卡                        │
├──────────────────────────────────────┤
│ 一句话定位：                          │
│  "竞品XX适合[XX场景]，我们适合[XX场景]" │
├──────────────────────────────────────┤
│ 我们的优势（客户视角）：                │
│  ① 功能：我们XX > 竞品XX              │
│  ② 服务：我们XX > 竞品XX              │
│  ③ 案例：我们有XX个同行业案例          │
├──────────────────────────────────────┤
│ 竞品的优势（诚实面对）：                │
│  ① 价格比我们便宜XX%                  │
│  ② XX功能比我们多                     │
│  → 应对：便宜但服务跟不上/功能多但用不上 │
├──────────────────────────────────────┤
│ 竞品的弱点（枪火）：                    │
│  ① 客户投诉率高                       │
│  ② 实施周期长                         │
│  ③ 安全漏洞历史                       │
│  → 用提问引导客户发现："您了解他们的     │
│    售后响应速度吗？"                   │
├──────────────────────────────────────┤
│ 常见竞品话术 vs 我们的话术：            │
│  竞品说"我们更便宜"                    │
│  → "便宜要看总成本（TCO），             │
│    我们3年总成本更低"                  │
│  竞品说"我们功能更多"                  │
│  → "功能多不等于用得上，                │
│    我们的功能都为客户解决问题"          │
├──────────────────────────────────────┤
│ 陷阱问题（Landmine）：                 │
│  问客户："你们对供应商的数据安全         │
│   有要求吗？竞品XX去年有过数据泄露"     │
│  问客户："你们的实施时间要求多紧？       │
│   竞品XX平均实施要6个月"               │
└──────────────────────────────────────┘

制作Battle Card的数据来源：
├─ 竞品官网/产品文档（功能对比）
├─ 竞品客户评价（App Store/知乎/行业论坛）
├─ 竞品招聘信息（看他们在招什么人=在做什么）
├─ 你的流失客户访谈（为什么选了竞品）
├─ 你的赢回客户访谈（为什么从竞品换回你）
└─ 行业报告/ analyst报告

⚠️ 用Battle Card的原则：
├─ 不要主动攻击竞品（显得心虚）
├─ 用提问引导客户自己发现竞品弱点
├─ 承认竞品有优势，但强调你的差异化
└─ 始终回到客户价值，不陷入功能对比
```

## 13.4 Discovery Call（需求探查电话）

```
第一次正式跟客户的深度沟通电话（通常30-45分钟）。

目标：
├─ 不是卖产品！是理解客户
├─ 判断值不值得花时间跟进（BANT/MEDDIC）
├─ 找到痛点和影响（痛点不够大就不会买）
└─ 约下一次面谈/演示

Discovery Call 5段式结构：

第一段：破冰+设定agenda（5分钟）
"王总，今天主要想了解你们目前[业务]的情况，
不急着聊我们的方案，先听听您的需求和挑战，
看看能不能帮上忙。大概30分钟，您看OK吗？"

第二段：现状探查（10分钟）——SPIN的S+P
"目前你们[流程]是怎么做的？"
"用了什么系统/工具？"
"这个环节花多少时间/人力？"
"有没有遇到什么困难/不满意的地方？"
→ 目标：找到现状中的"裂缝"

第三段：痛点深挖（10分钟）——SPIN的I
"您说的XX问题，多久了？"
"这个问题对[业务/效率/成本]的影响有多大？"
"一年下来因为这个损失大概多少？"
"如果不解决，会怎样？"
→ 目标：把"小问题"放大成"大问题"

第四段：理想方案探查（5分钟）——SPIN的N
"如果有个方案能解决[痛点]，您会感兴趣吗？"
"理想情况下，您希望达到什么效果？"
"您会怎么评估一个方案好不好？"
→ 目标：让客户自己说出"如果有方案就好了"

第五段：收尾+下一步（5分钟）
"王总，今天聊的很有收获。我总结一下您的需求：
1. ___ 2. ___ 3. ___
您看对不对？"
"根据这些，我给您做一个定制方案，
下周X发您，然后安排一个演示？"

⚠️ Discovery Call黄金法则：
├─ 70%时间客户说，30%你说
├─ 不卖产品！只问问题
├─ 每个回答都追问"Why"（挖到根）
├─ 记录每个关键信息（后面做方案要用）
├─ 不要怕沉默（客户在思考=好事）
└─ 不要跳过现状直接卖方案
```

## 13.5 处理内部反对者（Blocker）

```
客户内部有人在帮竞品说话/阻止你成交。

识别Blocker的信号：
├─ 在会议上不断质疑你的方案
├─ 反复强调竞品的好处
├─ 设置不合理的门槛/要求
├─ 拖延审批/回复
├─ 在背后跟决策者说你的坏话
└─ 要求"公平对比"但实际上偏向竞品

Blocker的3种类型及应对：

类型1：利益受损型（换了供应商他的权力/利益受影响）
→ 他怕换了系统他的工作变多/权力变小
应对：
├─ 不要跟他对抗（你赢不了）
├─ 找到他的顾虑，帮他解决
│   "刘工，新系统不会增加您的工作量，
│   反而帮您减少XX%的重复劳动"
├─ 把他变成受益者而不是受害者
└─ 如果实在搞不定，绕过他找更高层

类型2：偏好竞品型（他以前用过竞品/跟竞品关系好）
→ 他真心觉得竞品更好
应对：
├─ 不要说竞品坏话（他会更抵触）
├─ 用数据/案例证明你更适合
├─ 找到他关注的具体点，针对性回应
│   "您说的XX确实重要，我们在这个方面其实做得更好，
│   这是数据对比您看看"
└─ 如果他是技术评估者，找你的技术团队跟他深度对接

类型3：怕变化型（他害怕任何改变）
→ "现在用得好好的，为什么要换？"
应对：
├─ 用渐进式方案降低风险感
│   "不用全部换，先在一个部门/产线试试"
├─ 提供过度期支持（双系统并行）
├─ 找到他的Champion帮他背书
└─ 强调不改变的风险（比改变的风险更大）

⚠️ 处理Blocker原则：
├─ 不要在客户面前跟他吵架
├─ 不要去决策者面前告状（显得不专业）
├─ 私下了解他的真实顾虑
├─ 把反对者变成中立者就赢了（不一定要变支持者）
└─ 最狠的一招：让决策者直接拍板（绕过Blocker）
```

## 13.6 客户采购卡在法务/合同审核

```
销售最痛苦的阶段：deal谈好了，卡在法务/采购流程。

常见卡点：
├─ 法务要改合同条款（无限来回）
├─ 采购要走比价/招投标流程
├─ 财务要审核预算
├─ 安全/合规要审查供应商资质
└─ 领导审批链太长

加速法务审核：

① 提前准备
├─ 准备好标准合同模板（法务最喜欢标准条款）
├─ 准备好公司资质文件包（营业执照/ISO/安全合规）
├─ 提前了解对方法务的常见要求
└─ 预审：让你的法务先审一遍你的合同

② 找对人
├─ "王总，你们法务审核一般走什么流程？"
├─ "能不能给我法务的联系方式？我直接跟他们沟通效率更高"
├─ 跟法务建立关系：不是对抗，是配合
└─ 给法务提供他们需要的东西（不要让他们来追你）

③ 分割处理
├─ 把争议条款和非争议条款分开
├─ 非争议条款快速通过
├─ 争议条款一条一条谈
├─ 每条争议都给2-3个选项（不是"行/不行"）
└─ 实在谈不拢的条款，找替代方案

④ 升级机制
├─ 如果法务拖了>2周 → 让你的Champion去催
├─ 如果Champion催不动 → 找更高层
│   "王总，方案/价格都谈好了，现在卡在法务审核，
│   能不能帮忙催一下？避免影响上线时间"
└─ 用时间压力：法务审核延误 → 上线延误 → 客户的损失

⑤ 时间线管理
├─ 签约前就问清采购流程（"你们走法务要多久？"）
├─ 倒排时间表：要X月X日上线 → 法务必须X月X日完成
├─ 给采购/法务一个"截止日期"（不是无期限的）
└─ 每周跟进进度，不要等客户主动告诉你
```

## 13.7 大客户精耕（ABM策略）

```
ABM（Account-Based Marketing）= 把一个公司当一个市场来经营。

适合：客单价>10万/年，目标客户<200家的B2B。

ABM 3步法：

Step 1：选目标（Target）
├─ 列出你的TOP 50目标客户名单
├─ 按价值排序：A级（>50万/年）B级（10-50万）C级（潜力）
├─ 每个客户做一个1页纸的"客户档案"
│   （行业/规模/痛点/决策链/竞品现状/切入点）
└─ 不要追100个客户，集中精力打10个

Step 2：渗透（Penetrate）
├─ 多渠道触达同一个客户
│   ├─ 邮件：定期发行业洞察/案例（不是广告）
│   ├─ 社交：LinkedIn/脉脉连接多个决策者
│   ├─ 线下：行业活动/展会制造见面机会
│   ├─ 内容：为目标客户定制内容（"制造业数字化转型报告"）
│   └─ 引荐：找共同认识的人引荐
├─ 目标：在客户内部建立3-5个接触点（多线程）
└─ 每次接触都提供价值，不只是推销

Step 3：转化（Convert）
├─ 找到切入点（客户最近有什么变化/痛点/需求？）
├─ 安排深度会议（不是产品演示，是业务讨论）
├─ 做高度定制化的方案（不是通用方案）
├─ 让你的高管跟客户的高管对话（C对C）
└─ 从小开始：先做一个POC/试点/小项目

ABM vs 普通销售的区别：
┌──────────┬─────────────┬──────────────┐
│          │ 普通销售      │ ABM          │
├──────────┼─────────────┼──────────────┤
│ 目标     │ 越多客户越好   │ 集中打少数    │
│ 方案     │ 标准化        │ 高度定制      │
│ 接触     │ 1对1         │ 1对多/多对多  │
│ 周期     │ 快进快出      │ 长期渗透      │
│ 投入     │ 低            │ 高（值得）    │
│ 回报     │ 低客单价      │ 高客单价      │
└──────────┴─────────────┴──────────────┘
```

## 13.8 渠道商/代理商管理

```
不是所有客户都是你自己直接卖的。渠道商帮你卖更高效。

渠道商类型：
├─ 代理商：帮你卖产品，赚差价/佣金
├─ 集成商：把你的产品打包到他的方案里卖
├─ 分销商：大量采购再分销
├─ 推荐伙伴：推荐客户给你，赚推荐费
└─ 技术伙伴：技术互补，联合方案

渠道商管理5要素：

① 选对渠道商
├─ 看他的客户群跟你的目标客户重合度高不高
├─ 看他的销售能力/技术能力够不够
├─ 看他同时卖竞品吗？（专一 vs 多品牌）
├─ 看他的市场口碑/信誉
└─ 先小范围试点，再深度合作

② 利益分配明确
├─ 佣金/返利结构清晰（X% or 阶梯式）
├─ 价格体系明确（不能让渠道商自己乱降价）
├─ 客户归属规则（谁开发的算谁的）
├─ 保护机制（你直接收到该客户的询盘也要算给渠道商）
└─ 激励：超额完成有额外奖励

③ 赋能（Enablement）
├─ 产品培训：定期给渠道商做产品培训
├─ 销售物料：提供方案/PPT/案例/Battle Card
├─ 技术支持：有专属技术对接人
├─ 市场支持：联合营销/客户活动费用分摊
├─ CRM系统：让渠道商在系统里报备客户/跟进
└─ 认证体系：渠道商认证等级（铜/银/金/铂金）

④ 过程管理
├─ 每月1对1 review（上月业绩+本月计划+问题）
├─ 每季度渠道商大会（经验分享+新品发布）
├─ 客户报备机制（防止渠道商之间撞单）
├─ 价格管控（发现乱报价立刻处理）
└─ 数据透明（双方都能看到Pipeline）

⑤ 防止渠道冲突
├─ 划分区域/行业（各做各的，不撞单）
├─ 客户报备制度（先报先得）
├─ 你自己直销团队 vs 渠道商的规则要清晰
├─ 出现冲突时：制度优先，不要偏袒
└─ 定期清理不活跃/违规渠道商
```

## 13.9 应对"自满客户"（不需要改变）

```
最难卖的客户不是说"太贵了"的客户，而是说"我们现在挺好的"的客户。

客户为什么说"不需要"：
├─ 真没痛点（很少见）
├─ 有痛点但不知道（认知盲区）
├─ 有痛点但习惯了（麻木了）
├─ 知道有痛点但怕改变（风险厌恶）
└─ 上级没要求（没有外部压力）

3种破局策略：

策略1：Challenger式——制造认知冲击
"王总，你们现在的做法在行业里算效率比较低的，
同行的XX公司用了新方案后效率提升了XX%，
您有没有了解过他们怎么做的？"
→ 不是直接说"你不行"，而是用行业对标让客户自己发现差距

策略2：算账式——量化不改变的代价
"王总，我帮您算了一笔账：
按你们现在的次品率8%，一年损失约XX万，
如果降到3%，一年省XX万，
3年就是XX万——这笔钱一直在流失。"
→ 把"不改变的隐性成本"量化出来

策略3：小步快跑式——降低改变的风险
"王总，不用全面换。
先在一个产线/部门试点30天，
如果效果好再推广，如果不好就回到老办法，
您没有任何风险。"
→ 把"改变"的门槛降到最低

⚠️ 绝对不要做的：
├─ 不要说"你现在的做法是错的"（客户会抵触）
├─ 不要讲产品功能（客户没需求时不想听）
├─ 不要放弃（自满≠不买，只是还没意识到）
└─ 不要用"限时优惠"制造紧迫感（假紧迫感客户能看出来）

有效做法：
├─ 分享同行业案例（"XX公司之前也这么觉得，后来..."）
├─ 邀请参加行业活动/客户交流（让别人影响他）
├─ 持续提供价值内容（行业报告/数据对标）
├─ 等待触发事件（换领导/新政策/竞品动作）
└─ 保持关系，时机到了他就是你的
```
