# Phase 17：销售心理学

> 客户的购买决策90%由情绪驱动，再用逻辑来合理化。懂心理学，不是操纵客户，是理解客户。

## 什么时候看这个文件

- 客户明明有需求但就是不下单
- 想理解客户"嘴上说不要，行为却在买"的原因
- 想用心理学技巧提升转化率（不靠降价）
- 想知道为什么有些话术特别有效

## 一、7大购买心理触发器

### 1.1 互惠原则（给与取）

```
核心逻辑：人天生觉得"欠了别人的就要还"。

销售应用：
├─ 先给客户价值，再请求回报
├─ 免费咨询→客户觉得"欠了一个人情"→ 更容易成交
├─ 免费试用→客户用了你的产品→ 不好意思白用→ 付费
├─ 先帮客户解决一个小问题→ 建立亏欠感→ 推产品时阻力更小
├─ 送样品/试用装→ 客户用了满意→ 感到应该回报
└─ 提供免费报告/诊断→ 客户得到价值→ 更愿意继续聊

⚠️ 注意：互惠不是"道德绑架"。你给的必须是真有价值的东西，
   不是垃圾资料/无效咨询。客户能分辨真心和套路。
```

### 1.2 稀缺性（越少越想要）

```
核心逻辑：人害怕失去>喜欢得到。"再不买就没了"比"买了能赚"更有效。

销售应用：

数量稀缺：
├─ "只剩最后3个名额"
├─ "这批货只有200件，卖完等下一批要等2个月"
├─ "前100名下单额外送XX"
└— ⚠️ 必须是真的稀缺！假的被拆穿=信任崩塌

时间稀缺：
├─ "这个价格只限今天"
├─ "早鸟价周五截止"
├─ "活动倒计时最后2小时"
└─ ⚠️ 不要一直"最后一天"（客户不傻，看到每次都是最后一天就免疫了）

身份稀缺：
├─ "这个方案只开放给VIP客户"
├─ "需要审核资质才能购买"
├─ "邀请制，只有老客户推荐才能加入"
└─ 效果：让产品更"高级"，客户觉得"能买到是特权"
```

### 1.3 社会认同（从众心理）

```
核心逻辑：不确定的时候，人会看别人怎么做。

销售应用：

销量数据：
├─ "已有10,000+用户选择"
├─ "行业TOP3的品牌都在用"
├─ "本月已售出500+套"
└─ 数字越大越好，但必须真实

客户评价/案例：
├─ 展示真实客户好评截图（不是P的）
├─ "XX公司用了我们的方案后，效率提升了40%"
├─ KOL/KOC推荐
└— 最好是与目标客户相似的案例（"跟你同行业的XX公司"）

实时社会证明：
├─ "刚才又有3位客户下单了"
├─ 直播间实时显示下单数量
├─ "您浏览的这个产品，今天有27人加入购物车"
└─ 效果：营造"大家都在买"的氛围

群效应：
├─ 社群里有人晒单→ 其他人跟着买
├─ "群友都在用XX，反馈很好"
├─ 朋友圈看到朋友在用→ 信任度更高
└— 人更相信"跟我一样的人"的选择，而不是广告
```

### 1.4 权威效应（听专家的）

```
核心逻辑：人倾向于服从权威/信任专家。

销售应用：

专业权威：
├─ 展示资质证书/行业认证
├─ "10年行业经验/服务过500+客户"
├─ 发表专业内容（文章/视频/演讲）
├─ 被行业媒体报道/引用
└─ 出书/开课/做行业分享

第三方背书：
├─ 行业奖项/排名
├─ 权威机构认证（ISO/FDA/等）
├─ 知名客户logo墙
├─ 专家/学者推荐
├─ 媒体报道/采访
└─ 第三方评测/检测报告

穿着/形象权威：
├─ 专业着装（不是穿名牌，是穿对场合）
├─ 专业工具（高端电脑/精致PPT/数据报告）
├─ 专业语言（准确用术语，但不炫技）
└─ ⚠️ 权威不是居高临下，是让客户觉得"这个人靠谱"
```

### 1.5 喜好原则（跟喜欢的人买）

```
核心逻辑：人更愿意从自己喜欢的人那里购买。

怎么让客户喜欢你：

相似性：
├─ 找到共同点（老乡/校友/爱好/经历）
├─ "您也是湖南的？我也是！"
├─ 模仿客户的沟通风格（文字/语音/正式/随意）
└─ 人喜欢跟自己像的人

赞美：
├─ 真诚赞美（不是拍马屁）
├─ 赞美具体的事，不是泛泛的夸
├─ "您刚才问的那个问题特别专业"
├─ "您的方案考虑得很周全"
└─ ⚠️ 假赞美比不赞美更糟

熟悉度：
├─ 多接触（朋友圈互动/多次见面/定期联系）
├─ 曝光效应：见得越多越有好感
├─ 但不要骚扰！每次接触要有价值
└─ 社交媒体持续展示真实的你

关联：
├─ 跟客户喜欢的事物产生关联
├─ "我也喜欢打高尔夫"
├─ 客户喜欢什么→你也有兴趣→关系拉近
└─ 不要假装！不懂的领域可以说"您教教我"
```

### 1.6 损失厌恶（怕失去>想得到）

```
核心逻辑：失去100元的痛苦 > 得到100元的快乐（2-2.5倍）。

销售应用：

框架效应（怎么说比说什么重要）：
├─ ❌ "买了能省5万"（收益框架）
├─ ✅ "不买每年损失5万"（损失框架）
├─ ❌ "用了能提升30%效率"（收益框架）
├─ ✅ "不用的话每年浪费XX小时/XX成本"（损失框架）
└— 同一件事，用"损失"来表达比用"收益"更有冲击力

限时/限量的本质：
├─ "今天不买=失去这个优惠"
├─ "现在不续约=失去老客户价格"
├─ "不抢占名额=竞品抢占你的市场"
└— 本质上都是在触发损失厌恶

试用期到期转化：
├─ "您的试用还有3天到期"
├─ "到期后您的数据将被清除"
├─ "现在续费可以保留所有数据"
└— 强调"不行动会失去什么"比"行动能得到什么"更有效

⚠️ 红线：不要制造虚假的恐惧（"不买我们的产品你的公司就会倒闭"）
   这种极端的恐吓营销会破坏信任
```

### 1.7 承诺一致性（说了就会做）

```
核心逻辑：人倾向于保持言行一致。一旦做出了承诺（哪怕很小的），
        后续行为会跟之前的承诺保持一致。

销售应用：

阶梯式承诺（从小到大）：
├─ Step 1：让客户做一个很小的承诺
│   "方便花2分钟看看我们的方案吗？" → "好"
├─ Step 2：稍微大一点
│   "看完觉得怎么样？有兴趣了解一下吗？" → "有"
├─ Step 3：再大一点
│   "那我们约个时间做个演示？" → "好"
├─ Step 4：更大
│   "演示完了，做个试用？" → "好"
├─ Step 5：成交
│   "试用效果不错吧？要不要正式签？" → "好"
└— 每一步客户都说了"好"，下一步再拒绝就很难

书面承诺：
├─ 让客户把意向写下来（邮件确认/签字/微信群确认）
├─ "您确认一下，我周一发方案给您" → 客户回复"好"
├─ 有了书面确认，客户反悔的概率大大降低
└— 口头承诺<书面承诺<签字承诺

公开承诺：
├─ 在多人场合做出的承诺更难反悔
├─ 在领导面前答应的事→ 更会去做
├─ 在群里说"下周给方案"→ 群里的人都看到了→ 更难反悔
└— 适度使用，不要刻意让客户在公开场合下不了台
```

## 二、决策心理学

### 2.1 系统1 vs 系统2（快思考vs慢思考）

```
人有两个决策系统：

系统1（快思考）：
├─ 直觉/情绪/自动反应
├─ 毫秒级做出判断
├─ 占日常决策的95%+
├─ 容易被情绪、外观、第一印象影响
└─ 低客单价/冲动消费/日常购买 主要由系统1驱动

系统2（慢思考）：
├─ 理性/逻辑/深度分析
├─ 需要时间和精力
├─ 占日常决策的5%
├─ 会比较、计算、权衡
└─ 高客单价/B2B采购/专业决策 主要由系统2驱动

销售应用：

客单价<500的产品（系统1主导）：
├─ 视觉冲击>详细参数
├─ 情绪触发>理性分析
├─ 限时/稀缺/从众特别有效
├─ 简化决策："买就对了"
└─ 直播间/短视频/种草内容最有效

客单价500-10000的产品（双系统）：
├─ 情绪吸引注意 + 理性支撑决策
├─ 先让TA"想要"（系统1），再给TA"理由"（系统2）
├─ 内容种草+对比测评+客户评价
└─ 朋友圈+小红书+社群转化

客单价>10000的产品（系统2主导）：
├─ 数据/案例/ROI>情绪
├─ 决策周期长（1-3个月+）
├─ 需要多轮沟通+方案+演示+试用
├─ 提供决策工具（对比表/ROI计算器/案例分析）
└─ 1对1深度销售为主
```

### 2.2 选择悖论（选择越多越难决定）

```
核心逻辑：选项太多反而导致决策瘫痪，甚至放弃不买。

实验：
├─ 超市摆24种果酱 → 只有3%的人购买
├─ 超市摆6种果酱 → 30%的人购买
└— 选项少了10倍，转化率高了10倍

销售应用：

给客户的选择不要超过3个：
├─ ✅ 基础版/标准版/旗舰版（3选1）
├─ ✅ 方案A/方案B（2选1）
├─ ❌ 给客户看10个套餐/8种配色/15个模块
└— 选择超过3个，客户会"回去考虑考虑"

默认选项的力量：
├─ 给一个"推荐选项"或"默认选项"
├─ "大多数客户选标准版"（社会认同+减少决策负担）
├─ "如果您不确定，我建议从标准版开始"
└─ 人倾向于选默认选项（减少决策成本）

减少决策步骤：
├─ 能选1个就不选2个（别让客户填10个选项）
├─ 能一键就不两键（减少操作步骤）
├─ 能自动就不手动（帮客户做配置）
└─ 每多一步决策，流失率增加10-20%
```

### 2.3 锚定效应在销售中的实战

```
锚定效应：第一个看到的数字会严重影响后续判断。

经典实验：
一张钞票值多少钱？
├─ 先写下你社保后4位 → 再估这张钞票值
├─ 社保后4位大的人（如9999）→ 估值偏高
├─ 社保后4位小的人（如0001）→ 估值偏低
└— 毫无关联的数字都能影响判断，何况相关的

销售中的锚定：

报价中的锚定：
├─ 先报高价方案→ 再报目标价→ 客户觉得目标价"划算"
├─ 先说市场均价→ 再说你的价格→ 客户有参照物
├─ 先说不解决方案的损失→ 再说方案的价格→ "花小钱省大钱"
└— 报价顺序：高→低（先锚高，再落地）

展示中的锚定：
├─ 先展示高端产品→ 客户"锚"在高价位
├─ 再展示标准产品→ 客户觉得"便宜"
├─ 先展示大包装→ 再看小包装→ 小包装"不贵"
└— 橱窗里放最贵的（不是为了卖，是为了让其他显得便宜）

谈判中的锚定：
├─ 你先开价（锚定对你有利）
├─ 开价比目标价高20-30%（留让步空间）
├─ 如果对方先开价→ 你要"重锚"（忽略TA的数字，说你的数字）
└— "那个价格我们不考虑，我们的方案通常在XX-XX之间"
```

## 三、信任建立心理学

### 3.1 信任公式

```
信任 = (专业能力 + 可靠性 + 亲近感) / 自利动机

专业能力（你懂不懂）：
├─ 展示专业知识/经验/案例
├─ 说专业的话（用对术语）
├─ 提供专业的内容（报告/分析/建议）
└— 但不要炫技（让客户觉得"TA比我强太多"反而有距离感）

可靠性（你说到做到吗）：
├─ 答应的事100%做到（按时/按质/按量）
├─ 不夸大（说能做到8分，做出来10分=惊喜）
├─ 有问题提前告知（不要等到最后一刻才说）
└— 可靠性需要时间积累，但一次失信就会大幅扣分

亲近感（我觉得你亲切吗）：
├─ 找共同点（老乡/校友/爱好/经历）
├─ 展示真实的自己（不是完美人设）
├─ 关心客户本人（不只是关心TA的钱包）
└— 适度展示弱点/失败经历（让人觉得真实可信）

自利动机（你是不是只为了卖东西）：
├─ 分母！自利动机越强，信任越低
├─ 如果客户觉得"你就是想赚我钱"→ 信任崩塌
├─ 降低自利感知：
│   ├─ 有时候推荐客户不买（"你现在不需要，先别买"）
│   ├─ 说竞品的好话（"竞品在XX方面确实做得不错"）
│   ├─ 分享不卖东西的价值（免费干货/建议）
│   └─ 以客户利益为先（"如果我是您，我会选XX方案"）
└— 最有效的信任建立：让客户觉得你是"帮TA的人"，不是"赚TA的人"
```

### 3.2 信任建立的节奏

```
信任不是一步建立的，是分层递进：

第1层：专业信任（1-3天建立）
├─ "这个人懂行" → 展示专业知识
├─ 通过内容/案例/回答问题建立
└— 门槛最低，但也最容易被替代

第2层：能力信任（1-2周建立）
├─ "这个人能帮到我" → 展示解决问题的能力
├─ 通过免费咨询/试用/小项目建立
└— 客户开始觉得"TA的方案有价值"

第3层：人品信任（1-3个月建立）
├─ "这个人靠谱" → 说到做到/不坑人
├─ 通过持续交付/诚实沟通/主动维护建立
└— 客户开始愿意长期合作

第4层：关系信任（3个月+建立）
├─ "这个人我信得过" → 超越商业关系
├─ 通过关心客户本人/帮忙解决问题/长期陪伴建立
└— 最高信任：客户主动帮你转介绍

⚠️ 不要跳层！
├─ 第一次见面就谈"我们交个朋友"（跳到第4层）→ 客户觉得假
├─ 没展示专业能力就推高价方案（跳过第1层）→ 客户不信任
└— 每一层都需要前一层做基础
```
