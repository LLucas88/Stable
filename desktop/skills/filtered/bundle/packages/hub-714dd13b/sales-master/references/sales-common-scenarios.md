# 销售实战高频场景手册

> 这份手册覆盖了销售日常工作中容易遇到、但主流程没有展开的18个高频实操场景。按客户旅程排列，遇到问题直接查对应章节。

---

## 一、获客前

### 1.1 SEM/付费投流获客

> 什么时候看：想通过百度SEM/抖音信息流/朋友圈广告主动获客，不知道怎么搭建。

**投流获客4步法**：

```
第1步：确定投放策略
├─ 百度SEM → 适合B2B/高客单价（搜索意图明确，转化率高）
├─ 抖音/快手信息流 → 适合B2C/低客单价/冲动消费
├─ 朋友圈广告 → 适合本地生活/To B精准定向
├─ 小红书投流 → 适合女性消费品/品牌种草
└─ 领英广告 → 适合B2B跨国/高管触达

第2步：设计转化链路
曝光 → 点击 → 落地页 → 留资(表单/加微信) → 销售跟进
⚠️ 落地页是关键！90%的投流效果差是落地页不行
落地页要素：标题(痛点切入) + 痛点描述 + 解决方案 + 案例/数据 + 表单(越短越好，只要手机号)

第3步：算清楚获客成本
CAC(获客成本) = 投放花费 ÷ 获得的线索数
有效CAC = 投放花费 ÷ 成交客户数（真正花钱的数字）
例：花5000元 → 50个线索 → 5个成交 → CAC=100元/线索，有效CAC=1000元/成交

第4步：持续优化
├─ 点击率低 → 换广告素材/标题
├─ 留资率低 → 优化落地页/减少表单字段
├─ 线索质量差 → 调整定向人群
└─ 跟进转化低 → 不是投流问题，是销售话术问题
```

**投流vs内容营销选择**：
- 有预算+要快 → 投流（当天见效）
- 没预算+能等 → 内容营销（1-3个月见效，但长期免费）
- 最佳策略 → 投流快速验证 + 内容长期积累

### 1.2 新行业冷启动策略

> 什么时候看：刚换了一个新行业/新产品/新公司，完全没有客户资源和行业经验。

**冷启动30天计划**：

```
第1周：快速学习（不要急着卖）
├─ 找3-5个行业老手聊天（请吃饭/请教）
├─ 研究TOP3竞品的产品、定价、获客方式
├─ 加入3-5个行业社群/论坛/协会
├─ 参加1个行业活动/展会（不卖货，只认识人）
└─ 产出：行业认知笔记 + 目标客户清单

第2周：搭建基础
├─ 完善你的微信形象（头像/签名/朋友圈体现专业）
├─ 准备3个核心物料：产品介绍/案例/报价单
├─ 写3篇行业认知发朋友圈（建立专业人设）
├─ 从现有资源中筛出潜在客户（朋友/前同事/转介绍）
└─ 产出：物料清单 + 10-20个种子客户

第3周：开始触达
├─ 每天触达10-15个潜在客户（电话/微信/社群）
├─ 目标不是成交，是约到3-5个面谈/深度沟通
├─ 每次沟通后复盘：客户关心什么？常见问题？
├─ 收集竞品信息：客户现在用什么？满意/不满意？
└─ 产出：5个意向客户 + 客户痛点清单

第4周：加速推进
├─ 对意向客户做方案/报价
├─ 争取1-2个签约（哪怕低价/小单也先跑通流程）
├─ 用首批成交客户做案例（视频/文字）
├─ 请满意客户转介绍
└─ 产出：1-2个成交 + 2-3个pipeline客户 + 1个成功案例
```

**冷启动心态**：
- 前3个月不要追求高业绩，追求"跑通模式"
- 先做小单积累案例和信心，再追大单
- "前100个客户最难"——过了这个坎就顺了

## 二、首次接触

### 2.1 展会/活动后跟进

> 什么时候看：参加完展会/活动，收了一堆名片和微信，不知道怎么跟进。

**展会跟进4步法**：

```
展会当天（黄金24小时）：
├─ 当晚或次日早上发第一条消息
├─ 公式：[相遇场景回忆] + [价值传递] + [轻量互动]
├─ 话术："王总，昨天在XX展会上聊得很开心！您提到的[XX问题]，
│   我整理了一份资料给您参考。方便的话约个时间详细聊聊？"
└─ ⚠️ 不要群发！每条消息提到你们聊了什么（证明你记得ta）

第2-3天（筛选分级）：
├─ 按热情程度分级：
│   A级 = 主动留了需求/加了微信聊了几句 → 48小时内电话跟进
│   B级 = 拿了名片/扫了码但没深聊 → 发价值内容+约沟通
│   C级 = 只扫了码/留了联系方式 → 朋友圈培育，月度触达
└─ A级客户优先！展会热度衰减极快（3天不跟基本凉了）

第7天（价值跟进）：
├─ 给A级/B级客户发针对性的内容
├─ 不是发产品资料！是发他们关心的问题的解决方案
├─ 话术："上次您提到[XX痛点]，我专门研究了一下，发现[XX方案]可以解决..."
└─ 附一个简短案例/数据

第14天（收网）：
├─ 对A级客户：直接约线下见面/正式沟通
├─ 对B级客户：试探意向"最近在考虑[XX]方面的方案吗？"
├─ 对C级客户：降频到月度触达
└─ 统计展会ROI：花了多少 → 获得多少线索 → 预计成交多少
```

### 2.2 Inbound咨询接洽流程

> 什么时候看：客户主动来咨询（官网/广告/朋友推荐），怎么接才能转化率最高。

**Inbound接洽5步法**：

```
第1步：快速响应（5分钟内回复，转化率下降80%超过30分钟）
├─ 微信/电话第一时间接
├─ 开场白公式：感谢关注 + 快速了解需求 + 安排深度沟通
├─ "您好！感谢关注XX。方便简单说一下您主要想了解哪方面吗？"
└─ ⚠️ 不要一上来就甩产品介绍和报价！

第2步：需求快速诊断（3个问题锁定）
├─ "您目前是做什么行业的？团队多大？"
├─ "您最想解决的问题是什么？"
├─ "您预期什么时候开始用？预算大概什么范围？"
└─ 根据回答判断客户级别（A级紧急/B级培育/C级随手问问）

第3步：价值展示（不是产品功能介绍）
├─ 根据客户需求，只讲跟ta痛点相关的功能
├─ 用案例说话："跟您同行业的XX公司，用了之后效果是..."
├─ 算账："按您的情况，一年能省XX万/提升XX%效率"
└─ ⚠️ 不要把所有功能都讲一遍！客户只关心"你能帮我解决我的问题吗"

第4步：锁定下一步（不要让客户"考虑一下"就结束）
├─ "根据您的需求，我给您出一份定制方案，X天给您"
├─ "您看本周X还是下周X方便，我给您详细演示一下？"
├─ "我先加您微信，把相关资料发您，有什么问题随时问我"
└─ 必须锁定一个具体的时间和动作

第5步：Inbound vs Outbound的本质区别
├─ Inbound客户有主动需求 → 转化率高3-5倍 → 但决策也快，不跟紧就跑了
├─ Inbound客户同时咨询多家 → 你不是唯一选项 → 必须在第一次接触就建立差异
├─ Inbound客户更急 → 不要慢慢培育，加速推进
└─ Inbound是花钱/花精力换来的 → 每条线索都是钱，不要浪费！
```

### 2.3 竞品客户转化策略

> 什么时候看：想撬动竞争对手的客户。

**竞品客户转化5步法**：

```
第1步：信息收集（不要直接说"换我们吧"）
├─ 了解客户现在用哪家竞品？用了多久？
├─ 客户最满意竞品什么？最不满意什么？
├─ 竞品合同什么时候到期？（这是最佳切入时机）
└─ 问法："您现在用的是XX方案？感觉怎么样？有没有觉得不够好的地方？"

第2步：找薄弱环节（不是攻击竞品）
├─ 永远不说竞品坏话！"XX也不错，但根据您的情况..."
├─ 找到竞品的薄弱点：服务差？功能缺？响应慢？价格高？不支持定制？
├─ 你的差异化正好打在这个薄弱点上
└─ "我理解您现在用XX用得挺好，不过很多客户跟我们反馈，他们在用XX的时候遇到[XX问题]，我们刚好在这块做得比较深..."

第3步：等待时机（合同到期/服务出问题/需求变化）
├─ 最佳时机：竞品合同到期前60-90天
├─ 次佳时机：客户对竞品服务不满/出了事故
├─ 保持联系但不要硬推 → 让客户有需求时第一个想到你
└─ "没关系，您先用着XX，有任何问题随时找我，我很乐意帮忙"

第4步：试用/对比（降低切换风险）
├─ 提供免费试用/POC验证
├─ 做一份客观的对比表（不要刻意贬低竞品，突出你的优势）
├─ "您不用马上换，先试用一下对比对比，自己感受"
└─ 找到竞品做不到而你能做到的"杀手锏功能"

第5步：降低迁移成本（客户最怕换系统的麻烦）
├─ 提供数据迁移支持（免费帮忙导入）
├─ 提供过渡期支持（双系统并行一段时间）
├─ 提供培训（帮团队快速上手）
├─ 提供优惠（切换补贴/首年折扣）
└─ "从XX换过来，所有数据和配置我们帮您迁移，您只需要用就行"
```

## 三、跟进培育

### 3.1 "只聊不买"型客户处理

> 什么时候看：客户每次都聊得很开心，但就是不谈正事、不下单。

**判断+处理**：

```
先判断是哪种"只聊不买"：

类型A：真没需求/没预算 → 只是不好意思拒绝你
→ 处理：直接问"您目前对XX有具体需求吗？还是先了解一下？"
→ 如果真的没有 → 降频到月度触达，不要浪费时间

类型B：有需求但不急 → 觉得现在用不上/不痛
→ 处理：放大痛点！算拖延成本
→ "您现在每月在XX上花多少时间/成本？如果不解决，一年损失多少？"

类型C：在比价/等你主动降价 → 吊着你等折扣
→ 处理：设定边界
→ "这个报价是有效期的，月底恢复原价" / "现在签约有XX优惠"

类型D：决策者不是ta → 聊天的人不是拍板的人
→ 处理：找到真正的决策者
→ "除了您之外，这个决策还有谁参与？我能直接跟ta沟通吗？"

类型E：习惯性拖延 → 天生做决定慢
→ 处理：给推力+降低风险
→ "要不先从小模块开始试？不满意全额退款"
```

### 3.2 线上→线下约见话术

> 什么时候看：一直线上聊，想把客户约出来见面（面谈转化率高3-5倍）。

**约见5个话术**：

```
场景1：直接邀约（适合聊了一段时间、关系不错的）
"王总，线上聊了这么久还没见过面。下周我在您公司附近办事，方便的话约个咖啡聊20分钟？"

场景2：以方案为由（适合有明确需求的）
"根据您的需求，我做了一份详细的方案。这个当面聊效果更好，能看到具体的演示和数据。您看周三下午还是周四上午方便？"

场景3：以行业资讯为由（适合还没明确需求的）
"最近行业出了个新政策/新趋势，对您这行影响挺大的。我整理了一份分析，方便见面给您看看？"

场景4：以人脉为由（适合社交型客户）
"下周有个行业聚会/活动，有几个您的同行也会去，要不要一起去聊聊？"

场景5：降低门槛（适合比较忙的客户）
"不用专门安排时间，就15分钟，我带上demo直接给您看一眼。您看这周哪天方便？我直接过去。"

⚠️ 约见原则：
├─ 给选择题（周三还是周四？）而不是问答题（您什么时候方便？）
├─ 降低时间门槛（15-20分钟，不是"聊一个小时"）
├─ 主动上门（不要让客户来找你）
├─ 给一个见面的理由（不是"出来坐坐"，而是有明确目的）
└─ 被拒绝了不放弃："没关系，那先线上聊着，等您方便了再约"
```

### 3.3 产品演示/Demo怎么做

> 什么时候看：要给客户做产品操作演示（不是讲PPT方案，是实际操作展示）。

**Demo黄金法则**：

```
演示前：
├─ 提前了解客户最关心的3个问题（不要演示全部功能！）
├─ 准备好演示环境（账号/数据/网络，提前测试）
├─ 准备好对比素材（"您现在的方式 vs 我们的方式"）
└─ 设定演示目标（这次demo要达成什么？签约？约决策者？试用？）

演示中（7步流程）：
├─ 第1步：确认需求（3分钟）→ "您最想看到什么？我重点演示"
├─ 第2步：展示核心场景（10分钟）→ 只演示客户最关心的功能
│   ⚠️ 原则：每展示一个功能，就回答"这对你有什么用"
├─ 第3步：数据/效果展示（5分钟）→ 看实际数据/报表/效果
├─ 第4步：对比展示（3分钟）→ "您现在的方式要XX步，我们的只要XX步"
├─ 第5步：答疑（5分钟）→ 回答客户疑问
├─ 第6步：试用/报价（5分钟）→ 趁热打铁推下一步
└─ 第7步：锁定下一步 → "您觉得怎么样？要不要先试用一周？"

演示后：
├─ 当天发总结邮件/消息（列出讨论的要点和下一步）
├─ 24小时内跟进试用情况
└─ 3天内推进签约或安排决策者沟通

⚠️ Demo致命错误：
├─ ❌ 把所有功能都演示一遍（客户会睡着）
├─ ❌ 只讲功能不讲价值（"这个按钮可以XX" → 客户心想"关我什么事"）
├─ ❌ 演示时出bug/卡顿（提前测试！准备备用截图/录屏）
├─ ❌ 演示完不锁定下一步（"您看看，有什么问题随时找我"→客户消失了）
└─ ❌ 一个人讲到底不让客户动手（让客户亲自操作！参与感=拥有感）
```

## 四、需求挖掘

### 4.1 需求与产品部分匹配

> 什么时候看：客户有需求，但你的产品不能100%满足，有些功能你没有。

**处理框架**：

```
第1步：诚实评估匹配度
├─ 80%以上匹配 → 正常推进，缺失部分用变通方案/定制补
├─ 60-80%匹配 → 可以做，但要明确边界，不能承诺做不到的
├─ 40-60%匹配 → 谨慎评估，可能不值得做
└─ 40%以下匹配 → 诚实告知，推荐更合适的产品（客户会记住你的诚实）

第2步：处理缺失功能（3种策略）

策略A：变通方案（功能虽然不完全一样，但能解决同样的问题）
→ "您要的XX功能我们虽然没有直接的按钮，但可以用YY方式实现同样的效果"
→ 给客户演示变通方案，确认能接受

策略B：定制开发（客户愿意付费/等时间）
→ "这个功能目前没有，但可以定制开发。预计XX周，费用XX元"
→ 明确时间、费用、验收标准

策略C：产品路线图（功能在开发计划中）
→ "这个功能在我们的Q3路线图里，预计X月上线"
→ 给客户看路线图，约定上线后通知
→ ⚠️ 不要承诺你不确定的时间！

第3步：诚实沟通（最关键）
→ 永远不要承诺你做不到的事！
→ "这个功能目前确实没有，我不想忽悠您。但我们可以用XX方式解决..."
→ 客户会更信任诚实的人，而不是什么都答应的人
→ 如果你的产品真的不适合 → 大方推荐竞品："您这个需求，XX公司的产品可能更合适"
→ 客户会记住你的专业和诚实，下次有合适的机会会回来找你
```

## 五、方案报价

### 5.1 定制项目报价

> 什么时候看：客户要的不是标准产品，是定制项目，不知道怎么报。

**定制报价5步法**：

```
第1步：拆解工作量和成本
├─ 人天估算法：把项目拆成小模块，每个模块估需要多少人天
├─ 成本 = 人天数 × 日均成本（含工资+社保+管理分摊）
├─ 材料成本：服务器/第三方服务/采购等
└─ 产出：成本明细表

第2步：确定利润率
├─ 一般定制项目利润率：30-50%
├─ 老客户/大单：可以降到20-30%
├─ 新客户/小单/急单：可以加到50-80%
├─ 报价 = 成本 × (1 + 利润率)
└─ 同时准备3档报价：标准版/增值版/旗舰版

第3步：报价单结构
├─ 项目概述（做什么、为什么做）
├─ 工作范围（明确做什么和不做什么！⚠️ 范围不清=后期扯皮）
├─ 交付物清单（每个模块交付什么）
├─ 时间计划（里程碑+交付日期）
├─ 报价明细（分模块报价，不要只给一个总数）
├─ 付款节奏（建议30%预付+30%中期+30%验收+10%质保金）
├─ 不含项说明（明确哪些不在范围内 → 防范围蔓延）
└─ 变更说明（超出范围的工作怎么收费）

第4步：防坑清单
├─ ⚠️ 范围必须白纸黑字写清楚（口头需求=后期无限加需求）
├─ ⚠️ 每个模块写明"交付标准"（怎么算完成）
├─ ⚠️ 明确客户配合事项（需要客户提供什么/什么时候提供）
├─ ⚠️ 预留10-20%的buffer（定制项目100%会超预期）
└─ ⚠️ 变更流程（客户加需求怎么走 → 报价+签字+排期）

第5步：报价话术
→ "这个项目的标准报价是XX万，包含了[模块A/B/C]的开发"
→ "如果预算有限，可以先做核心模块A和B，XX万起步，后续再加"
→ "这个报价基于目前的需求理解。如果需求有变化，我们会重新评估"
```

### 5.2 客户要求免费做方案

> 什么时候看：客户说"你先出个方案/做个demo看看效果，好了再谈合作"。

**处理方式**：

```
先判断客户类型：

类型A：大客户/预算充足，只是流程要求
→ 可以做！但设定边界：
→ "没问题，方案我来做。不过为了确保方案精准，需要您提供[XX数据/信息]"
→ "方案我先出概要版，确认方向对了再出详细版"（先小后大）
→ Demo做精简版/用已有案例展示，不从零开发

类型B：不确定值不值，想先看看效果
→ 给替代方案：
→ "我可以给您看同行业的成功案例，效果数据都有"
→ "我们有现成的demo环境，您可以直接体验，不用专门做"
→ "先不急着做方案，我们聊聊您的需求，看适不适合再说"

类型C：白嫖型（只想免费要方案，不打算付费）
→ 设门槛筛掉：
→ "做定制方案需要XX天的工作量，正常是收费的。
   如果签约了可以抵扣，如果没有签约需要支付XX元方案费"
→ 或者：只给标准方案模板 + 通用案例，不给定制内容
→ ⚠️ 绝对不要把详细的设计方案/技术方案白给！

话术：
→ "理解您想先看效果。这样，我先给您看几个跟我们做过的类似案例（展示成果数据）。
   如果觉得方向对了，我们再出定制方案，效率更高。"
→ "方案可以出，不过我需要先了解几个关键信息，确保方案对您有用而不是泛泛而谈。
   您方便提供一下[XX数据]吗？"（让客户先投入，减少白嫖）
```

## 六、成交阶段

### 6.1 签约前客户突然加条件

> 什么时候看：客户说"可以签，但你得加XX功能/降XX价格/送XX服务"。

**处理4步法**：

```
第1步：稳住情绪（不要慌，也不要马上拒绝）
→ "您提的这个需求我理解，让我想想怎么帮您安排"
→ 不要当场答应也不要当场拒绝！

第2步：评估合理性
├─ 合理的（小需求/你本来就要做的）→ 答应，但要交换条件
├─ 不合理但可商量的 → 谈判：给选项，让客户选
└─ 完全做不到的 → 诚实告知 + 给替代方案

第3步：交换原则（永远不免费让步！）
→ "加XX功能可以，但我需要您配合[签2年约/预付全款/加XX模块]"
→ "降价可以，但需要[减少服务范围/去掉XX模块/缩短服务期]"
→ "送XX服务可以，但您帮我[转介绍1个客户/做案例分享]"

第4步：话术模板
→ "王总，您提的这个我理解。这样：
   选项1：按现在的方案签，[XX功能]我们在二期加上，不影响一期上线
   选项2：一期就包含[XX功能]，但总价需要加XX万
   选项3：总价不变，但把[XX模块]换成[XX功能]
   您看哪个方案合适？"

⚠️ 临门一脚加条件的心理：
├─ 客户在试探你的底线 → 你的反应决定最终成交价
├─ 客户真的需要这个功能 → 如果合理就灵活处理
├─ 客户想获得"赢"的感觉 → 给他赢的感觉，但你要守住底线
└─ 永远给选项，不要只说"不行"
```

### 6.2 竞品突然降价搅局

> 什么时候看：竞争对手突然大降价/搞免费活动，客户来问你"人家降了你跟不跟"。

**应对策略**：

```
第1步：不要恐慌降价！
├─ 竞品降价不一定是针对你（可能是清库存/冲业绩/融资需要）
├─ 跟着降价 = 进入价格战 = 两败俱伤
└─ 先搞清楚竞品降价的真实原因

第2步：重新强调价值（不打价格战打价值战）
→ "王总，我理解价格是重要考量。不过您可以想想：
   1. 降价的厂商，后续服务能保障吗？（利润不够→砍服务→客户遭殃）
   2. 降价是因为产品卖不动 → 产品可能有你不知道的问题
   3. 今天降价，明天会不会涨回来？还是继续降？你买的是一个长期方案，不是一次性交易
   4. 我们的价格包含了[XX服务/XX保障/XX支持]，这些是竞品降价后不包含的"

第3步：拆开比（不要只比总价）
→ "您算一下综合成本：
   竞品降价后XX元，但不含[实施/培训/售后/升级]
   我们XX元，包含全套服务
   加上竞品不包含的部分，实际您花的更多"

第4步：给替代方案（不是降价，是给选择）
→ "如果您预算有限，我建议从基础版开始，XX元起步"
→ "我们可以调整方案范围，在您的预算内做到最优配置"
→ "如果您现在签约，我可以给一个XX的额外服务/延长服务期"（给价值不加折扣）

第5步：守住底线
├─ 如果客户纯粹比价格 → 这个客户可能不适合你
├─ "羊毛出在羊身上" → 降价的产品一定在其他地方找回来
├─ 有些客户不值得追 → 低价客户通常也是最难服务、最容易投诉的
└─ "王总，价格我做不了最低，但价值我能做到最高。您选哪个？"
```

## 七、签约交付

### 7.1 交付延误危机沟通

> 什么时候看：项目交付延迟了，不知道怎么跟客户说。

**危机沟通4步法**：

```
第1步：尽早告知（不要等到客户来问！）
├─ 发现可能延期 → 第一时间告知（提前7天以上）
├─ 越早说 → 客户越能理解
├─ 越晚说 → 客户越愤怒（觉得你隐瞒/不负责任）
└─ 话术："王总，有个情况需要提前跟您同步一下..."

第2步：原因+影响+方案（三件套）
→ "交付时间需要从X号调整到Y号。
   原因是[客观原因：XX模块的复杂度超预期/第三方接口变更/需求变更]
   影响：上线时间推迟X天
   方案：我们已经安排了[加人/加班/并行推进]来缩短延期
        作为补偿，我们[免费加XX服务/延长XX/送XX]"

第3步：给具体的修正计划
├─ 不要只说"尽快" → 给具体日期
├─ 分阶段交付：能先交付的部分先交付
├─ "整体延期到Y号，但核心模块X号可以先上线，不影响您的业务"
└─ 每周同步进度（重建信任）

第4步：预防下次
├─ 复盘原因（是估时不足？需求变更？资源不够？）
├─ 下次报价/排期加buffer
├─ 合同里写明"需求变更影响交付时间"的条款
└─ ⚠️ 绝对不要隐瞒！客户从别处知道你延期了 → 信任归零
```

### 7.2 客户验收不合格/投诉处理

> 什么时候看：交付的东西客户不满意，说"这不是我要的"。

**HEART投诉处理模型**：

```
H - Hear（倾听）
├─ 让客户把不满全部说出来，不要打断
├─ "您具体说说哪些地方不满意？我记下来"
└─ ⚠️ 不要辩解！不要说"但是..."！

E - Empathize（共情）
├─ "我理解您的感受，换我也会不满意"
├─ 认可客户的情绪是合理的
└─ ⚠️ 不要说"这是正常的/其他客户没反馈这个问题"

A - Apologize（道歉）
├─ 真诚道歉，不管是不是你的错
├─ "对不起，这是我们没做到位"
└─ 如果不是你的错："抱歉给您带来了不好的体验"

R - Resolve（解决）
├─ 给具体解决方案 + 时间节点
├─ "这个问题我来负责解决，X天内给您答复"
├─ 方案要具体：谁做、做什么、什么时候完成
└─ 如果问题复杂 → 分阶段解决，先给一个临时方案

T - Track（追踪）
├─ 解决后跟进确认："上次的问题解决了吗？您还满意吗？"
├─ 记录问题原因 → 改进流程 → 防止再犯
└─ 投诉处理好的客户 → 忠诚度比从没投诉的客户更高！
```

**验收不合格的3种情况**：

```
情况A：客户需求变了（交付物跟最初需求不一样了）
→ 对比合同/需求文档："我们看一下最初确认的需求..."
→ 如果确实是客户改了需求 → 走变更流程（加钱加时间）
→ 如果是你没做到 → 赶紧改

情况B：交付质量不达标
→ 承认问题 + 立即修正 + 给补偿
→ "确实是我们的问题，我安排X天内修好。给您带来不便，补偿XX"

情况C：客户期望太高（交付物达标但客户期望更多）
→ 管理期望："这个在合同范围内是XX标准，我们已经达到了"
→ 如果想超出预期 → "我可以额外做XX，但这超出合同范围了"
→ ⚠️ 预防方法：签合同前明确验收标准！白纸黑字写清楚"交付什么、什么标准"
```

## 八、客户维护

### 8.1 NPS/客户满意度调查

> 什么时候看：想了解客户满意度、做NPS调查。

**NPS实操**：

```
什么是NPS（Net Promoter Score）：
├─ 一个问题："您有多大可能向朋友/同行推荐我们的产品/服务？(0-10分)"
├─ 9-10分 = 推荐者（忠实客户，会转介绍）
├─ 7-8分 = 中立者（满意但不热情）
├─ 0-6分 = 贬损者（不满意，可能流失/说坏话）
└─ NPS = 推荐者% - 贬损者%

怎么调查：
├─ 频率：每季度/每半年一次（不要太频繁）
├─ 方式：微信发问卷 / 电话直接问 / 邮件问卷
├─ 时机：项目交付后30天 / 续约前90天 / 定期回访时
├─ 模板：
│   "王总，想占用您1分钟做个简单调研：
│    1. 您有多大可能向朋友推荐我们？(0-10分)
│    2. 您最满意的是什么？
│    3. 您觉得我们还有什么可以改进的？"
└─ ⚠️ 收到差评不要慌 → 贬损者是最有价值的反馈来源

调查后处理：
├─ 推荐者(9-10) → 请转介绍！发感谢 + 请做案例分享
├─ 中立者(7-8) → 问"怎么做能让您打10分？" → 找到提升点
├─ 贬损者(0-6) → 立即电话回访！了解原因 → 挽救关系
└─ 所有反馈 → 记录 → 改进 → 下次告诉客户"您上次提的问题我们改了"

满意度调查维度（不只是NPS，定期全方位体检）：
├─ 产品/服务质量（核心功能满足度）
├─ 响应速度（问题处理是否及时）
├─ 沟通体验（对接是否顺畅）
├─ 性价比感知（值不值）
├─ 续约意愿（明年还用不用）
└─ 转介绍意愿（会不会推荐给别人）
```

## 九、复购

### 9.1 续约时客户压价

> 什么时候看：老客户续约时说"用了2年了，给个老客户价吧" / "今年预算紧，降一点吧"。

**处理方式**：

```
第1步：先了解真实原因
├─ 预算真的紧了 → 客观原因，可以灵活
├─ 觉得不值这个价了 → 主观问题，要重新塑造价值
├─ 在比价 → 竞品报了低价
├─ 习惯性压价 → 每次续约都压
└─ 问法："是预算方面有变化了，还是觉得目前的服务有哪些可以改进的？"

第2步：重新展示价值（续约=第二次销售）
→ "王总，过去一年我们为您做了[XX成果/XX数据/XX价值]"
→ "续约不只是继续用，我们还新增了[XX功能/XX服务]"
→ "您的投入回报率是XX倍"（用数据说话）

第3步：处理策略
├─ 策略A：不降价但加价值
│   → "价格不能降，但我可以额外送[XX模块/XX月服务/XX培训]"
│   → 客户感觉赚到了，你的成本几乎不增加
├─ 策略B：签长约换优惠
│   → "签1年原价，签2年降5%，签3年降10%"
│   → 用折扣换长期锁定
├─ 策略C：调整方案范围
│   → "如果预算有限，我们可以调整方案：去掉[XX不常用的模块]，降到XX元"
│   → 不是单纯降价，是重新配置
└─ 策略D：坚守底线
    → "王总，我们这个价格已经是在同类产品里最有性价比的了。
       再降就保证不了服务质量了，我不想因为降价而降低对您的服务标准。"

第4步：预防续约压价
├─ 合同里写明"续约按原价/逐年递增X%"
├─ 平时持续传递价值（不要等到续约才想起来）
├─ 记录全年服务成果（续约谈判时有弹药）
└─ 提前90天启动续约（不要到期了才谈，时间紧迫你就被动）
```

## 十、流失挽回

### 10.1 客户方人员变动

> 什么时候看：客户的对接人/决策者离职/调岗了，新来的人不认你。

**应对策略**：

```
场景A：对接人离职（换了个新人）

第1步：立刻建立新关系
├─ 得知对接人离职 → 48小时内联系新接手的人
├─ 主动介绍："您好，我是XX公司的XX，之前负责您公司的[XX项目]"
├─ 安排一次面对面/视频沟通（不要只发消息）
└─ 准备一份"项目回顾"（之前做了什么、效果如何、下一步计划）

第2步：帮新接手的人成功
├─ 新人来了最怕接手烂摊子 → 你帮他快速了解情况
├─ 主动整理：项目现状/历史数据/已完成的工作/待办事项
├─ "这是我整理的项目交接文档，方便您快速了解"
├─ ⚠️ 新人需要的是"安全感"和"掌控感" → 给他！
└─ 让新人觉得你是一个靠谱的合作伙伴，而不是前任留下的问题

第3步：重新确认关系
├─ 不要假设新人会继续用你 → 重新走一遍价值展示
├─ "您对目前的合作有什么看法？有没有想调整的方向？"
├─ 如果新人想换供应商 → 了解原因，用数据和案例保卫阵地
└─ 给新人一个"新官上任三把火"的支持 → 帮他出业绩

场景B：决策者（老板/总监）换了
├─ 影响更大！新决策者可能有自己的供应商关系
├─ 尽快约见新决策者（通过对接人引荐）
├─ 准备：合作成果报告 + 行业洞察 + 未来建议
├─ 新决策者最关心：你帮他解决了什么问题？值不值？
└─ 如果新决策者要换 → 保持专业态度，不要撕破脸
   → "理解您的决定。合同到期前我们会做好交接。
      以后有需要随时联系。"（留后路）

场景C：你原来的对接人去了新公司
├─ 这是机会！不是流失
├─ 保持联系 → ta在新公司可能需要你的产品/服务
├─ "恭喜高升！新公司有[XX]方面的需求吗？"
└─ 前客户到新公司 = 自带信任的转介绍
```

## 十一、团队管理

### 11.1 团队士气管理

> 什么时候看：销售团队士气低落（连续丢单/业绩下滑/有人离职），需要激励。

**士气管理5招**：

```
第1招：找出士气低落的原因（不要盲目打鸡血）
├─ 业绩原因 → 连续丢单？目标太高？市场不好？
├─ 管理原因 → 分配不公？沟通不畅？微观管理太严？
├─ 个人原因 → 收入低？看不到前景？跟同事/领导有矛盾？
├─ 外部原因 → 竞品太强？产品问题？客户太难搞？
└─ 找到根因再对症下药！

第2招：小胜利激励（最有效）
├─ 士气低落时不要设大目标 → 设小目标创造"赢"的感觉
├─ "这周每个人只需要签1单" → 达成了就庆祝
├─ 把大目标拆成每天/每周的小目标
├─ 庆祝每一个小胜利（群内表扬/小奖励/下午茶）
└─ 士气是靠"赢"出来的，不是靠"喊口号"

第3招：1对1沟通（了解真实想法）
├─ 跟每个人单独聊15-20分钟
├─ 不要谈业绩！谈感受："最近感觉怎么样？有什么困难？"
├─ 倾听 > 说教
├─ 找到每个人在意什么（钱？认可？成长？自由？）
└─ 根据个人需求给激励（不是所有人都吃钱这一套）

第4招：透明沟通（不要隐瞒坏消息）
├─ 公司有困难 → 直接说（不要让团队瞎猜，猜的比实际更可怕）
├─ "目前公司/市场确实有挑战，但我们的应对策略是..."
├─ 给方向感：我们往哪走、怎么走、走到哪
└─ 不确定性 = 焦虑 = 士气低落 → 减少不确定性

第5招：仪式感+团队氛围
├─ 每周有"高光时刻"分享（每个人分享一个本周做得好的事）
├─ 月度"最佳进步奖"（不只奖业绩最好的人）
├─ 团队活动（吃饭/运动/团建）→ 不是花钱，是花时间
├─ 公开表扬，私下批评
└─ 销售 culture = "我们是一起打仗的兄弟"
```

### 11.2 销售周会/月会怎么开

> 什么时候看：想开好销售周会/月会，不要变成念数据/挨骂大会。

**周会标准SOP（30-45分钟）**：

```
开场（5分钟）：
├─ 上周亮点回顾（1-2个成交案例快速分享）
├─ 表扬上周表现好的同事（具体行为，不是泛泛表扬）
└─ 定调：这周的重点目标是什么

数据复盘（10分钟）：
├─ 上周关键数据：新增线索/拜访/方案/成交/回款
├─ 跟上周/上月对比（趋势好不好？）
├─ 漏斗健康度：每个阶段的转化率
└─ ⚠️ 不要念每个人的数据！只看异常（特别好/特别差的）

案例分享（10分钟）：
├─ 每周选1个案例（成交的 or 丢单的）
├─ 成交案例：怎么赢的？关键动作是什么？→ 复制
├─ 丢单案例：为什么输？学到什么？→ 改进
└─ 让团队成员分享，不是经理一个人讲

问题讨论（10分钟）：
├─ 大家遇到什么困难？需要什么支持？
├─ 团队一起出主意解决
├─ 限时讨论，不发散
└─ 记录待办事项+负责人+完成时间

总结（5分钟）：
├─ 本周目标确认
├─ 待办事项确认
└─ 打气收尾（正能量结束）

⚠️ 周会禁忌：
├─ ❌ 念每个人的数据（变成批斗大会）
├─ ❌ 经理一个人说30分钟（变成训话）
├─ ❌ 只谈数据不谈方法（知道数据差但不知道怎么办）
├─ ❌ 开超过1小时（销售的时间很贵）
└─ ❌ 只批评不表扬（士气越来越低）
```

**月会标准SOP（60-90分钟）**：

```
月度回顾（20分钟）：
├─ 月度数据总览 + 环比/同比
├─ 目标达成率（达到了庆祝，没达到分析原因）
├─ TOP销售分享（怎么做到的）
└─ 新客户/大客户进展

市场/产品动态（15分钟）：
├─ 竞品动态（对手在做什么？）
├─ 产品更新（有什么新功能/新政策？）
└─ 市场趋势（行业有什么变化？）

下月计划（15分钟）：
├─ 下月目标 + 分解
├─ 重点项目/重点客户
├─ 需要的资源和支持
└─ 激励政策/SPIF

培训/演练（20分钟）：
├─ 每月1次专题培训（异议处理/需求挖掘/谈判技巧...）
├─ 角色扮演（模拟客户对话）
├─ 话术打磨
└─ 轮流主讲（培养团队能力）
```

## 十二、特殊场景

### 12.1 政企/国企采购流程

> 什么时候看：客户是政府机关/国企/事业单位。

**政企采购特点**：

```
├─ 流程严格：必须走招标/比价/审批，不能像私企那样灵活
├─ 周期长：从接触到签约可能3-12个月
├─ 决策链长：使用者→部门领导→分管领导→财务→采购办→领导会议
├─ 合规要求高：反腐败/反贿赂红线严格（详见Phase 15反贿赂红线）
├─ 预算固定：年初定预算，预算内才能买，预算外要走调整审批
└─ 关系重要：但关系≠行贿！关系=信任+专业+靠谱

政企采购5阶段：
├─ 1.预算编制阶段（年初/上年末）→ 影响预算！让客户把你的产品写进预算
├─ 2.需求确认阶段 → 帮客户写需求文档（合理设置技术参数→你有优势）
├─ 3.招标/比价阶段 → 准备投标文件（详见advanced-templates标书框架）
├─ 4.评审阶段 → 可能需要述标/演示
└─ 5.签约+履约 → 严格按合同执行

关键策略：
├─ 尽早介入（预算编制阶段就接触，不要等招标公告出来才介入）
├─ 帮客户写需求（技术参数暗合你的产品优势）
├─ 多触点布局（使用者/技术负责人/决策者都要覆盖）
├─ 资质准备（提前准备好各种资质/案例/认证）
├─ 找到"内部支持者"（愿意推你产品的人）
└─ ⚠️ 合规底线绝对不能碰！（回扣/送礼/请客吃饭超过标准→法律风险）
```

### 12.2 内部撞单处理

> 什么时候看：发现公司内部另一个销售在跟同一个客户。

**处理SOP**：

```
第1步：判断归属（按规则来，不要抢）
├─ 公司有CRM/报备系统 → 按报备时间/规则判定
├─ 没有系统 → 找主管裁定
├─ 一般规则：谁先报备/先接触 = 谁的主客户
└─ ⚠️ 不要绕过规则私下抢！

第2步：沟通协调（不要对立）
├─ 主动找对方沟通："我发现我们在跟同一个客户，怎么处理比较好？"
├─ 合作 > 竞争 → 可以一起跟进（一个对技术/一个对商务）
├─ 如果客户从不同入口来的 → 看客户的意愿（客户想跟谁对接）
└─ 主管裁定后 → 尊重结果

第3步：预防机制
├─ 建立客户报备制度（先报先得）
├─ CRM系统统一管理客户（避免重复录入）
├─ 定期客户对账（发现撞单尽早处理）
├─ 明确规则：跨区域/跨产品线的客户归属
└─ 撞单奖金分配：如果两人都有贡献 → 按比例分业绩

⚠️ 撞单的真正危害：
├─ 客户看到你们内部不协调 → 专业度打折扣
├─ 两个销售给不同报价 → 客户趁机压价
├─ 团队内部矛盾 → 影响整体士气
└─ 客户不知道该信谁 → 谁都不信 → 丢单
```

## 补充：报价后沉默 / 法务强势 / 僵尸客户激活

### 报价后客户沉默

> 什么时候看：给客户报了价，客户突然就不回消息了。

**判断+处理**：

```
先判断沉默原因（5种可能）：

原因A：价格超预期，不知道怎么拒绝你
→ 处理：主动破冰，给台阶
→ "王总，报价发您了，不知道您看了感觉怎么样？
   如果预算有压力，我们可以调整方案配置，在您的预算内做到最优。"

原因B：还在内部讨论/对比
→ 处理：主动提供对比工具，帮客户做决策
→ "方便的话，我做一份跟竞品的对比表给您参考？"
→ 主动帮客户准备向上汇报的材料

原因C：需求变了/项目暂停了
→ 处理：确认项目状态
→ "王总，最近项目进展怎么样？有没有什么变化我需要了解的？"

原因D：真的忙，忘了回
→ 处理：轻量提醒（不要催）
→ "王总，方案您看了吗？有什么问题我随时解答。"
→ 发一条有价值的内容（行业资讯/案例），不提报价

原因E：已经在跟竞品签了（最坏情况）
→ 处理：最后争取一下，不行就留关系
→ "王总，不管最后选哪家，都希望您能选到最合适的。
   如果方便的话，能给我一个反馈吗？我们也想改进。"

跟进节奏（报价后）：
├─ 第1天：发报价，附"有问题随时找我"
├─ 第2天：不催，发一条相关案例/数据（不提报价）
├─ 第4天：主动问"方案看了吗？有什么疑问？"
├─ 第7天：换角度切入"最近行业出了个新政策/趋势，对您有影响"
├─ 第10天：试探"如果预算有压力，我们可以调整方案"
├─ 第14天：降频到周度触达
└─ 第21天：降频到月度培育

⚠️ 报价后沉默的预防（比处理更重要）：
├─ 报价时锁定下次沟通："报价发您后，我周四跟您确认一下？"
├─ 报价时给有效期："这个价格保留到X号"
├─ 不要只发数字！报价时附价值总结（为什么值这个价）
├─ 报价后24小时内主动跟进（不要等客户来找你）
└─ 如果客户说"我看看"→ 当场追问"大概什么时候能给我反馈？"
```

### 客户法务很强势

> 什么时候看：客户的法务/合规部门要求改合同条款，态度强硬，卡住了签约。

**处理策略**：

```
第1步：理解法务的立场（法务不是故意刁难你）
├─ 法务的职责是保护公司利益 → 他们天然对风险敏感
├─ 法务改条款不是针对你 → 是他们的工作要求
├─ 跟法务对立 = 给自己挖坑
└─ 正确心态：法务是帮你发现风险的盟友，不是敌人

第2步：分级处理条款修改要求

A级：不影响核心利益的修改 → 快速同意
├─ 术语调整/格式修改/措辞优化 → 直接同意
├─ "没问题，这个我们改"（快速建立好感）
└─ 用小让步换取大条款的谈判筹码

B级：可以接受但需要微调的修改 → 谈判交换
├─ "这个条款我们可以调整，但需要您在[XX条款]上配合我们"
├─ 用"如果...那么..."句式：如果接受A修改，那么B条款保持不变
└─ 核心：永远不单方面让步

C级：红线条款（绝对不能接受的） → 解释+替代方案
├─ 常见红线：
│   ├─ 无限责任（赔偿上不封顶）
│   ├─ 数据所有权归客户（你的核心IP）
│   ├─ 随时无条件退款
│   ├─ 排他条款（不能服务其他客户）
│   └─ 付款条件过于苛刻（如验收后180天付款）
├─ 处理："这个条款我们的合规要求不能改，原因是[XX]。
│        不过我理解您的顾虑，我们可以用[替代方案]来解决..."
├─ 给替代方案而不是直接拒绝
└─ 如果法务坚持 → 升级到双方高层沟通

第3步：准备你的"标准条款包"
├─ 提前准备好：哪些条款可以改、哪些不能改、替代方案是什么
├─ 不要临场决策！销售自己拍板改合同条款 = 后患无穷
├─ 跟自己的法务/合规提前沟通，拿到授权范围
├─ "授权范围内"→销售自己定
├─ "授权范围外"→走内部审批（告诉客户需要X天）
└─ ⚠️ 不要跟客户法务说"我们法务说不行" → 挑起法务对战
   → 要说"根据行业惯例/合规要求，这个条款通常是这样处理的..."

第4步：加速签约技巧
├─ 设定合同截止日期："这个报价/条款有效期到X号"
├─ 找到法务的"内部盟友"：客户的业务部门帮你推动法务
├─ "王总（业务负责人），合同法务那边反馈了XX条修改，
│   其中大部分我们都同意了。只有第X条因为我们合规要求不能改，
│   您看能不能帮忙内部沟通一下？"
├─ 用业务价值推动法务："如果X号前签不了，上线时间要推迟到Y月"
└─ 准备好"已签字版"合同模板 → 减少法务工作量（改得越少越快签）
```

### 僵尸客户激活（拖了3个月以上）

> 什么时候看：一个客户跟了3个月以上没有任何进展，不知道是继续还是放弃。

**判断+处理**：

```
第1步：冷血评估（不要自我欺骗）

问自己4个问题：
├─ 上次有实质性进展是什么时候？（超过2个月没进展=僵尸）
├─ 客户有没有明确的下一步行动？（没有=僵尸）
├─ 客户还回你消息吗？（不回=深度僵尸）
├─ 你还在这个客户身上花时间吗？（不想花但又不放弃=僵尸）

判断结果：
├─ 有实质进展但慢 → 继续！只是周期长
├─ 没进展但客户还回消息 → 尝试激活（下面的话术）
├─ 没进展且客户不回消息 → 最后一次尝试，不行就放弃
└─ 你自己都不想跟了 → 放弃！把时间花在新客户上

第2步：激活话术（从轻到重4级）

第1级：价值唤醒（最轻）
→ 发一条跟客户行业相关的高价值信息，不提合作
→ "王总，最近[行业新政策/竞品动态/行业报告]，对您应该有参考价值"
→ 目的：重新引起注意，不施压

第2级：新理由切入
→ 用一个新变化作为重新接触的理由
→ "王总，我们最近出了新功能/新方案/新案例，刚好能解决您之前提的[XX问题]"
→ "最近有几个您的同行在用我们的方案，效果不错，想到您了"
→ 目的：给客户一个重新考虑的理由

第3级：直接摊牌（中等压力）
→ 直接问客户现状，要一个明确答复
→ "王总，我们聊了有一阵了。我想直接问一下：
   目前这个项目还在推进吗？还是暂时搁置了？"
→ "不管什么情况都没关系，我就想确认一下，方便安排后续工作"
→ 目的：逼出一个明确的Yes/No

第4级：最后通牒（最高压力）
→ 给时间限制，倒逼决策
→ "王总，目前的报价/方案/优惠到X号到期。
   如果X号前确认不了，下次需要重新走审批，价格可能也会变。"
→ ⚠️ 说到做到！如果客户不回就真的撤回优惠
→ 目的：最后的推力，不成则放弃

第3步：放弃策略（知道何时放弃）
├─ 4级激活都试了，客户还是不回/不推进 → 放弃
├─ 放弃≠删除！降频到季度触达（万一以后有需求呢）
├─ "王总，理解您目前可能没有需求。我先不打扰您了，
│   以后有任何需要随时联系。祝好！"
├─ 把时间精力转到新客户身上（新客户ROI更高）
└─ 记录失败原因 → 复盘：为什么这个客户没成交？下次怎么改进？

第4步：预防僵尸客户
├─ 每次沟通后锁定下一步（具体时间+具体动作）
├─ 每周review pipeline，超过2周没进展的标记预警
├─ 不要把"客户说考虑一下"当成进展（那不是进展！）
├─ 设定每个客户的最长跟进周期（超了自动降级）
└─ pipeline里"虚假希望"最可怕 → 宁可早点认清，不要自欺欺人
```
