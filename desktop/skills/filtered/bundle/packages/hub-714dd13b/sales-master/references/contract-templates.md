### 1.2 三档报价策略

```
高端版（锚定）：¥XX万
├─ 包含所有功能+VIP服务

└─ 话术："这是全套方案，功能最全"

推荐版（目标）：¥XX万 ← 你真正想卖的
├─ 80%的核心功能，性价比最高
├─ 用高亮/标注引导客户选这个
└─ 话术："大多数客户选这个版本"

基础版（门槛）：¥XX万
├─ 核心功能，满足基本需求
├─ 目的：给预算不够的客户一个选择
└─ 话术："可以先从这个开始，后续升级"

💡 核心：给3个选择，但引导客户选中间的
```

## 二、合同签约检查清单

### 2.1 签约前必查清单

```
□ 合同主体
  ├─ 双方公司全称（与营业执照一致）
  ├─ 注册地址
  ├─ 法定代表人
  └─ 联系方式

□ 服务/产品范围
  ├─ 明确交付物清单（不能含糊）
  ├─ 明确不包含的内容（防止范围蔓延）
  ├─ 明确交付标准（怎么算完成？）
  └─ 明确变更流程（客户加需求怎么处理？）

□ 金额与付款
  ├─ 合同总金额（大写+小写）
  ├─ 付款方式（一次性/分期/里程碑）
  ├─ 付款节奏（推荐50%+30%+20%）
  ├─ 发票类型（普票/专票）
  ├─ 发票开具时间（付款前/后？）
  └─ 逾期付款利息/违约金

□ 时间节点
  ├─ 合同签订日
  ├─ 项目启动日
  ├─ 各阶段交付日期
  ├─ 验收期限
  └─ 合同有效期/到期日

□ 验收标准
  ├─ 验收标准（量化、可判断）
  ├─ 验收流程（谁验收？怎么验收？）
  ├─ 验收期限（几天内必须反馈？）
  └─ 不通过验收的处理方式

□ 售后服务
  ├─ 免费维护期（多长？）
  ├─ 维护范围（什么包含？什么不含？）
  ├─ 响应时间（紧急问题多久响应？）
  └─ 维护期满后的收费标准

□ 知识产权
  ├─ 交付物的知识产权归属
  ├─ 你的底层的技术的知识产权
  └─ 客户数据的安全和保密

□ 违约责任
  ├─ 你方违约的责任（交付延迟/质量问题）
  ├─ 客户违约的责任（逾期付款/随意变更）
  └─ 不可抗力条款

□ 终止条款
  ├─ 什么情况下可以终止合同
  ├─ 终止后的费用结算
  └─ 终止后的交接安排

□ 其他条款
  ├─ 保密条款
  ├─ 争议解决方式（协商/仲裁/诉讼）
  ├─ 管辖法院/仲裁机构
  └─ 合同份数和生效条件
```

### 2.2 付款节奏建议

```
按金额分类：

小单（< 1万）：
├─ 推荐：100%预付
├─ 备选：70%预付 + 30%验收后
└─ 理由：金额小，分期管理成本高

中单（1万-10万）：
├─ 推荐：50%预付 + 30%中期 + 20%验收后
├─ 备选：60%预付 + 40%验收后
└─ 理由：平衡双方风险

大单（10万-100万）：
├─ 推荐：30%预付 + 30% + 30% + 10%尾款
├─ 按里程碑分阶段付款
└─ 每个里程碑验收通过后付下一笔

超大单（> 100万）：
├─ 按项目阶段详细拆分
├─ 建议引入法律顾问审核
└─ 保留5-10%质保金（3-6个月后付）

⚠️ 黄金法则：
├─ 预付款 ≥ 30%（覆盖你的启动成本）
├─ 尾款 ≤ 20%（降低坏账风险）
├─ 千万不要0预付开工！（除非特别信任的客户）
└─ 尾款回收前，保留对交付物的控制权
```

### 2.3 合同常见坑

```
坑1：口头承诺不写进合同
→ 所有约定都要白纸黑字写进合同
→ "你们当时说过的XX" → "合同里没有这一条"

坑2：交付标准太模糊
❌ "客户满意后交付"
✅ "系统上线运行30天无重大bug（定义重大bug）即视为验收通过"

坑3：范围蔓延（Scope Creep）
→ 客户签了A，执行中要求加B、C、D
→ 合同里写明：超出范围的需求另行报价
→ 话术："这个不在合同范围内，我可以帮您做，但需要补一个变更单"

坑4：付款节奏没卡住
→ 客户拿到东西后拖延付款
→ 预付款收了再开工！尾款条款要严格

坑5：违约责任不对等
→ 只写了你违约的责任，没写客户的
→ 双向违约责任要对等

坑6：没有验收期限
→ 客户无限期拖延验收
→ 写明："交付后X天内未提出书面异议，视为验收通过"
```

### 3.2 催款节奏与话术

```
阶段1：到期前7天（温和提醒）
"王总好，提醒一下，尾款XX号到期，
金额¥XX，方便安排一下吗？
账号信息：[银行/账号]"

阶段2：到期当天（正式通知）
"王总，今天是对账日，
合同约定的尾款¥XX今天到期，
麻烦您安排财务处理一下，
账号信息：[银行/账号]"

阶段3：逾期3天（跟进原因）
"王总，款项还没到账，是有什么问题吗？
需要我重新发一下账单或者配合什么？"

阶段4：逾期7天（升级处理）
"王总，这笔款已经逾期一周了，
麻烦帮催一下财务，看看什么时候能安排？"

阶段5：逾期15天（书面催款）
→ 发正式催款函（邮件+纸质快递）
→ 抄送对方财务/领导

阶段6：逾期30天（法律手段）
→ 暂停服务
→ 发律师函
→ 考虑起诉

⚠️ 催款原则：
├─ 不要觉得不好意思——你提供了价值，收钱天经地义
├─ 催款话术要客气但坚定，不要道歉
├─ 每次催款都留记录（微信/邮件/通话记录）
├─ 大额应收款，建议购买应收款保险
└─ 建立信用评级：逾期客户下次合作提高预付比例
```

## 四、合同续约管理

### 4.1 续约时间线

```
合同到期前90天：启动续约准备
├─ 回顾合作成果（帮客户实现了什么价值？）
├─ 准备续约方案（新功能/新服务/新优惠）
├─ 内部评估：这个客户值不值得续约？
└─ 如果客户有不满，提前解决

合同到期前60天：第一次续约沟通
→ "王总，咱们合作马上满X年了，
   我准备了一份续约方案，给您看看"

合同到期前30天：正式方案+早鸟优惠
→ "续约方案如下，提前签约有XX优惠"

合同到期前15天：跟进+限时激励
→ "王总，续约方案您看了吗？
   早鸟优惠到本周截止，帮您确认一下？"

合同到期前7天：最后确认/紧急处理
→ 如果客户还在犹豫，找原因，针对性解决

合同到期日：
├─ 续约成功 → 签新合同，继续合作
├─ 还在谈 → 签一个过渡协议，延长30天
└─ 不续约 → 优雅收尾，保持关系，留后路
```

### 4.2 续约话术

```

1. [具体成果1 - 数据化]
```
