# Phase 12：进阶场景库

> 以下是销售实战中高频但容易被忽略的场景。

## 12.1 销售提成方案设计

```
设计原则：
├─ 底薪+提成比例要平衡（底薪太低留不住人，提成太低没动力）
├─ 阶梯式提成：卖得越多提成比例越高（激励冲刺）
├─ 设置加速器：超额完成部分提成翻倍
└─ 续约/复购也要算提成（鼓励长期维护）

常见提成结构：

方案A（适合初创团队）：
  底薪：5000-8000
  提成：成交金额的 5-10%
  例：月成交10万 → 提成5000-10000 → 总收入10000-18000

方案B（阶梯式，适合成熟团队）：
  底薪：6000
  0-5万部分：3%提成
  5-15万部分：5%提成
  15万以上部分：8%提成（加速器）
  例：月成交20万 → 1500+5000+4000=10500 → 总收入16500

方案C（含续约，适合SaaS/订阅制）：
  新签提成：8%
  续约提成：3%（鼓励维护老客户）
  追加销售：5%
  例：新签10万(8000)+续约5万(1500)+追加3万(1500)=11000

⚠️ 注意事项：
├─ 提成发放节奏：签约收预付款发50%，尾款到账发50%
├─ 退货/退款要扣回提成（设3个月锁定期）
├─ 团队单和个人单分开算
└─ 每季度评估提成方案是否合理（太低了调高，太高了看利润）
```

## 12.2 招投标流程

```
客户要招投标，意味着进入了正式采购流程：

投标前（收到标书→截止日前）：
├─ 评估是否值得投（看资质要求/预算/竞争态势）
├─ 组建投标小组（销售+技术+商务）
├─ 仔细读标书：评分标准/资质要求/技术参数/商务条件
├─ 找差异化优势：在哪个评分项上能拿最高分
├─ 准备标书文件：
│   ├─ 技术方案（核心！占分最大）
│   ├─ 商务报价（密封报价，注意不要报太高也不要最低）
│   ├─ 公司资质（营业执照/ISO认证/行业资质）
│   ├─ 成功案例（同行业案例最有说服力）
│   ├─ 售后方案（响应时间/SLA/培训）
│   └─ 其他（财务报告/纳税证明/信用证明）
└─ 报价策略：不要做最低价！做性价比最高的

投标中：
├─ 按时递交（截止时间前至少1天送达）
├─ 现场答辩/讲标（如果有的话）
│   → 准备10分钟PPT，重点讲方案+案例+ROI
│   → 预演3遍以上
│   → 准备评委可能问的10个问题
└─ 答疑阶段及时回复

投标后：
├─ 中标：走签约流程（注意中标价≠合同价，可谈增项）
├─ 未中标：要复盘结果（哪个评分项丢了分）
└─ 未中标也要保持关系（下次再投，或客户找你直接采购）

⚠️ 招投标红线：
├─ 不要围标串标（违法）
├─ 不要诋毁竞品
├─ 不要私下接触评委
└─ 标书不要泄露给竞品
```

## 12.3 多客户并行管理

```
销售最怕的不是没有客户，而是客户多了管不过来。

时间管理四象限法：

     紧急          不紧急
重要  A: 今日必做    B: 重要计划
     ·到期催款      ·方案制作
     ·客户回信      ·客户拜访
     ·合同签约      ·线索开发

不重要 C: 授权/批量  D: 尽量减少
     ·数据录入      ·无效会议
     ·格式调整      ·刷朋友圈

执行原则：
├─ 每天只做3件A类事（最重要的）
├─ B类事安排固定时间段做（如下午14:00-16:00）
├─ C类事批量处理（如每天17:00统一录数据）
└─ D类事能推就推

客户管理优先级（每天复习）：
├─ 今日必联系（≤3人）：A级客户+即将签约+逾期催款
├─ 本周必推进（≤5人）：谈判阶段+方案阶段
├─ 持续培育（5-10人）：意向客户+新线索
└─ 低频维护（其余）：C/D级客户月度触达

工具辅助：
├─ 用 email_automation.py 的 work-logs 记录每个客户每次互动
├─ 用 check-dates 自动提醒关键日期
├─ 每周一早上做Pipeline总览（哪些客户在哪个阶段）
└─ 每天下班前花5分钟规划明天的Top 3
```

## 12.4 转介绍客户跟进

```
老客户介绍的新客户 ≠ 普通新客户！

转介绍客户特点：
├─ 信任门槛低（朋友推荐的，天然信任）
├─ 成交周期短（省去了获客→培育→建立信任的时间）
├─ 客单价通常更高（跟推荐人消费水平接近）
└─ 转化率60-80%（远高于普通线索的5-15%）

转介绍客户4步跟进法：

第1步：了解背景（接到的第一时间）
"王总，感谢张总的推荐！张总说您可能需要[服务]，
方便简单说说您目前的情况吗？"

第2步：借力推荐人信任（第一次沟通）
"张总用我们服务2年了，他说最大的感受是[具体效果]，
您的需求跟他类似吗？还是有什么不同的地方？"
→ 借推荐人的嘴说你的好，比自己说有力100倍

第3步：快速推进（缩短流程）
→ 转介绍客户不需要14天培育，可以直接进方案
→ "王总，既然是张总推荐的，我直接给您做一个方案，
   比张总当时的还优惠一点，您看怎么样？"

第4步：感谢推荐人（成交后）
→ 成交后第一时间告诉推荐人："张总，您推荐的王总签约了！
   非常感谢，[回报方式：折扣/红包/礼物]"
→ 让推荐人有成就感，下次还会帮你介绍
→ 闭环：新客户满意 → 也帮你转介绍 → 滚雪球

⚠️ 转介绍客户绝对不能搞砸：
├─ 服务质量要比普通客户更高（搞砸了丢两个客户）
├─ 响应速度要更快（推荐人的面子你给）
├─ 价格不要比推荐人买的时候高太多（会说给推荐人听）
└─ 持续同步进展给推荐人（让推荐人放心）
```

## 12.5 微信社群销售转化

```
社群不是发广告的地方，是建信任的地方。

社群转化4阶段：

阶段1：融入（第1-2周）
├─ 不要一进群就发广告！
├─ 观察群规、群文化、谁是KOL
├─ 先回答别人的问题、帮别人
├─ 偶尔分享有价值的干货（不带产品推广）
└─ 目标：让群友认识你→认可你

阶段2：种草（第2-4周）
├─ 分享真实案例/客户故事（不是硬广）
├─ 回答问题时有技巧地提及产品
│   "这个问题我之前帮客户解决过，用XX方法效果不错"
├─ 在群里展现专业形象（行业洞察/数据分析/趋势判断）
└─ 目标：有人主动私聊你问问题

阶段3：转化（第4-8周）
├─ 群里做一次正式分享/直播（先跟群主报备）
├─ 发限时群内专属优惠（制造稀缺感）
├─ 对互动过的人1对1私聊跟进
├─ 邀请到线下活动/体验
└─ 目标：群里3-5人转化为付费客户

阶段4：裂变（持续）
├─ 满意的客户在群里帮你说话（最强广告）
├─ 鼓励群成员推荐（转介绍机制）
├─ 建自己的VIP群（付费客户专属）
└─ 目标：从1个群裂变到多个群

社群运营节奏：
├─ 每天发1-2条有价值内容（不是广告）
├─ 每天互动3-5次（评论/回答/点赞）
├─ 每周做1次主题分享
├─ 每月做1次社群活动（线下/线上）
└─ 数据指标：活跃度/私聊数/转化数

⚠️ 社群销售红线：
├─ 不要刷屏发广告（会被踢）
├─ 不要跟同行在群里吵架
├─ 不要在别人的群里挖人
├─ 不要群发私信推销（容易被告发）
└─ 先给价值，再谈生意
```
