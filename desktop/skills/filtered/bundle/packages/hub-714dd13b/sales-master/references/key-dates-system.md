# 关键日期管理系统

> 客户觉得你用心，往往就在这些细节上。记住客户生日、提前提醒合同到期，比任何话术都管用。

## 二、客户生日管理系统

### 2.1 生日信息收集技巧

```
怎么自然地获取客户生日？

方法1：身份证/名片推断
→ 有些名片上有生日信息
→ 身份证号第7-14位是生日（但要合法获取）

方法2：社交媒体
→ 朋友圈/微博可能有生日动态
→ 微信个人信息有时会显示

方法3：日常聊天中自然问
→ "王总您是哪里人？" → "XX的" → "哦？我有个朋友也是XX的，您是哪年的？"
→ "王总看着好年轻，是90后吧？" → 自然带出年龄/生日
→ 聊星座/属相 → "王总您什么星座？" → 推断月份

方法4：填表/注册
→ 客户注册你的服务时收集生日信息
→ 会员系统/CRM系统里记录

方法5：直接问（关系到位后）
→ "王总，我记一下您的生日，到时候给您送祝福~
   是公历还是农历呀？"
→ 关系好的客户直接问完全没问题

⚠️ 记录格式：统一用公历，如果是农历要标注
→ "王总生日：8月15日（农历七月十五，每年公历日期不同）"
```

### 2.2 按级别的生日动作

```
A级VIP客户：
├─ 提前7天：准备定制礼物（预算200-500元）
│   → 投其所好（茶叶/酒/书/运动用品）
│   → 不要送太贵的（客户有压力/合规风险）
├─ 生日当天：
│   → 早上发微信祝福（带名字，走心）
│   → 打电话祝福（比微信更有诚意）
│   → 礼物提前寄到或当面送
└─ 进阶：了解客户全家生日
    → 孩子生日也送祝福/小礼物
    → 让客户觉得你"真的用心"

B级潜力客户：
├─ 提前3天：准备小礼物/红包（预算50-200元）
├─ 生日当天：微信祝福（走心，不群发）
└─ 可以结合业务："生日月专享优惠"

C级普通客户：
├─ 生日当天：微信祝福
├─ 可以群发但要带个人称呼
└─ "王总，祝您生日快乐！万事如意！"

D级沉睡客户：
├─ 生日当天：微信祝福（顺便唤醒）
└─ "王总好久不见，今天是您生日，祝您生日快乐！
    有空联系，我们最近出了新方案~"
```

## 三、合同到期/续约提醒系统

### 3.1 合同到期提醒四级预警

```
🟢 绿灯（到期前90天）——准备阶段
动作：
├─ 回顾合作成果，整理价值清单
├─ 准备续约方案（含升级/优惠）
├─ 内部评估是否续约（客户质量）
└─ 如果有问题，提前解决

通知话术：
"王总，咱们合作马上一年了！
最近我帮您梳理了一下合作成果，
顺便准备了明年的升级方案，下次见面聊？"

🟡 黄灯（到期前60天）——沟通阶段
动作：
├─ 正式提出续约
├─ 发送续约方案
└─ 了解客户是否有换供应商的想法

通知话术：
"王总，咱们的合同还有2个月到期，
我给您准备了一份续约方案，
有几个新功能/新服务，价格也有老客户优惠，
我发您看看？"

🟠 橙灯（到期前30天）——推进阶段
动作：
├─ 跟进方案反馈
├─ 处理客户异议
├─ 提供早鸟优惠（刺激提前签约）
└─ 了解竞品动态

通知话术：
"王总，续约方案您看了吗？
本月签约有额外XX优惠，
有什么问题我随时解答"

🔴 红灯（到期前15天）——紧急阶段
动作：
├─ 高频跟进（每3天1次）
├─ 找到犹豫的真实原因
├─ 上级介入（大客户）
├─ 准备替代方案
└─ 如果不续约，准备过渡和交接

通知话术：
"王总，合同还有2周到期了，
目前是什么情况？有什么顾虑我帮您解决？
如果需要调整方案，我们还可以谈"

⚡ 紧急（到期前7天）——最后阶段
├─ 每天跟进
├─ 最后报价/让步
├─ 准备过渡协议（延长30天）
└─ 不续约的话，优雅收尾
```

## 四、其他关键日期管理

### 4.1 项目上线后回访节点

```
项目上线后，按以下节点回访：

Day 7：使用情况初查
"王总，系统上线一周了，用着怎么样？
有没有什么问题需要解决？"

Day 30：效果评估
"王总，系统用了一个月了，
我帮您做个效果评估报告，
看看是否达到了预期目标？"

Day 60：深度回访
"王总，两个月了，想跟您深入聊聊，
目前哪些功能用得好？哪些还需要改进？
有没有新的需求？"

Day 90：续约/升级引导
"王总，三个月了，效果您也看到了，
我们有个升级版/高级功能，
跟您现在的使用场景很匹配，要不要了解一下？"
```

### 4.2 复购窗口期

```
不同产品的复购窗口：

消耗品/订阅服务：
├─ 月度服务：到期前7天提醒续费
├─ 季度消耗品：用完前2周提醒补货
├─ 年度服务：到期前60天开始续约推进
└─ 一次性产品：根据使用周期判断

复购触发信号：
├─ 客户主动问"还有没有XX"
├─ 客户说"上次买的用完了/到期了"
├─ 到了历史复购时间节点
└─ 客户业务扩张/团队增长（需要更多）

复购提醒话术：
"王总，上次您买的XX差不多该用完了吧？
最近正好有老客户补货优惠，
需要的话我帮您安排？
顺便问一下，用着还满意吗？"
```

### 4.3 财年/预算周期

```
利用客户预算周期做销售：

中国大部分企业财年 = 自然年（1月-12月）
├─ 10-11月：预算要花完（不花明年减预算）
│   → 最佳签单时机！客户急着花钱
├─ 12月：做明年预算
│   → 可以提前锁定明年的需求
├─ 1-2月：春节，预算刚批，决策慢
│   → 淡季，适合培育客户
├─ 3-4月：新预算到位，开始执行
│   → 旺季，客户有钱了，加速推进
└─ 6-7月：年中评估
    → 有预算结余的客户可以推

外资企业财年可能不同：
├─ 美国企业：很多是7月-次年6月
├─ 日本企业：很多是4月-次年3月
└─ 先问清楚客户的财年周期
```

## 五、自动化提醒实现方式

### 5.1 用Hermes cron实现自动提醒

```
可以设置定时任务，定期扫描客户数据，生成提醒：

# 每天早上8点检查今日待办
cron: 0 8 * * *
任务：扫描客户生日表、合同到期表、跟进提醒表
输出：今日需联系的客户清单 + 话术建议

# 每周一早上生成本周计划
cron: 0 8 * * 1
任务：生成本周客户维护计划
输出：本周需要触达的客户 + 触达方式 + 话术

# 每月1号生成月度报告
cron: 0 8 1 * *
任务：生成上月客户维护总结 + 本月计划
输出：月度客户维护报告
```
