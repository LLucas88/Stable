## 🎭 性格分析

**性格类型（DISC）：**
□ 🔴 支配型（D型-老虎）——结果导向、效率高、直接
   → 应对：开门见山，给结论，别绕弯
   → 禁忌：不要啰嗦、不要闲聊太久

□ 🟡 表达型（I型-孔雀）——爱说话、要面子、社交型
   → 应对：多互动、多赞美、给社交货币
   → 禁忌：不要冷场、不要否定他

□ 🟢 亲和型（S型-考拉）——温和、慢热、怕风险
   → 应对：建立信任、给安全感、不要催
   → 禁忌：不要逼单太狠

□ 🔵 分析型（C型-猫头鹰）——理性、重数据、要细节
   → 应对：给数据、给案例、给保障
   → 禁忌：不要讲情怀

## 二、客户档案使用指南

### 2.1 每次沟通前（2分钟）

```
沟通前快速浏览：
1. 客户什么级别？→ 决定你投入多少精力
2. 上次聊到哪了？→ 从上次的话题接续
3. 客户性格类型？→ 用对应的方式沟通
4. 客户核心需求/痛点？→ 沟通中对接
5. 有什么承诺没兑现？→ 优先处理
6. 客户偏好？→ 用对方舒服的方式
```

### 2.2 每次沟通后（5分钟）

```
沟通后立即更新：
1. 跟进记录表（日期/方式/内容/反应/下一步）
2. 更新销售阶段
3. 更新成交概率
4. 记录新了解到的偏好信息
5. 设置下次跟进提醒
6. 如果有承诺，记下来，设提醒
```

### 2.3 定期更新

```
每周：更新跟进记录
每月：重新评估客户级别（A/B/C/D）
每季度：更新客户价值评估（RFM/CLV）
每半年：全面回顾客户档案，清理过时信息
```
