# Phase 17：定价策略与价格心理学

> 价格不是随便定的。同样的产品，定价方式不同，利润差2-3倍。

## 什么时候看这个文件

- 不知道产品该定什么价位
- 定价太低没利润，太高卖不动
- 想涨价但怕客户流失
- 想用价格策略提升转化率和客单价
- 面对价格战不知道怎么应对

---

## 一、5大定价方法

### 1.1 成本加成定价（最简单）

```
公式：价格 = 成本 × (1 + 加成率)

例：产品成本50元，加成率100%
    价格 = 50 × 2 = 100元
    毛利 = 100 - 50 = 50元

优点：简单，保证利润
缺点：完全忽略客户感知价值和竞品价格

适用：制造业/贸易商/零售商（成本透明的品类）
⚠️ 不要只用这个方法！它是底线参考，不是最终定价
```

### 1.2 价值定价（利润最高）

```
逻辑：不看你花了多少成本，看客户觉得值多少。

例：一个SaaS软件，开发成本可能只有几万块。
    但如果它帮客户一年省100万人力成本，
    客户愿意付10万/年。
    你定10万/年，毛利率99%+。

价值定价3步法：
Step 1：量化客户收益
  "用我们的产品，客户一年省/赚多少钱？"
  → 帮客户省100万/年

Step 2：定价=客户收益的10-30%
  → 10-30万/年（客户觉得"花10万省100万，划算"）

Step 3：验证
  → 客户接受 → 定对了
  → 客户不接受 → 你的价值塑造不够/收益没量化清楚

适用：SaaS/咨询/服务/知识产权/高附加值产品
```

### 1.3 竞争定价（最常见）

```
逻辑：看竞品定多少，你定差不多（略高/略低/持平）

3种策略：

渗透定价（比竞品低10-30%）
├─ 目标：快速抢占市场份额
├─ 适合：新品上市/市场挑战者
├─ 风险：利润薄/引发价格战/品牌定位低
└─ 例：小米手机初期

持平定价（跟竞品一样）
├─ 目标：不打价格战，靠差异化竞争
├─ 适合：成熟市场/产品同质化高
├─ 要求：必须有明显的差异化卖点
└─ 例：可口可乐vs百事可乐

撇脂定价（比竞品高20-100%）
├─ 目标：高端定位/高利润
├─ 适合：品牌力强/技术领先/差异化明显
├─ 风险：销量小/客户群窄
└─ 例：苹果手机
```

### 1.4 动态定价（最灵活）

```
逻辑：同一个产品，不同时间/不同客户/不同渠道，价格不同。

航空/酒店模式（时间动态）：
├─ 旺季涨价，淡季降价
├─ 提前预订便宜，临时预订贵
├─ 剩余越少越贵
└─ 适用：旅游/酒店/机票/演出票

电商模式（渠道/用户动态）：
├─ 新用户首单低价（获客）
├─ 老用户复购原价/涨价（利润）
├─ 大促降价（走量）
├─ 日常正价（利润）
└─ 适用：电商/SaaS/订阅服务

企业模式（客户动态）：
├─ 大客户量折扣（买越多单价越低）
├─ 小客户标准价
├─ 战略客户亏本做（换案例/换市场）
└─ 适用：B2B/批发/SaaS企业版
```

### 1.5 阶梯定价（提升客单价利器）

```
逻辑：设置多个价位档位，引导客户选中间或最高。

经典3档结构：

         高端版          标准版          庼础版
         ¥9,800/年      ¥4,800/年 ←     ¥2,800/年
         全功能          核心功能         基础功能
         优先支持         标准支持         邮件支持

├─ 高端版作用：锚定高价，让标准版显得划算（不一定指望卖多少）
├─ 标准版作用：主力出货，80%客户选这个
├─ 基础版作用：降低门槛， capture 预算不够的客户
└─ 核心：让中间档看起来"性价比最高"

4个定价心理学技巧（配合阶梯定价）：

① 诱饵效应
├─ 加一个"没人选"的选项，改变其他选项的吸引力
├─ 例：只有基础版¥2980和标准版¥4800
│   → 很多人选基础版
├─ 加入高端版¥9800
│   → 标准版突然显得超值，多数人选标准版
└─ 高端版就是"诱饵"

② 锚定效应
├─ 先展示高价，再展示实际价格
├─ "原价¥9800，今天只要¥4800"
├─ 客户心里锚点是9800，觉得4800"赚了"
└─ 即使4800本身不便宜

③ 整数定价 vs 尾数定价
├─ 高端产品用整数：¥10,000（简洁/高端感）
├─ 大众产品用尾数：¥99/¥199/¥298（便宜感）
├─ 99比100感觉便宜很多（左位数效应）
└— 订阅制用月费：¥399/月 比 ¥4788/年 感觉便宜

④ 分拆定价（降低感知成本）
├─ "¥399/月"比"¥4788/年"感觉便宜
├─ "每天只要¥13元"比"一年¥4788"感觉便宜
├─ "相当于一杯咖啡的钱"比"每月¥30"感觉便宜
└─ 把大数字拆成小单位，降低心理门槛
```

## 二、涨价策略

### 2.1 什么时候该涨价

```
涨价信号（出现2个以上就该涨）：

✅ 产品供不应求（客户排队/库存不够）
✅ 毛利率低于30%（利润太薄）
✅ 竞品比你贵20%以上（你定低了）
✅ 客户从不讨价还价（说明价格远低于心理预期）
✅ 客户说"这么便宜不会是假的吧"（价格拉低了信任）
✅ 近6个月增加了大量新功能/服务（价值提升了）
✅ 原材料/运营成本大幅上涨

不该涨价的情况：
❌ 销量在下滑（涨价会加速下滑）
❌ 竞品正在降价（你涨=送客户给竞品）
❌ 没有新增价值（光涨价不给理由=客户流失）
❌ 大客户合同还没续约（等续约后再涨）
```

### 2.2 涨价实操方法

```
方法1：新品涨价法（最安全）
├─ 老产品维持原价，推出升级版（加功能/改包装/换规格）
├─ 升级版定高价
├─ 逐步引导客户从老产品转向新产品
├─ 老产品慢慢淡出
└─ 好处：不会直接得罪老客户

方法2：老客户保护涨价法
├─ 新客户直接用新价格
├─ 老客户维持原价X个月（过渡期）
├─ 过渡期结束后全面涨价
├─ 提前通知："X月X日起价格调整，老客户在此之前续约享原价"
└─ 好处：给老客户缓冲，还能催续约

方法3：价值叠加涨价法
├─ 不光涨价，同时增加价值
├─ "价格从¥4800涨到¥5800，但增加了3个新功能+1对1服务"
├─ 让客户觉得"虽然贵了1000，但多了价值2000的东西"
└─ 好处：涨价的阻力最小

方法4：套餐调整涨价法
├─ 不涨单品价格，但调整套餐结构
├─ 原来包含A+B+C的套餐¥4800
├─ 现在只包含A+B，要C需要加¥1000
├─ 或者改为A+B+C+D，¥5800（加量加价）
└─ 好处：不直接涨价，客户感知弱

涨价幅度建议：
├─ 一次性涨幅<10%：客户几乎无感
├─ 10-20%：需要给理由/加价值
├─ 20%+：必须有重大升级/不可替代性
└─ 建议：每年小幅涨（5-10%）> 隔几年大幅涨（30%+）
```

## 三、应对价格战

### 3.1 价格战3种应对策略

```
策略1：不跟降，打价值战（推荐）

核心逻辑：客户嫌贵，不是价格问题，是价值感知不够。

做法：
├─ 量化价值："您花¥10,000，但我们帮您省/赚¥100,000"
├─ 对比TCO（总拥有成本）："竞品便宜¥3000，但每年多花¥5000维护"
├─ 强调差异化："我们贵是因为[独家功能/更好服务/更多保障]"
├─ 社交证明："XX公司选了我们而不是更便宜的竞品，因为..."
├─ 分割定价："如果预算紧，可以先做基础版¥X起步"
└─ 承认竞品优势："对方确实更便宜，但您要考虑[XX风险]"

策略2：差异化定价（不打正面战场）

├─ 你不打价格战，但出一个"战斗版"产品
├─ 专门针对竞品低价市场，配置精简
├─ 主力产品维持高价+高价值
└─ 例：苹果出SE系列（低价版），不影响旗舰Pro定价

策略3：战略性降价（最后手段）

仅在以下情况使用：
├─ 你的成本结构确实比竞品低（你能耗死对方）
├─ 市场窗口期极短（现在不抢就没了）
├─ 你有后端变现（前端亏钱，后端赚钱）
└─ ⚠️ 不要轻易打价格战！赢了也是惨胜（利润没了）
```

### 3.2 价格谈判中的锚定

```
谈判中的价格锚定技巧：

技巧1：先开价（你先说数字）
├─ 谁先开价，谁就锚定了谈判区间
├─ 你先报¥100,000，客户会觉得50,000-100,000是合理区间
├─ 客户先报¥30,000，你会觉得30,000-50,000是合理区间
├─ 先开价者优势：锚点对你有利
└— 但你的开价不能太离谱（否则破坏信任）

技巧2：报区间而不是单点
├─ "我们的方案通常在5-8万之间，具体看需求"
├─ 客户的注意力会落在5万（区间的低端）
├─ 但你的锚定区间已经设到了5-8万
└─ 比"一口价6万5"更有弹性

技巧3：用高价选项做锚
├─ 先展示高端版¥9800
├─ 客户觉得"太贵了"
├─ 再展示标准版¥4800
├─ 客户觉得"这个还行"
└─ 如果没有¥9800的锚，客户会觉得¥4800也贵

技巧4：让步的幅度递减
├─ 第一次让步：降10%（¥4800→¥4320）
├─ 第二次让步：降5%（¥4320→¥4104）
├─ 第三次让步：降2%（¥4104→¥4022）
├─ 每次让步幅度递减，传递"已经到底了"的信号
└─ 千万不要等额让步（每次降5%），客户会觉得你还能降
```
