## 三、赢/输单分析模板（已填写示例）

### 赢单分析

```
赢单复盘：赵总（XX电商）¥58,000/年

赢单原因TOP 3：
  1. 同行业案例（给赵总看了3个电商客户案例 → 信任建立）
  2. 快速响应（每次4小时内回复 → 客户说"你们最靠谱"）
  3. 灵活定价（3档方案+2年约优惠 → 客户觉得划算）

关键转折点：
  6/20面谈时，赵总说"考虑一下"
  → 销售没有放弃，第3天发了同行案例
  → 赵总看完后主动打电话："你们的案例跟我情况最像"
  → 7/1签约

谁帮了我们：
  Champion：赵总的运营总监李姐（她帮推荐了方案）

竞品情况：
  智答AI也在竞争，输给我们因为：
  - 只覆盖网站微信（赵总需要全渠道）
  - 没有电商行业案例

可复制的经验：
  · 同行业案例是最强武器 → 多准备行业专属案例
  · "考虑一下"后不要放弃 → 第3天用案例重新激活
  · 找到Champion（运营总监李姐）帮内部推动
```

### 输单分析

```
输单复盘：孙总（ZZ制造）¥85,000

输给谁了：竞品B（XX科技）

客户说的原因："你们价格太高了"
实际上：不是价格问题，是以下原因：

最早在哪里出了问题：
  □ 找错人 ✅（孙总不是最终决策者，他老板才是）
  □ 需求没搞对（没了解他们要的是MES不是AI质检）
  □ 方案不行 ✅（方案太通用，没有制造业专属内容）
  ☑ 价格太高（比竞品B贵15%，但价值差异没讲清楚）
  ☑ 跟进太慢 ✅（竞品B 2天内出方案，我们花5天）
  ☑ 信任不够（没有制造业案例，客户不敢第一个吃螃蟹）

如果重来一次会怎么做：
  1. 第一次见面就要求见决策者（孙总老板）
  2. 找一个制造业案例（哪怕借用合作伙伴的）
  3. 方案模板增加制造业专属模块
  4. 出方案速度从5天缩短到2天

还有机会吗：
  □ 3个月后重新接触（竞品B如果做不好，机会来了）
  → 设置日历提醒：10/1联系孙总问使用情况
```

❌ 不要做最低价！
├─ 最低价=评委怀疑你"偷工减料"
├─ 最低价=利润太薄甚至亏本
└─ 最低价=交付质量下降→影响后续口碑

✅ 做性价比最高的：
├─ 报价在中位数偏上（略高于均价）
├─ 技术方案拿最高分（弥补价格分差距）
├─ 案例和资质拿满分（差异化优势）
├─ 售后方案超预期（给评委"选你更放心"的理由）
└— 很多标书评分=技术分70%+价格分30%，技术远比价格重要
