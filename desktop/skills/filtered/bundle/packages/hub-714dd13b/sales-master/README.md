## 📌 一句话介绍

**Sales Master** 是一个覆盖销售全生命周期的 AI Skill，包含 **17 个 Phase、100+ 个实战场景、60+ 套可直接复制的话术模板**，并自带 **邮件自动化系统**（定时发送 / 生日提醒 / 合同到期预警 / 日报周报月报）。

不需要懂销售理论，遇到任何销售问题直接问，AI 给出**具体的话术、模板和行动方案**，复制就能用。

## ✨ 核心亮点

### 1. 话术可以直接复制使用

每个场景都有 **填好变量的完整话术**，不是"你要共情客户"这种正确的废话，而是：

```
「王总，贵不贵要看跟什么比。
跟竞品比，我们贵10%，但效果好50%。
跟不解决的损失比，这个投入3个月就回来了。
如果预算有压力，可以先做核心模块，XX元起步。」
```

### 2. 客户性格自适应

4 种性格类型，**不同性格用不同话术**：

| 性格 | 特征 | 话术风格 |
|------|------|---------|
| 🔴 支配型 | 结果导向、雷厉风行 | 开门见山，给数据给结论 |
| 🟡 表达型 | 爱社交、要面子 | 多互动多赞美，讲案例故事 |
| 🟢 亲和型 | 慢热、怕风险、重关系 | 温暖不催，给安全感 |
| 🔵 分析型 | 理性、要数据、怕出错 | 给数据给表格，讲ROI |

### 3. 邮件自动化系统

自带 Python 邮件系统，支持：

```bash
python email_automation.py init              # 初始化数据库+3个演示客户
python email_automation.py send --to 邮箱 --template birthday_wish  # 发生日邮件
python email_automation.py campaign --template product_promotion    # 群发营销
python email_automation.py check-dates       # 自动检查生日/合同到期
python email_automation.py work-report --period daily --send        # 日报发邮件
python email_automation.py scheduler         # 启动定时调度引擎
```

**11 个邮件模板**：生日祝福 / 合同续约 / 产品推广 / 节日问候 / 跟进提醒 / 逼单提醒 / 回款提醒 / 日报 / 周报 / 月报 / 客户回信通知

每封邮件 **自动追加公司签名**（从配置文件读取）。

### 4. 客户关键日期自动提醒

不用记客户生日、合同到期日——系统自动扫描，提前 7/30/60 天触发提醒邮件。

```
🎂 客户生日 → 提前7天发生日祝福
⏰ 合同到期 → 提前30/60天发续约提醒
💰 回款到期 → 提前7天发催款提醒
```

### 5. 真实演示数据

内置 **3 个完整客户档案**（SaaS 公司 CEO / 保险个人客户 / 制造厂老板），包含：
- 完整客户喜好档案（性格 / 沟通偏好 / 兴趣 / 家庭 / 饮食禁忌）
- 关键日期（生日 / 合同到期 / 续约窗口）
- 跟进时间线（8-10 条真实记录）
- 已填写的报价单 / 合同 / 保单

## 🚀 快速上手（3步）

### 第 1 步：安装

把 `sales-master/` 文件夹放到你的 AI Agent 的 skills 目录。

### 第 2 步：配置邮箱（可选）

```bash
cd sales-master/scripts/
cp email_config.example.yaml email_config.yaml
# 编辑 email_config.yaml，填入你的 SMTP 信息和公司信息
python email_automation.py init    # 初始化数据库
```

### 第 3 步：开始用

直接问任何销售问题：

```
"客户说太贵了怎么回？"
"加了客户微信第一句话怎么说？"
"合同快到期了怎么续约？"
"帮我给客户写生日祝福"
"怎么做销售周报？"
```

AI 会自动匹配对应 Phase，给出具体话术和行动方案。

## 💡 设计理念

1. **不是理论书，是工具箱** — 每个场景都有可直接复制的话术、模板、检查清单
2. **不是通用模板，是场景化方案** — 根据客户性格、行业、阶段给定制建议
3. **不只是文字，还有代码** — 自带邮件自动化系统，能实际执行（发邮件/定时/记录）
4. **不是一次性输出，是持续进化** — 经过 7 轮搜索→测试→优化迭代，覆盖 60+ 真实场景
5. **不替代人，是赋能人** — AI 给弹药，销售做决策
