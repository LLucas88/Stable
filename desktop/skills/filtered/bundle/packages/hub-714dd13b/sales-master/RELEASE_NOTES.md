# Sales-Pro v2.0.0 · 更新说明

## 📌 一句话介绍

**Sales-Pro** 是一个覆盖销售全生命周期的 AI Skill，从获客到复购、从线下陌拜到直播带货、从话术模板到邮件自动化，一个 Skill 搞定销售全链路。不需要懂销售理论，遇到任何销售问题直接问，AI 给出具体的话术、模板和行动方案，复制就能用。

## 🚀 快速上手（3步）

### 第 1 步：安装

把 `sales-master/` 文件夹放到你的 AI Agent 的 skills 目录。

### 第 2 步：配置邮箱（可选）

```bash
cd sales-master/scripts/
cp email_config.example.yaml email_config.yaml
# 编辑 email_config.yaml，填入你的 SMTP 信息和公司信息
pip install -r requirements.txt
python email_automation.py init
```

### 第 3 步：开始用

直接问任何销售问题：

```
"客户说太贵了怎么回？"
"加了客户微信第一句话怎么说？"
"合同快到期了怎么续约？"
"怎么做直播带货？"
"怎么给产品定价？"
```

## 💡 设计理念

1. **不是理论书，是工具箱** — 每个场景都有可直接复制的话术、模板、检查清单
2. **不是通用模板，是场景化方案** — 根据客户性格、行业、阶段给定制建议
3. **不只是文字，还有代码** — 自带邮件自动化系统，能实际执行（发邮件/定时/记录）
4. **不是一次性输出，是持续进化** — 经过模拟测试验证，覆盖80+真实场景
5. **不替代人，是赋能人** — AI 给弹药，销售做决策
