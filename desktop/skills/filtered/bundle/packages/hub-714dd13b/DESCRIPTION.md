# 💼 销售高手技能包

5 个核心技能，覆盖销售全流程：获客 → 沟通 → 谈判 → 成交 → 复购。

## 技能清单

| # | 技能 | 解决什么问题 |
|---|------|-------------|
| 1 | **客户开发与触达助手** | 去哪找客户？怎么加人/打电话/陌拜？ |
| 2 | **销售话术与成交技巧** | 见客户说什么？怎么报价？怎么逼单？ |
| 3 | **谈判与异议处理** | 客户嫌贵/考虑一下/比价格，怎么应对？ |
| 4 | **客户关系管理与复购** | 怎么维护老客户？怎么提高复购率？ |
| 5 | **销售跟进追踪器** | 客户太多记不住？Pipeline/周报/预测一键生成 |

## 安装方式

将 `sales-pro` 文件夹复制到 Hermes 的 skills 目录：

```bash
cp -r sales-pro ~/.hermes/skills/
```

## 使用示例

- "帮我写一个电话陌拜的话术，卖企业管理软件"
- "客户说太贵了怎么回？"
- "怎么提高老客户的复购率？"
- "帮我建一个客户跟进记录"
- "帮我写这周的销售周报"
- "怎么让客户帮我转介绍？"

## 适用行业

全行业通用：B2B/B2C/服务业/零售/地产/保险/教育/SaaS

## 📦 主Skill vs 子Skill

```
sales-pro/
├── sales-master/          ← ⭐ 主Skill（推荐安装这一个就够了）
│   └── 15+2 Phase 完整版，含所有参考文件+邮件系统+演示数据
│
├── cold-outreach/         ← 子Skill（主Skill Phase 2的独立版）
├── sales-scripts/         ← 子Skill（主Skill Phase 3-6的独立版）
├── negotiation/           ← 子Skill（主Skill Phase 6的独立版）
├── client-management/     ← 子Skill（主Skill Phase 8-10的独立版）
└── crm-tracker/           ← 子Skill（主Skill Phase 11的独立版）

怎么选？
├─ 完整体验 → 只装 sales-master（推荐）
├─ 只需某个环节 → 装对应子Skill
└─ 子Skill是主Skill的"精简独立版"，内容有重叠
```
