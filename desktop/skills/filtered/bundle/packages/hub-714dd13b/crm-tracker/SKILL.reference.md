# 销售跟进追踪器

好记性不如烂笔头。不记录 = 不存在。

## 什么时候用

- 客户太多，记不清每个聊到哪了
- 不知道这个月能签多少单
- 老板问销售进展，不知道怎么说
- 想复盘销售过程，找改进点

## 二、销售漏斗（Pipeline）

### 2.1 漏斗阶段

```
线索（Leads）
  ↓ 初次接触筛选
意向（Prospects）
  ↓ 需求确认
方案（Proposal）
  ↓ 报价/演示
谈判（Negotiation）
  ↓ 签约
成交（Won）

每个阶段的转化率参考：
线索 → 意向：30-50%
意向 → 方案：40-60%
方案 → 谈判：50-70%
谈判 → 成交：60-80%

整体转化率：线索 → 成交 ≈ 5-15%
```

## 四、成交预测方法

```
加权预测法：

每个客户的价值 = 预计金额 × 成交概率

示例：
客户A：¥10万 × 80% = ¥8万（谈判阶段）
客户B：¥5万 × 50% = ¥2.5万（方案阶段）
客户C：¥20万 × 30% = ¥6万（意向阶段）

预测总成交 = ¥8万 + ¥2.5万 + ¥6万 = ¥16.5万

概率参考：
├─ 谈判阶段：70-90%
├─ 方案阶段：40-60%
├─ 意向阶段：20-40%
├─ 初次接触：5-20%
└─ 线索阶段：1-5%
```

## 五、快速生成销售工具

当用户需要管理销售时：

1. **新建客户卡** — "帮我建一个客户记录，[客户信息]"
   → 生成完整的客户信息卡

2. **更新Pipeline** — "帮我看一下当前的销售漏斗"
   → 汇总所有客户，生成Pipeline总览

3. **生成周报** — "帮我写这周的销售周报"
   → 根据跟进记录生成周报

4. **成交预测** — "帮我预测这个月能签多少"
   → 加权预测法计算

5. **跟进提醒** — "哪些客户该跟进了"
   → 扫描客户记录，找出超期未跟进的客户
