# 客户关系管理与复购

开发一个新客户的成本是维护老客户的5-10倍。会卖的人赚一次，会管的人赚一辈子。

## 什么时候用

- 不知道怎么维护老客户
- 客户买完一次就不来了
- 想提高复购率和客单价
- 想让老客户帮忙转介绍

---

## 一、客户分级管理

### 1.1 客户分级模型

| 级别 | 定义 | 贡献 | 维护策略 |
|------|------|------|---------|
| **A级（VIP）** | 核心大客户，复购频次高 | 80%收入 | 1对1专属服务，定期拜访 |
| **B级（潜力）** | 有消费力但频次不够 | 15%收入 | 定期触达，引导升级 |
| **C级（普通）** | 偶尔消费，金额不大 | 5%收入 | 朋友圈/社群维护 |
| **D级（沉睡）** | 曾经消费但很久没来了 | 0 | 唤醒活动/节日问候 |

### 1.2 客户信息记录模板

```
每位客户记录以下信息：

基础信息：
├─ 姓名/称呼
├─ 公司/职位
├─ 联系方式
└─ 生日/纪念日

业务信息：
├─ 首次成交时间
├─ 累计消费金额
├─ 最近一次消费时间
├─ 常买产品/服务
└─ 客户级别（A/B/C/D）

偏好信息：
├─ 沟通偏好（电话/微信/面谈）
├─ 决策方式（自己决定/需要商量）
├─ 关注点（价格/质量/服务/品牌）
├─ 性格特点（直接/温和/理性/感性）
└─ 兴趣爱好

跟进记录：
├─ 最近一次联系时间和内容
├─ 下次跟进计划
└─ 待解决的问题
```

## 二、客户维护节奏

### 2.1 按级别维护

```
A级VIP客户：
├─ 每周至少1次互动
├─ 每月1次面谈/电话
├─ 重要节日专属礼物
├─ 新品/优惠优先通知
└─ 遇到问题第一时间处理

B级潜力客户：
├─ 每两周1次互动
├─ 每月1次微信深度沟通
├─ 节日问候
├─ 推荐适合的升级方案
└─ 定期分享行业资讯

C级普通客户：
├─ 每月1次朋友圈互动
├─ 节日群发（带个性化称呼）
├─ 大促活动通知
└─ 公众号/社群内容触达

D级沉睡客户：
├─ 每季度1次唤醒触达
├─ 专属回归优惠
├─ 节日问候
└─ 生日问候
```

### 2.2 日常维护技巧

```
朋友圈互动（每天10分钟）：
├─ 给客户朋友圈点赞（不是每条都点，选有意义的）
├─ 偶尔评论（走心的，不是"赞""好看"）
└─ 分享对客户有价值的内容（别只发广告）

微信私聊节奏：
├─ 不要每次都聊业务
├─ 看到对客户有用的信息主动分享
├─ 看到客户朋友圈有动态，适时私聊
└─ 记住客户提过的事，下次主动问进展

节日问候：
├─ 不要群发！不要群发！不要群发！
├─ 每条单独发，带对方名字
├─ 内容简短真诚
└─ 重要的客户可以打电话/寄礼物
```

## 三、复购策略

### 3.1 提高复购的6个方法

```
方法1：会员/积分体系
→ 消费越多折扣越大/积分越多
→ 让客户觉得"继续在你这买更划算"

方法2：定期提醒
→ "王总，上次您买的XX快用完了吧？最近正好有活动"
→ 在客户可能需要补货/续费的时间点提醒

方法3：搭配推荐
→ "您上次买了A，搭配B效果更好，B现在有组合优惠"
→ 关联销售，提高客单价

方法4：专属优惠
→ "老客户专享价""会员日折扣"
→ 让客户觉得被优待

方法5：升级引导
→ "您现在用的是基础版，升级到专业版能___"
→ 向上销售

方法6：服务绑定
→ 提供持续的服务（售后/培训/咨询）
→ 客户因为依赖你的服务而持续合作
```

### 3.2 复购话术模板

```
场景1：产品快用完/服务快到期
"王总，您的[产品/服务]还有XX天到期，
提前续费现在有老客户专属优惠，能省XX元，
帮您续上？"

场景2：有新品/新方案
"王总，我们新出了一个[产品/功能]，
跟您现在用的搭配起来效果特别好，
给您预留了一个体验名额，要不要试试？"

场景3：节日/活动促复购
"王总，年底回馈老客户，
您常买的XX现在买X送X，
帮您备上？"

场景4：顺便提一嘴（不经意型）
"对了王总，上次您说[需求]，
我们刚好出了个方案能解决这个问题，
下次见面我给您详细说说？"
```

## 四、客户流失挽回

### 4.1 流失预警信号

```
以下信号出现2个以上，说明客户可能在流失：

⚠️ 回消息越来越慢/越来越短
⚠️ 不再主动咨询/下单
⚠️ 朋友圈不再互动
⚠️ 投诉增多/要求增多
⚠️ 提到竞品/比较价格
⚠️ 取消续费/减少采购量
⚠️ 找各种理由推脱见面
```

### 4.2 流失挽回话术

```
场景1：客户很久没联系了（30天+）
"王总好久不见！最近怎么样？
上次您[提到的事]后来怎么样了？
有空一起喝个茶聊聊~"
→ 先重新建立联系，不要一上来就卖东西

场景2：客户转向竞品
"王总，听说您最近选了[竞品]，
用着还好吗？
不管怎样，咱们关系在，
有任何问题随时找我~"
→ 大度，保持关系，等竞品出问题时你还有机会

场景3：客户因为不满离开
"王总，上次的事是我们没做好，
我已经[改进措施]了，
希望您给我们一次弥补的机会，
这次我亲自跟进，一定让您满意"
→ 真诚道歉 + 具体改进 + 承诺

场景4：回归优惠
"王总，好久不见！刚好我们最近有个活动，
老客户回归有专属优惠，想到您了，
不管买不买，先跟您说一声~"
```

## 五、快速生成客户维护方案

当用户说"怎么维护客户"或"怎么提高复购"时：

1. 问：什么行业？客单价？客户类型（B2B/B2C）？目前有多少客户？
2. 帮客户做分级（A/B/C/D）
3. 制定维护节奏（按级别的触达计划）
4. 推荐适合的复购策略
5. 给出具体的维护话术模板
