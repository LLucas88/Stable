# 销售话术与成交技巧

销售是一场有节奏的对话。每个环节都有对应的话术和技巧。

## 什么时候用

- 见客户不知道说什么
- 聊了很多但就是不成交
- 报完价客户就没音了
- 不知道怎么逼单/促成交

---

## 一、销售对话6步法

```
步骤1：开场破冰 → 建立好感
步骤2：需求挖掘 → 找到痛点
步骤3：产品介绍 → 对接需求
步骤4：处理异议 → 消除顾虑
步骤5：报价谈价 → 达成共识
步骤6：促单成交 → 签单收款
```

---

## 二、开场破冰话术

### 2.1 面谈开场

```
场景A：对方办公室
"王总，您办公室这[摆设/字画/绿植]很有品味啊，
看得出来您是个[评价]的人~"

场景B：约咖啡/茶
"感谢王总抽时间，今天主要是想跟您交流一下，
不着急聊业务，咱们先随便聊聊~"

场景C：展会/活动
"王总您好，我是[公司]的[名字]，
之前一直关注你们[产品/项目]，做得真好，
今天终于见到本人了~"
```

### 2.2 破冰话题选择

```
✅ 好话题：
- 对方的行业/公司近况
- 共同认识的人
- 最近的热点新闻
- 对方的社交媒体动态
- 天气/交通（实在找不到话题时）

❌ 禁忌话题：
- 政治/宗教
- 个人隐私（收入/年龄）
- 负面新闻
- 竞品公司的坏话
```

## 三、需求挖掘（SPIN提问法）

```
S - 现状问题（了解现状）
"王总，目前你们[业务/流程]是怎么做的？"
"这个环节通常花多长时间？"

P - 痛点问题（找到问题）
"在做[某件事]的时候，有没有遇到过什么困难？"
"现在这个方案，您觉得有什么不满意的地方？"

I - 影响问题（放大痛点）
"这个问题如果不解决，对[业务/效率/成本]有多大影响？"
"一年下来因为这个损失大概有多少？"

N - 需求问题（引导需求）
"如果有个方案能解决[痛点]，帮您[节省XX/提高XX]，
您会感兴趣吗？"
"理想的情况下，您希望达到什么效果？"

💡 核心：让客户自己说出需求和痛点，比你直接说更有说服力
```

## 四、产品介绍（FABE法则）

```
F - 特性（Feature）
"我们这个方案的特点是___"

A - 优势（Advantage）
"跟其他方案相比，我们的优势是___"

B - 利益（Benefit）
"对您来说，最直接的好处就是___"

E - 证据（Evidence）
"这是我们帮[客户名]做的案例，
用之前是___，用之后变成了___"

话术示例：
"王总，我们这个系统（F）用的是云端架构，
不用您自己买服务器，（A）比传统方案便宜60%，
（B）帮您一年至少省20万，
（E）你看XX公司用了我们系统后，成本从50万降到了30万。"
```

## 五、报价与谈价

### 5.1 报价时机

```
❌ 错误：一上来就报价
→ 客户还没认识到价值，觉得贵

✅ 正确：价值塑造完再报价
→ 先让客户觉得值，再告诉他价格

报价前的铺垫：
"王总，按您的需求，常规方案大概要XX万，
但根据您的情况，我给您做了一个定制方案，
效果更好，价格只要___"
```

### 5.2 报价技巧

```
锚定报价法：
"市场上同类方案一般在XX-XX万之间，
我们的方案是XX万，性价比非常高"

拆分报价法：
"总价是XX万，拆开来看：
系统费XX万（均摊到每天才XX元）
实施费XX万（一次性）
培训费XX元（可以免费送您）
平均下来每天才XX元，比招一个人还便宜"

对比报价法：
"如果你们自己做，需要招XX个人，一年人工成本XX万
用我们的方案，一年只要XX万，还包维护"
```

### 5.3 应对"太贵了"

```
客户："太贵了"

回复A（拆解法）：
"王总，我理解您的感受，乍一看确实不便宜。
但您算一下，这个方案能用3年，
均摊下来每天才XX元，
比一杯咖啡还便宜"

回复B（对比法）：
"确实不便宜，但您对比一下，
如果不解决这个问题，
每年因为[痛点]损失的成本是这个的3倍"

回复C（价值法）：
"贵是因为确实值这个价，
我们帮XX公司做了之后，他们第一年就多赚了XX万，
这个投入3个月就回本了"

回复D（选项法）：
"如果预算有限，我们可以先做核心模块，
大概XX万就能搞定基础版，后续再逐步升级"
```

## 六、逼单与成交

### 6.1 逼单时机

```
逼单信号（客户出现以下表现就可以逼单了）：
├─ 开始问细节（"售后怎么弄""什么时候能开始"）
├─ 开始讲价（"能不能便宜点"）
├─ 问别人的情况（"XX公司也用了？效果怎么样"）
├─ 开始算时间（"多久能上线""什么时候能发货"）
├─ 拿竞品对比（"XX家的报价才XX"）
└─ 询问付款方式（"怎么付款""能开发票吗"）
```

### 6.2 逼单话术

```
方法1：二选一法
"王总，您看是选标准版还是旗舰版？"
（不要问"要不要买"，问"买哪个"）

方法2：限时法
"王总，这个价格是活动价，月底就恢复了，
现在定能省XX元"

方法3：稀缺法
"这个方案我们这个月只剩3个名额了，
先到先得"

方法4：假设成交法
"那王总，我们就按这个方案来，
您看下周二还是周三安排实施比较好？"

方法5：风险逆转法
"王总，您先试试，不满意我们全额退款，
您没有任何风险"

方法6：从众法
"您这个行业的XX公司、XX公司都选了我们，
效果都很好"

方法7：最后一步法
"王总，方案您也看了，效果也确认了，
咱们就差签个合同了，我把合同发您？"
```

### 6.3 成交后的关键动作

```
签单后别急着走！

1️⃣ 再次确认关键信息
"王总，我确认一下：方案是XX，价格XX，交付时间XX，对吧？"

2️⃣ 告知下一步
"接下来我会安排XX，预计XX时间完成，中间有问题随时联系我"

3️⃣ 设置下次接触点
"XX天后我来跟进一下使用情况"

4️⃣ 表达感谢
"感谢王总信任，一定不会让您失望！"
```

## 七、快速生成销售话术

当用户说"帮我写销售话术"时：

1. 问：卖什么产品/服务？目标客户？客单价？销售方式（面谈/电话/微信）？
2. 生成完整话术链：开场 → 需求挖掘 → 产品介绍 → 报价 → 逼单
3. 附带常见异议的处理话术
4. 给出销售注意事项
