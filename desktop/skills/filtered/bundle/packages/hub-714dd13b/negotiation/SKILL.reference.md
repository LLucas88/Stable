# 谈判与异议处理

客户说不，才是销售的开始。

## 什么时候用

- 客户说"太贵了"/"考虑一下"/"不需要"
- 谈价格时不知道怎么让步
- 被客户压价压得没利润
- 谈判陷入僵局不知道怎么破

---

## 一、8大常见异议处理

### 异议1："太贵了"

```
真相：90%的情况不是真觉得贵，是觉得不值

处理步骤：
1. 共情："我理解，确实是一笔投入"
2. 拆解："您算一下，用3年，均摊到每天才XX元"
3. 对比："不解决这个问题，每年损失是XX"
4. 案例："XX公司用了之后，3个月就回本了"
5. 选项："如果预算有限，可以先做基础版，XX万起步"

万能回复：
"王总，贵不贵要看跟什么比。
跟[竞品]比，我们贵10%，但效果好50%。
跟[不解决的损失]比，这个投入3个月就回来了。"
```

### 异议2："考虑一下"

```
真相：要么是借口（不想买），要么有顾虑（不敢买）

处理方式：
"没问题，考虑是应该的。
不过我想确认一下，您主要是在考虑哪方面？
是价格、效果、还是时间安排？
这样我也能帮您更好地分析一下"

→ 把模糊的"考虑"变成具体的问题
→ 然后逐个解决
```

### 异议3："不需要"

```
真相：还没意识到自己需要

处理方式：
"理解，很多客户一开始也这么说。
但我好奇的是，你们现在[相关业务]是怎么做的？
效果满意吗？"

→ 用提问引导客户意识到现状的问题
→ 不要反驳，用提问让他自己发现
```

### 异议4："已经有供应商了"

```
真相：有供应商不代表满意，只是懒得换

处理方式：
"那挺好的，说明您对这个确实有需求。
您跟现在的供应商合作多久了？
各方面还满意吗？有没有觉得可以更好的地方？"

→ 找到现有供应商的薄弱环节
→ 不要说竞品坏话，让客户自己说
→ "那我们有空可以聊聊，不一定要换，多一个选择也不错"
```

### 异议5："预算不够"

```
真相：要么真没预算，要么优先级不够

处理方式A（真没预算）：
"理解，那咱们换个思路。
先用基础版解决最核心的问题，XX元就能起步。
等见效了再升级，这样压力小很多"

处理方式B（优先级不够）：
"理解，预算确实要花在刀刃上。
不过您算一下，这个问题拖一年，
损失的成本是这个方案的X倍。
如果我能帮您3个月见效，值不值得优先安排？"
```

### 异议6："我要跟领导/合伙人商量"

```
真相：要么是拖延借口，要么真需要审批

处理方式：
"没问题，那您看需要我准备什么材料，
帮您跟领导汇报更方便？
要不这样，我出一个简单的方案对比表，
您直接拿给领导看，一目了然"

→ 主动帮客户准备向上汇报的材料
→ 甚至可以提议一起跟领导开会
```

### 异议7："别家更便宜"

```
真相：在试探你的底线

处理方式：
"王总，便宜的方案确实有，但您要看清楚3件事：
1. 功能一样吗？（很多低价是阉割版）
2. 服务一样吗？（出了问题有人管吗）
3. 能用多久？（便宜但用不了半年就要换）

我建议您不要只看价格，看整体性价比。
我们贵一点，是因为[差异化价值]。"

→ 不打价格战，打价值战
```

### 异议8："我先试试免费的"

```
真相：对你还不够信任

处理方式：
"可以的，我们正好有免费试用期。
不过我建议您试的时候重点关注这3个方面：___
这样您能更准确地判断适不适合。

试用期间有任何问题随时找我，
我帮您做配置和答疑，不额外收费"
```

## 二、价格谈判策略

### 2.1 谈判前准备

```
谈判前必须明确的4个数字：
1. 报价（第一次报的价格）
2. 目标价（你真正想卖的价格）
3. 底线价（低于这个就不做了）
4. 竞品价（对方可能拿来压你的价格）

⚠️ 报价 > 目标价 > 底线价
⚠️ 让步空间 = 报价 - 底线价
```

### 2.2 让步原则

```
原则1：永远不要免费让步
客户："便宜5000"
你："可以，不过你这边也要[签2年约/预付全款/加个模块]"
→ 用条件交换条件

原则2：让步幅度越来越小
第一次让 10% → 第二次让 5% → 第三次让 2%
→ 让客户觉得已经挤到底了

原则3：让步要显得很困难
"这个价格我需要请示一下领导..."
"这个已经是破例了，其他客户都没有这个价"
→ 让客户觉得自己赚到了

原则4：每次让步都要有回报
"我可以给您优惠XX，但需要您[签长期合同/全款/转介绍]"
→ 永远是交换，不是单方面退让
```

### 2.3 价格僵局破局法

```
方法1：转移焦点
"王总，价格的事咱们先放放，
您先看看方案本身有没有问题？
如果方案满意，价格好商量"

方法2：改变条件
"如果价格实在谈不拢，
我们可以换一种合作方式：
按效果付费/分期付款/先小范围试用"

方法3：制造紧迫感
"这个价格我只能保留到本周五，
下周就要调价了"

方法4：引入决策者
"要不这样，我把方案和价格报给我们总监，
看看能不能给您一个更好的方案？"

方法5：切割法
"把价格拆开来看，
这个功能值XX，这个值XX，
您觉得哪个部分可以不要？"
```

## 三、谈判心理学技巧

```
1. 沉默是金
→ 报完价后闭嘴，让客户先说话
→ 谁先开口谁先让步

2. 锚定效应
→ 先报一个偏高的价格锚定客户预期
→ 然后在"让步"中到达你的目标价

3. 黑脸白脸
→ "我愿意给这个价，但我老板不同意"
→ 让客户觉得你已经尽力了

4. 框架效应
→ "每天只要XX元"（而不是"总价XX万"）
→ "能帮您省XX万"（而不是"要花XX万"）

5. 互惠原则
→ 先给客户一些免费的（方案/建议/体验）
→ 客户会觉得"欠你一个人情"
```

## 四、快速生成异议处理

当用户说"客户说XX，怎么回"时：

1. 分析客户异议背后的真实原因
2. 给出2-3种回复方案
3. 附带注意事项和后续话术
4. 如果涉及价格谈判，给出让步策略
