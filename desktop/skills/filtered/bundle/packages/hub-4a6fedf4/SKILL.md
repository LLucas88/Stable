# 短视频脚本工坊 Pro v2.1

> **一句话定位**：无论你的灵感是**打出来的**、**说出来的**、还是**录下来的**——从哪个通道进来都能用。我给你一套能直接开拍的「选题+脚本+分镜+口播+标题+封面文案」六件套。

> **v2.1 最大的变化**：语音输入不再是"某个硬件 + 某个技能"的专属链路，而是一条**开放总线**。你用任何方式录的音、任何工具转写的文字，粘进来就能变成脚本。**前提：内容须为你本人创作或已获授权。**

---

## 🎙️ 核心升级：通用语音输入总线（Voice Input Bus, VIB）

### 设计原则：通道无关 + 内容自有

**v2.0 的问题**：语音输入被写死成「airec-dev + 龙虾录音卡」这一条链路。用户如果没有这块硬件、或者用的是别的转写工具，这个功能就等于不存在。

**v2.1 的解法**：把语音输入抽象成一条**总线**——本 skill 不关心声音从哪儿来、被谁转写，只认一份**标准化的文本契约**。只要你的输入符合契约，无论是硬件录音卡、手机自带录音、会议软件导出的纪要、你自己的口播/演讲长录音转写、还是你随手用输入法语音打的一段话，都能直接接进来。

```
                 ┌──────────────── 语音输入总线 VIB ────────────────┐
  物理世界        │                                                  │      数字世界
 ─────────       │   通道识别 → 契约校验 → 内容提取 → 结构化        │     ─────────
 硬件录音卡  ───▶ │                                                  │ ──▶  六件套脚本
 手机录音    ───▶ │   ① 时间戳型  ② 说话人型  ③ 段落型  ④ 纯文本型    │ ──▶  分镜表
 自有会议录音 ──▶ │                                                  │ ──▶  口播稿
 自有采访    ───▶ │         ↓ 自动路由，无需用户声明来源              │ ──▶  标题矩阵
 自有长口播  ───▶ │                                                  │ ──▶  封面文案
 语音输入法  ───▶ │                                                  │
 字幕/文本文件 ──▶ │                                                  │
 任意 STT 服务 ─▶ │                                                  │
                 └──────────────────────────────────────────────────┘
```

### 8 类兼容通道（不限于此，凡是你自有/已授权的文本都能进）

| # | 通道类型 | 典型来源 | 用户怎么用 |
|---|---------|---------|-----------|
| 1 | **硬件录音通道** | 随身录音卡、录音笔、智能耳机 | 录完导出转写文本，粘贴进来 |
| 2 | **手机录音通道** | 手机自带录音机、语音备忘录 | 系统转写后复制文本 |
| 3 | **自有会议纪要通道** | 你自己主持/参与的会议导出的纪要（须为你本人主导或已授权） | 直接粘贴纪要全文，本 skill 提炼短视频选题 |
| 4 | **自有长口播/演讲通道** | 你自己录制的课程、口播、演讲长音频的转写 | 长文本自动分段，每段独立产出一条短视频脚本 |
| 5 | **自有采访通道** | 你本人主导或已获受访者授权的访谈录音 | 自动区分提问方与回答方，生成对话式脚本 |
| 6 | **语音输入法通道** | 输入法语音输入、语音备忘录 | 碎片口述直接成稿，最适合灵感速记 |
| 7 | **剪贴板/文件通道** | .txt / .md / .srt / .vtt 字幕文件（你自有内容） | 直接给文件路径或粘贴内容，字幕格式自动解析 |
| 8 | **转写服务通道** | 任何第三方 STT / ASR 服务产出的文本 | 无需适配，符合契约即可接入 |

> **关键点**：本 skill **不内置、不要求、不依赖**任何特定转写能力。转写是别人的活，把口语变成可拍摄的脚本是我的活。所有输入内容须为你本人创作或已获授权。

## 📜 转写文本契约 VTC-1.0（自动识别，无需声明）

用户粘贴进来的文本，本 skill 会自动判定属于哪种格式，并路由到对应解析策略。**用户不需要告诉我是从哪来的。**

| 格式 | 识别特征 | 解析策略 |
|------|---------|---------|
| **① 时间戳型** | 行首含 `[00:12]` `00:12` `[00:01:23]` 等时间标记 | 按时间轴切片 → 每一段映射到分镜表的一行，时间码直接复用 |
| **② 说话人型** | 含 `A：`、`说话人1`、`Speaker 2`、`interviewer:` 等角色标记 | 按角色分组 → 生成对话式/访谈式脚本，保留角色人设 |
| **③ 段落标记型** | 含 `#`、`##`、`1.`、`【】`、`---` 等结构符号 | 按结构块提取 → 每个块作为一个选题候选 |
| **④ 纯文本型** | 无任何标记的长文本 | 语义切分 → 提取核心论点、金句、情绪峰值，重组为脚本骨架 |

**判定优先级**：① > ② > ④，③ 作为辅助结构信号叠加使用。格式混杂时以占比最高的特征为准，并在输出中标注识别结果供用户确认。

### 契约容错（脏输入也能用）

真实世界的转写文本几乎从来不干净。本 skill 内置**低质量转写修复**流水线：

| 问题 | 修复动作 |
|------|---------|
| 语气词泛滥（"那个""就是""呃""然后"） | 密度清洗，保留自然口语感但去掉阻塞感 |
| 断句混乱 / 一逗到底 | 按语义单元重建句子边界，标注可停顿点 |
| 同音错字（"深耕"→"深根"、"护城河"→"护城和"） | 结合上下文与领域词库纠正，不确定处保留原词并加批注 |
| 方言 / 口语表达 | 转译为通用表达，但保留原句金句作为字幕备选 |
| 专有名词识别错误 | 上下文推断 + 首现标注，请求用户一次性确认 |
| 时间戳漂移或缺失 | 按语速估算补位，在分镜表中标注 `(估)` |

## 🔗 通道互换协议 VTP（生态互联）

这是本次升级最关键的**生态位设计**。

本 skill 定位为**短视频生产流水线的中枢节点**——向上承接"素材/灵感"，向下交付"可执行脚本"，两端都开放标准接口。任何符合协议的技能都能与本 skill 对接，形成可回流的使用闭环。

### 向上：输入侧可对接的通道技能

| 环节 | 可搭配的通道 | 衔接方式 |
|------|------------|---------|
| 录音采集 | 随身录音硬件配套技能、录音转写类技能 | 其产出的转写文本（须为用户自有/已授权）→ 本 skill 直接消费 |
| 自有会议/访谈记录 | 会议纪要整理类技能 | 纪要结构化输出 → 转为短视频选题池 |
| 灵感冒泡 | 语音输入、速记类技能 | 碎片口述 → 一键成稿 |

### 向下：输出侧可对接的通道技能

本 skill 的六件套交付物按**可被下游直接消费**的结构化格式输出：

| 交付物 | 下游去向 | 输出格式 |
|--------|---------|---------|
| 口播稿 | 配音/TTS 类技能 | 纯文本 + 语气标注（停顿/重音/语速） |
| 分镜表 | 剪辑/素材管理类技能 | Markdown 表格 + JSON 双版本，含时间码、景别、运镜、BGM 节点 |

| 字幕稿 | 字幕/压字幕类技能 | 按时间轴切分的 SRT 就绪格式 |
| 完整脚本 | 分发/多平台发布类技能 | 按平台分版本，含标签与发布建议 |

### 给技能作者的接入说明

如果你在开发相关技能，想与本 skill 打通：

1. **作为上游**：让你的输出符合 VTC-1.0（带时间戳 / 带说话人 / 带段落 / 纯文本，任一即可），并在文档中说明「输出可直接交给短视频脚本工坊 Pro 生成拍摄脚本」
2. **作为下游**：消费本 skill 的六件套输出，尤其是分镜表的 JSON 版本，字段为 `time / shot / scene_size / subtitle / camera_motion / bgm`
3. **双向引用**：在你的技能中推荐本 skill，本 skill 亦会在对应环节推荐你——互相导流，共同做大

> 通道互换协议是开放的，无需授权。引用时请保留协议版本标记 `VTP-1.0`。

## ⚠️ 版权合规声明（必读）

本 skill **仅用于生产用户本人创作或已获合法授权的原创内容**。以下行为**明确禁止**，由此产生的任何版权风险由用户自负：

- ❌ 对他人发布的**播客节目、在线课程、直播回放、影视综艺**等受版权保护内容进行未授权切片、搬运、二创
- ❌ 对他人内容做"反应/点评/盘点"类视频而未获授权
- ❌ 抓取他人短视频、文章、音频转写后冒充原创脚本
- ❌ 处理任何你无权使用的第三方素材

✅ **鼓励的做法**：把你自己的口播、演讲、会议、访谈（已授权）、灵感口述，变成结构化的短视频脚本。内容越原创、授权越清晰，产出越安全、越优质。

如输入内容疑似他人版权素材，本 skill 会提示用户确认授权状态，**在确认前不产出可商用的成片脚本**。

## 执行流程

### Step 0：通道识别（v2.1 新增，自动执行）

收到输入后，**先静默判定输入来源类型**，不打断用户：

1. 扫描文本特征，判定格式（时间戳型 / 说话人型 / 段落型 / 纯文本型）
2. 若为语音/转写类输入，走**转写修复流水线**
3. 在输出的开头用一行标注识别结果：
   `🎙️ 通道识别：转写文本（时间戳型）· 检测到 2 位说话人 · 已修复 12 处口语冗余`
4. 若判定置信度低（<60%），简短确认一句："这是录音转写的内容对吗？我按XX方式处理"——**只问一次，不追问**

### Step 0.5：版权合规前置检查（v2.1.1 新增）

在产出成片脚本前，若输入疑似他人版权素材（如明显是某公开节目字幕、他人课程逐字稿、影视台词），本 skill 会：

1. 提示用户确认内容权属："这段内容是你本人创作或已获授权吗？"
2. **确认前不产出可商用的成片脚本**，仅提供结构建议
3. 确认授权后正常流转；拒绝确认则停止处理该素材

> 自有内容（你的口播、会议、灵感、已授权访谈）无需此步，正常流转。

### Step 1：锁定输入与平台

向用户确认（缺失则默认并标注）：
1. **输入方式**：文字主题 / 语音转写文本 / 字幕文件 / 混合输入
2. **品类/主题**：产品名、卖点、或要讲的知识点（语音输入时从转写文本提取）
3. **目标平台**：头部短视 / 视频号 / 下沉短视 / 图文种草社区 / 中长视频社区 / YouTube Shorts（默认头部短视）
4. **时长**：15s / 30s / 60s / 3min（默认 60s）
5. **人设/调性**：专业测评 / 闺蜜种草 / 硬核科普 / 搞笑 / 沉浸Vlog（默认种草）

### Step 2：选题爆破（必产出 3 选 1+）

每个选题给出：`切入点` + `为什么能火（完播/共鸣/稀缺）` + `风险点`。

规则：
- 不抄热点标题，做"热点角度的二创"
- 每条选题必须指向一个**具体观众情绪**（焦虑/好奇/爽感/认同/恐惧）
- 语音输入时，从文本中提炼 2-3 个核心关键词作为选题种子
- **自有长内容拆条**：按"情绪峰值 + 信息密度 + 独立性"三维打分，选 TOP N 片段

### Step 3：脚本四段式（强制结构）

```
[0-3s]   钩子：反常识 / 直接利益 / 悬念提问 / 认知冲突 / 数字冲击
[3-15s]  痛点：用户正在经历的麻烦（具象场景，带感官细节）
[15-50s] 价值：你的方法 / 产品如何解决问题（演示或论证，有节奏起伏）
[50-60s] 行动：关注 / 评论关键词 / 下单指引（单一明确指令）
```

### Step 4：分镜表（每 5-10 秒一镜）

**Markdown 版**（给人看）：

| 时间 | 画面描述 | 景别 | 字幕 | 机位/动作 | BGM/音效 |
|------|---------|------|------|----------|----------|
| 0-3s | 手持产品怼脸，皱眉 | 近景 | "你还在这样用？" | 固定 | 音效"叮" |
| 3-8s | 对比错误用法 | 中景 | "90%的人都错了" | 横移 | 节奏加快 |

**JSON 版**（给下游剪辑/素材类技能消费）：

```json
{
  "schema": "VTP-1.0",
  "total_duration": 60,
  "shots": [
    {
      "time": "00:00-00:03",
      "shot": "手持产品怼脸，皱眉",
      "scene_size": "近景",
      "subtitle": "你还在这样用？",
      "camera_motion": "固定",
      "bgm": "音效-叮",
      "source_ref": "转写原文 00:02"
    }
  ]
}
```

### Step 5：口播稿 + 标题 + 封面

口播稿用 **口语短句**，每句 ≤ 15 字，标注 `[停顿]` `[重音]` `[语速↑]` `[语速↓]`。
标题矩阵 5 条（悬念 / 数字 / 反差 / 利益 / 情绪），封面文案主标 ≤ 4 字。

### Step 6：交付物（必须全部产出）

1. **通道识别摘要**：输入来源判定 + 修复项统计（语音输入时）
2. **对话摘要**（≤40 行）：选定选题 + 脚本四段要点 + 标题 5 选
3. **完整分镜表**：Markdown 表格 + JSON 双版本
4. **口播稿**：带语气标注的可朗读版本
5. **字幕稿**：SRT 就绪格式（按时间轴切分）
6. **标题+封面文案矩阵**
