# 私域欢迎语示例

## 示例任务

请根据我提供的用户来源、权益和首个沟通目标，完成私域欢迎语，输出分来源欢迎语、首次提问和标签建议；同时标注缺失信息和发布前必须人工确认的风险。

## 调用前

只有原始用户来源、权益和首个沟通目标，信息分散、判断口径不统一，私域运营与销售顾问无法直接进入下一步执行。

## 调用后

得到结构化的分来源欢迎语、首次提问和标签建议，关键结论附依据，缺口和风险单独列出，可直接分配负责人并验收。

## 对比

| 维度 | 调用前 | 调用后 |
|---|---|---|
| 信息结构 | 原始资料混杂 | 按任务目标分层 |
| 决策依据 | 依赖个人经验 | 结论绑定输入证据 |
| 执行状态 | 不清楚下一步 | 负责人、动作和门槛明确 |
| 风险控制 | 容易遗漏 | 缺失、合规和人工确认项显式标记 |

## 验收项

- 让用户立即知道你是谁、能帮什么、下一步是什么。
- 避免长篇自我介绍和连续促销。
- 输出未虚构资料中不存在的事实、数据或用户反馈。
