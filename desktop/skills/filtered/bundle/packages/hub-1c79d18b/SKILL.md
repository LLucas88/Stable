# 私域欢迎语｜郭亿易

把用户来源、权益和首个沟通目标转换为分来源欢迎语、首次提问和标签建议。

## 工作流程

1. 识别客户阶段：围绕“让用户立即知道你是谁、能帮什么、下一步是什么”处理，不扩大到无关任务。
2. 核对事实与权限：以用户提供的用户来源、权益和首个沟通目标为事实边界。
3. 生成可发送回应：形成分来源欢迎语、首次提问和标签建议中的对应部分。
4. 记录标签与后续动作：使用“避免长篇自我介绍和连续促销”作为最终门槛。

## 输入最低要求

- 接收：用户来源、权益和首个沟通目标。
- 明确目标平台、时间范围、数量或格式；缺失时列出假设，不静默补造事实。
- 对个人信息、订单信息、商业数据和未公开资料执行最小披露。

## 输出合同

- 首段先给可执行结论，再给分来源欢迎语、首次提问和标签建议。
- 每个判断附输入证据、来源位置或“待确认”标记。
- 同时列出阻断项、风险项和下一步负责人；不把建议伪装成已完成动作。

## 质量门槛

- 让用户立即知道你是谁、能帮什么、下一步是什么。
- 避免长篇自我介绍和连续促销。
- 不复制第三方 Skill 的文字、代码或品牌；只解决本 Skill 声明的中文垂直任务。
