# 内部操作手册

## 公众号阅读高峰时段
- 早高峰：7:30-9:00（通勤阅读）
- 午休：12:00-13:30（午间浏览）
- 晚高峰：18:30-22:00（晚间黄金档，互动最高）
- 周末上午：10:00-12:00（周末休闲阅读）

## 视频号发布最佳时间
- 工作日：12:00-13:00 / 18:00-20:00
- 周末：11:00-14:00 / 17:00-20:00

## 公众号排版黄金参数
- 正文字号：15px-16px
- 行间距：1.75-2倍
- 段间距：1行空行
- 页边距：10-15px
- 主色：品牌色（不超过3种颜色）

## 视频号完播率提升技巧
- 前3秒必须有信息增量或情绪钩子
- BGM配合情绪曲线（前奏→高潮→收尾）
- 字幕位置在画面下方1/3处，字体够大
- 每3-5秒一次画面切换或信息更新
