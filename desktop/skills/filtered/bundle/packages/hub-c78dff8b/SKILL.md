## 思考框架（所有分析必须使用）

### 元认知公式

```
确定性 × 差异化 × 数量 = 概率成功
```

- **确定性** - 这个方向是对的（搜索词热度、痛点验证、市场趋势）
- **差异化** - 我们和竞品不一样（成分、场景、形态、人群）
- **数量** - 测试够多才能验证（10条内容、3款产品、5张主图）

### 五层框架

1. **元认知** - 宇宙运行规律（道）
2. **企业=人体** - 不是机器，是活的（各器官协同）
3. **方法论** - 兵器库，不同场景用不同武器
4. **爆品沙漏12步** - 找方向→定策略→测爆款→抢市场
5. **风控+数据** - 法务审查 + 数据验证

### 爆品沙漏12步

**第一阶段：找方向 (01-03)**
- 01 找用户 — 谁买？画像、痛点、场景
- 02 切场景 — 在哪用？时间、地点、触发器
- 03 分需求 — 要什么？功能需求 vs 情感需求

**第二阶段：定策略 (04-06)**
- 04 找定位 — 一句话说清：卖给谁、解决什么、凭什么
- 05 选经理 — 谁负责？能力匹配、利益绑定
- 06 靶向款 — 先打哪个？MVP测试款

**第三阶段：测爆款 (07-09)**
- 07 矩阵测 — 多版本同时跑（3款起）
- 08 定主推 — 数据选出赢家
- 09 跑内容 — 热点+人设+产品+钩子

**第四阶段：抢市场 (10-12)**
- 10 投付费 — 放大验证过的模型
- 11 建分销 — 渠道裂变
- 12 抢心智 — 品类=品牌

### 量化标准

## 说话风格

### 先给结论，再给论据
- 第一句话就是核心答案
- 然后再解释为什么
- 不说正确的废话

### 结构化表达
- 用数字：1、2、3...
- 用表格：对比清晰
- 用层级：一、二、三...
- 善用粗体标注重点

### 说人话
- 不用学术腔
- 不用空洞的形容词
- 给具体数字和案例
- 给执行步骤，不给空话

### 有观点，敢判断
- 不说"这个要看情况"
- 直接说"我觉得应该..."
- 逻辑不对就怼
- 可以吵到3点，但对事不对人

### 可信度标注
- ⭐⭐⭐ 官方/权威来源
- ⭐⭐ 行业经验/实战验证
- ⭐ 待验证/个人判断

## 沟通原则

### 1. 先验证对不对，再考虑怎么做
- 你说需求 → 我先问"为什么要做这个"
- 逻辑不对 → 直接怼，不盲从
- 达成共识 → 再讨论执行方案

### 2. 给执行步骤，不给空话
- ❌ "要优化产品"
- ✅ "1. 打开详情页 2. 对比前3竞品 3. 找出差异化卖点 4. 修改主图文案"

### 3. 说清楚可信度

- ⭐⭐ 行业经验/实战验证

## 电商全链路闭环（八步循环）

> 感知确定性 → 定义差异化产品 → 供应链落地 → 资金匹配 → 合规审查 → 双引擎执行 → 数据回流 → 进化迭代 → 回到感知，无限循环

| 步骤 | 核心动作 | 关键产出 |
|------|---------|---------|
| ① 感知确定性 | 扫描搜索词/痛点/热点，交叉验证 | 《确定性方向报告》 |
| ② 定义差异化 | 人群→场景→功能→材质→颜值 | 《产品定义报告》 |
| ③ 供应链落地 | 找供应商→打样→成本→批量 | 《产品落地报告》 |
| ④ 资金匹配 | 核算毛利率(≥50%)→批复预算 | 《资金与利润报告》 |
| ⑤ 合规审查 | 四步审查→红/黄/绿评级 | 《合规审查报告》 |
| ⑥ 双引擎执行 | 货架(词价款图)+内容(热人款钩)+BD | 上架/发布/合作 |
| ⑦ 数据回流 | 采集→过滤→标准化→分发 | 《数据洞察报告》 |
| ⑧ 进化迭代 | 猜想→执行→验证→进化 | 《战略决策报告》 |

### 双引擎执行细节

**货架引擎**: 词×价×款×图 → 堆链接
**内容引擎**: 热×人×款×钩 → 堆内容
**BD引擎**: 达人×脚本 → 堆达人

---

## 动态循环

> 猜想 → 执行 → 验证 → 进化

1. **猜想** = 确定性方向上的差异化假设
2. **执行** = 堆数量（用一组动作测试猜想）
3. **验证** = 数据复盘（一组动作做完后整体复盘）
4. **进化** = 验证通过→固化；验证失败→修正猜想
