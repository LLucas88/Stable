# 输出模板库

本文件为「今日头条热点改写投稿专家」的模板与示例，由 `SKILL.md` 引用。
所有模板均为骨架，实际生成时填入具体热点内容，并遵守 SKILL.md 的原创与合规红线。

---

## 一、微头条模板（100–300 字）

**结构**：钩子开头 → 事件还原 → 观点解读 → 互动结尾

```text
[钩子]（前 1–2 行，冲突 / 悬念 / 痛点，可带 1 个 emoji）
[事件]（2–3 句短句，讲清发生了什么，带信源）
[观点]（你的增量视角，1–2 句，敢说但有理）
[互动]（抛一个问题，引导评论，如"你觉得呢？"）
#话题1 #话题2
```

**示例（占位热点）**：
🔥 刚刷到一个消息，越想越不对劲。
据说__（事件，来源：__）。表面看是__，但仔细一想__。
我觉得这事关键在__，普通人最该警惕的是__。
你们怎么看？评论区聊聊。
#热点 #__

## 二、头条文章模板（800–1500 字）

**双标题**：
- 主标题（≤20 字，吸睛）：__
- 副标题（补充事件）：__

**结构**：
- 导语（50–80 字，钩子，点出为何值得读）
- 小标题一：事件还原（发生了什么，带信源、时间线）
- 小标题二：背后逻辑（为什么会发生，数据 / 背景）
- 小标题三：我的观点（增量视角，可反常识但需有据）
- 小标题四：对普通人的影响 / 启示（落到读者利益）
- 结语（收束 + 互动提问，引导关注 / 评论）

**示例骨架**：
```text
（主标题）
（副标题）

[导语] 今天__刷屏了。这事看着简单，其实藏着__的信号，花 3 分钟说清楚。

一、事情经过
__（5W1H，短句分段）

二、为什么会这样
__（补充数据 / 背景，信息增量）

三、我的看法
__（独特观点，可反常识但需有据）

四、跟我们有什么关系
__（落到读者利益）

[结语] __（一句话总结 + 提问引导关注 / 评论）
```

## 三、标题变体生成示例

给同一事件出 4 个标题变体，覆盖不同钩子，输出时标注建议的主 / 副标题组合：

1. **数字悬念**：「3 个细节，暴露了__」
2. **反差冲突**：「看似降温，其实__」
3. **痛点利益**：「别再被__骗了」
4. **情绪共鸣**：「作为一个__，我坐不住了」

> 输出时至少给 2 个变体，并标注推荐组合（主标题 + 副标题）。
