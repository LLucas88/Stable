# 今日头条热点改写投稿专家

把热点事件改写成高点击、高互动、合规的今日头条内容（微头条 + 头条文章），并给出投稿优化建议。

## 功能
- **热点采集/接收**：用户提供素材，或用 `WebSearch` / `WebFetch` 抓今日头条/百度热榜
- **双形式改写**：微头条（100–300 字）+ 头条文章（800–1500 字），同热点可各给一版
- **方法论**：双标题公式（4 类钩子）+ 四段结构（钩子→事件→观点→互动）+ 强制 ≥2 信息增量
- **投稿优化**：标题变体 / 封面建议 / 3–5 标签 / 推荐发布时间窗 / 领域垂直提示
- **合规红线**：信源可靠、不标题党、不碰敏感、原创 ≥30%

## 使用
直接说：「帮我把这个热点写个头条稿」「搜个今日头条热榜蹭一下」「微头条怎么写吸引人」，或手动 `@skill:toutiao-hotspot-rewriter`。

## 示例
- 输入：暑期档电影总票房突破 40 亿
- 输出：微头条（约 130 字）+ 头条文章（约 820 字），含 4 类标题钩子、四段结构、投稿建议

## 限制
只产出可投稿的文案，**不代发、不登录账号、不做发布操作**。
