# 多来源专题研究

面向需要证据综合的专题调研，先从已知上下文确定研究问题、范围、时效和交付用途。信息不足且影响结果时再澄清。

1. 按主题拆分子问题，设计能区分相反解释的检索词。
2. 使用本轮实际提供的联网搜索。Stable 搜索是否可用取决于所选模型与账户，不能假设存在固定的 DuckDuckGo CLI、web_fetch 或 OpenClaw 会话工具。
3. 优先读取官方资料、原始研究和一手披露；不能仅据搜索摘要作出重要判断。通过获准的后台 HTTP 读取公开页面，不自动接管浏览器。
4. 对关键结论交叉验证，区分多家转载和独立证据。比较发表时间与事件时间；历史问题不机械排除旧来源。
5. 报告先给结论与证据，再说明分歧、限制及尚待验证的部分，引用直接支持论断的页面。

长报告写到当前工作区的用户指定路径，简短任务可直接回复。检索次数和报告章节以实际研究需要为准。未获取的网页、未完成的访问和没有证据支持的数字必须如实说明。
