# 竖屏 HTML 演示稿

用户要求 HTML 演示或明确接受该格式时，将讲稿转成单文件竖屏演示。用户要求 `.pptx` 时不能用 HTML 冒充 PowerPoint 文件。

1. 阅读原稿，保留事实和重要条件；生成适合演示的精简内容与页面顺序。
2. 参考 `references/slide-types.md` 和 `references/design-spec.md`，选择与内容匹配的页面。默认极简深色，但用户的品牌、比例和风格要求优先。
3. 以 `assets/template.html` 为起点替换示例标题、数据与正文。此迁移版模板使用内联 CSS 和系统字体，无需远程脚本。
4. 保留键盘左右翻页、点击导航、页数与进度更新；处理小屏、长标题和减少动态效果的偏好。
5. 保存到当前工作区，核对文字和页数，使用获准的预览路径检查溢出与交互。未做视觉检查时明确说明。

按用户要求交付 HTML 文件、讲稿或大纲，不重复输出用户不需要的完整代码。页数由内容决定，不强制扩写到固定数量。
