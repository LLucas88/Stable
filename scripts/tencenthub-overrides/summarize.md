# 文本与文档摘要

读取用户给定的文本、文件或可访问网页，识别正文，提炼要点，保留决定含义的数据、人物、时间和条件。可按用户要求输出短句、段落、详细摘要或结构化 JSON。

1. 确认源内容是否完整；先提取实际正文。按本轮工具能力读取 TXT、Markdown、DOCX 或 PDF，网页通过可用搜索/后台读取能力获取。
2. 对长材料分段提炼，再合并去重，记录重要结论的页码、章节或链接。不能把抓取失败或截断的内容当作全文。
3. 区分作者观点、材料事实与摘要者推断，保留原材料中的不确定性与相互矛盾之处。
4. 根据用户需要附上关键词、文档大纲或来源元信息。不要把摘要改写成无来源的新结论。

本迁移版直接利用 Codex 与 Stable 的文件能力，不依赖原包文档中并未提供实现的 `summarize` CLI。扫描 PDF 的 OCR 和受登录保护的网页需具备实际支持后才能处理。
